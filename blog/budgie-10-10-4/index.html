Budgie 10.10.4: what actually changed since 10.10.3

Budgie 10.10.4

A stable fourth minor release of the 10.10 series. Panel auto-hide and dock mode finally work on Wayland, Raven gets keyboard view switching, panels get a show shortcut, and a long list of panel, Crystal Dock, and labwc bugs get fixed.

Budgie 10.10.4 shipped on November 1, 2026 as the fourth minor release of the 10.10 series. It is primarily a bug fix release, but it also makes automatic and intelligent panel hiding work on Wayland, reworks dock mode, adds keyboard switching between Raven views, adds a shortcut for showing panels, and speeds up panel startup. This is a normal stable release with no feature freeze.

Things worth your attention

Panel auto-hide and dock mode on Wayland

Under X11, Budgie could read window size and position and hid an Intelligent panel whenever a window intersected it. On Wayland it only gets maximized state and monitor from wlr-foreign-toplevel-management, so that overlap check had nothing to work with. In 10.10.3, an Intelligent panel hid by dropping behind windows, which broke once a window was maximized (issue #950); Automatic did not hide at all; and a hiding dock still reserved its whole edge.

10.10.4 reworks the panel code. A hidden panel now stays above windows but invisible, with a 3px strip along its edge to catch mouse events. Moving the mouse to that edge brings the panel back, and clicks elsewhere pass through to the window underneath. Panels stay visible while one of their popovers is open, so Budgie Menu, Icon Tasklist popovers, and the Sound applet keep working. Panels set to auto-hide no longer reserve screen space, so maximized windows use the full screen.

Since Budgie cannot check whether a window intersects a panel, both policies now go by maximized windows. Automatic hides the panel whenever any window on its monitor is maximized. Intelligent hides it only while the focused window is maximized.

Fullscreen applications

Moving the mouse to the edge of the screen now shows the panel above a fullscreen video. Games that lock the pointer are unaffected, as long as the compositor implements the pointer constraints protocol. Panels set to “Never” stay behind fullscreen applications, and there are two ways to raise panels over one (issue #600). Super+T is a new shortcut that shows all panels without opening Budgie Menu; pressing it again hides them, as does moving the mouse over a panel and then away. The Super key now shows every panel when opening Budgie Menu, not just the panel the menu sits on. Panels stay visible while the menu is open and hide once it closes and the mouse is not over any of them.

Raven

You can now switch between Raven’s widgets and notifications views with the keyboard while Raven is open (issue #1005). Super+A or Super+N switches to that view, and pressing the shortcut for the view you are already on closes Raven.

labwc bridge

Super+Shift+arrow keys move the focused window to the monitor in that direction, as they did on Budgie 10.9 (issue #1006). Picture-in-Picture windows, such as Firefox’s, now stay on top of other windows (issue #1018). Left clicking the desktop now only focuses it, while right clicking still opens the root menu. This fixes accidental launches on touchpads and Budgie Menu and Raven not closing when left clicking the desktop with desktop icons turned off (issue #1004). Existing labwc configs migrate on login, keeping any mouse settings you added.

Screen dimming and locking

You can choose how long Budgie waits before dimming the screen, from 30 seconds to 30 minutes, with 0 turning dimming off (issue #999). Set it with gsettings set com.solus-project.budgie-wm dimming-delay 90. You can also choose which screen locker Budgie uses, gtklock or swaylock (issue #1021). By default it uses the first one found, checking gtklock first: gsettings set org.buddiesofbudgie.budgie-locker locker-choice 'swaylock'. If the chosen locker is not installed, Budgie falls back to the one that is.

Faster panel startup

Previously, Budgie Menu, Icon Tasklist, and the Autostart page in Budgie Desktop Settings each loaded the full application list separately, and Icon Tasklist did so again for every window it needed to match. Now the list is loaded once and shared across the panel, and reloaded when applications are installed or removed. Measured with 281 applications installed: desktop-file scans at startup dropped from 9 to 1, main-thread scan time from about 200 ms to 22 ms, panel user-space CPU time from 392/427 ms to 255/270 ms (about 36% less), tasklist first population from 106/118 ms to 14/13 ms, allocation calls from 2,756,211 to 1,763,625 (about 36% fewer), and short-lived allocations from 522,009 to 213,184 (about 59% fewer). Peak heap rose by 0.81 MB, which is the shared application list kept for the panel’s lifetime. Opening the Autostart page and matching windows opened after startup also use the shared list now.

Development

Budgie Desktop now supports meson devenv, so the panel, applets, and Raven can run straight from a build directory without installing: meson devenv -C build budgie-panel --replace.

Smaller changes

Performance and internals

  • The shared application list is reloaded when applications are installed or removed, so Icon Tasklist and the Autostart page stay current.
  • Crystal Dock’s wallpaper border workaround can handle JPEG XL wallpapers on distributions whose ImageMagick lacks JPEG XL support, by building Budgie with GraphicsMagick instead (issue #988).

Visual polish

  • A hidden panel keeps a 3px capture strip along its edge so the mouse can bring it back, while clicks elsewhere pass through to the window underneath.
  • Panels stay visible while a popover is open, so menus and applets remain usable.

Developer tools

  • meson devenv support for running the panel, applets, and Raven from a build tree.

Content and smaller apps

No new applications or content changes in this release.

Bug fixes

Panel

Applets could disappear from the panel after updating to 10.10.3 in a non-English locale. Applet settings store the plugin name, and the panel matched it against the name libpeas reports, which became translatable in 10.10.3, so translated names failed to match. Applets now store the plugin’s module name in a new module key, which the panel prefers; existing applets are migrated on login, and translated names saved by 10.10.3 are still accepted. Other panel fixes: a panel no longer stays hidden when an applet fails to load and that applet is removed from configuration; Budgie Menu no longer covers a panel that does not reserve screen space; clicking a dropdown inside a popover no longer closes the popover; the panel no longer crashes at startup when it has no stored position (issue #1001); a newly created panel saves its position right away; and a panel no longer moves off the primary monitor after changing its edge.

Bluetooth applet

Budgie Control Center 2.1.1 removed its Bluetooth panel, which broke the settings button. It now opens the first installed of Bluejay, Blueman, or Budgie Control Center.

Crystal Dock

JPEG XL wallpaper handling works via GraphicsMagick builds where ImageMagick lacks JPEG XL support (issue #988); changing a setting no longer regenerates the wallpaper twice (issue #945); and restarting budgie-daemon no longer leaves stray swaybg processes.

VMware

The mouse pointer is visible again in VMware virtual machines. The labwc session sets WLR_NO_HARDWARE_CURSORS when it detects VMware’s virtual GPU, as it already did for virgl (issue #1037).

Qt applications

Older Qt applications and AppImages without Wayland support can launch again. When QT_QPA_PLATFORM is not already set, the labwc session sets it to wayland;xcb, so Qt falls back to XWayland.

Known regressions and deferred work

None listed yet.
