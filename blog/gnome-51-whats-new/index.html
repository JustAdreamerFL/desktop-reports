GNOME 51 “A Coruña”: what actually changed since GNOME 50

GNOME 51

Alpha and beta are out, the final release lands September 16. Here is everything noteworthy, everything minor, and the bug fixes worth knowing about, sorted into sections you can actually read.

As of late August 2026, GNOME 51 has an alpha (July 3) and a beta (August 15). The final release is due September 16. Beta also started the UI, feature, and API freezes, so this covers practically the whole release: fixes and translations will still land before the final, new features will not.

Things worth your attention

Graphics and the compositor

Mutter can now blur window backgrounds through a new Wayland protocol, ext-background-effect-v1, and GTK 4.23.3 added the client side (ext-background-effect). The compositor does the blurring rather than the app, so it works universally. Until now this was shim and extension territory.

Timing is the other big area. Michel Dänzer sent a series of frame scheduling patches to Mutter (!5138, !5131, !5183, !5167, !5156), and Benjamin Otte reworked the GTK frame clock: better prediction of when a frame will actually hit the screen, fewer dropped frames, and a fix for the frameclockidle deadlock. Animation and scrolling smoothness should improve across the board, most visibly at high refresh rates and on VRR displays.

Cursors can ship as SVG now, in a format compatible with KDE. Cursor theme authors no longer need to generate raster sets for every HiDPI scale.

Mutter fills in mastering display metadata for HDR output.

One breaking change: Mutter dropped legacy NVIDIA drivers (!5079). Old proprietary versions stop working; current NVIDIA and Open kernel modules are fine.

Shell and login

Web login and a unified auth mechanism (MR !3212): the login screen can offer several authentication mechanisms side by side, including logging in through the web. This is the biggest GDM and Shell change in years.

Shell started honoring the reduced-motion setting (initial support), holding back motion animations for people who want less of them. GTK respects the same setting.

The COPY, CUT, and PASTE keys work in Shell text entries.

Calendar reminders pop up as Shell notifications (!1064), so you no longer need to open the calendar app to see them. Monitor brightness is saved and restored across sessions, too.

The VA-API H.264 screencast pipeline gained rate control, so screen recording loads the machine less. The extensions app moved to its own repository. Extension authors should note that async disable() is explicitly disallowed now; until recently that path led straight to race conditions.

GDM has a fallback session setting (it kicks in when a user has no preferred session or theirs is unusable), an option to turn off the local greeter on headless machines, and KMSCON VT compatibility. Conflicting sessions are enumerated through logind, so GDM sees sessions started by ThinLinc or TigerVNC as well. XDG_DATA_DIRS no longer hard-codes /usr/share above /usr/local/share, which means hacking on a locally built gnome-shell no longer requires rebuilding GDM with the same prefix. The remote display D-Bus API and GDM settings finally have documentation.

Applications

Disks is finally on GTK4 and libadwaita. The port came with real HIG and accessibility work: adaptive mount options, better unlock and resize UX, benchmarking, reworked drive view and partition editing headers, and multi-device filesystems show total filesystem size. The GTK4 rewrites of Boxes and Disks were originally planned together, but only Disks made it into 51.

Maps can download maps for offline use. Probably the most useful addition of the whole app batch.

Calendar went through an internal rework onto GListModel (GcalTimeline and GcalTimelineSubscriber now operate on GListModels). You will notice it mostly with large calendars; the concrete view fixes are listed under bug fixes.

Orca 51 is nearly a release of its own: user plugins and extensions, MathCAT for MathML, announcing formatting changes while reading (handy for proofreading), language-specific voice sets activated by command, automatic sleep mode for chosen apps, configurable flat review, double-tapped Orca+F showing all font and formatting info in a window, and configurable speech inflection. The beta added localized strings for extensions.

Nautilus opens locations from other apps in new tabs, has AdwTabOverview in narrow mode, moves search focus to the most relevant result, ignores most duplicate entries in the app chooser, and gives the Projects bookmark its own symbolic icon.

Epiphany: a keyboard shortcut for copying the page URL, URL pinning in history and overview, a Firefox Sync OAuth flow, EphyWebExtension replaced by WebKitWebExtension, secure password generation via libpwquality, undo toasts when removing overview items, and adjusted Reader Mode line spacing.

Calculator remembers calculation history across restarts, shows the exponent in the current base, and does exact rational arithmetic via GMP.

Settings: a new fingerprint management interface in Users, an About panel with a button to open the release notes and a more accurate “GNOME Shell Version”, an Accessibility setting to disable the focus timeout, an Auto Rotate row for devices with accelerometers, center-aligned display snapping, disabling the touchpad when a mouse is plugged in, DNS domain search, Wi-Fi sharing through the QR widget, “ConfigureShortcuts” in Global Shortcuts, reworked panel navigation, and stricter policies for systemd-homed accounts (auto-login off, data deletion on account removal). WEP support is gone.

Initial Setup supports systemd-homed accounts, and enterprise accounts got error indications plus accessibility states. Loupe shows the ICC or CICP profile description along with metadata like author, copyright, lens, and software. Text Editor allows move-next/previous while the search bar is closed. Connections handles H.264 encoding in Flatpak builds, captions in app screenshots, and connections to IPv6 URIs. Software warns before installing end-of-life apps, lists more Flatpak permissions, and starts faster thanks to cached AppStream data. Kiosk got a basic screensaver and session presence, a sample root menu and session, and window configuration options (lock-move, lock-resize, set-strut, match-window-type).

What left the platform

Removed modules: gcr-3, gnome-keyring, evince (Papers replaces it), and gtksourceview-4. Together with oo7-portal from the API section, the direction for secret storage is clear: the oo7 stack. Distros can still package these themselves, but they are no longer part of the GNOME platform.

Smaller changes

Performance and internals

  • Nautilus: faster view reloading, blocking IO pushed off the main thread, no duplicated loading locations.
  • Software: faster icon loading and PackageKit repository refinement.
  • System Monitor: reworked cgroups performance.
  • tinysparql: faster ICU full-text tokenizer; localsearch refactored code shared between processes.
  • GtkSourceView: faster context engine and search context.
  • Shell screencasts minimize stage paints and buffer copies.
  • GLib: the GNetworkMonitor netlink backend behaves like iproute2 and pulls the route table less often.
  • libdex: reworked work stealing in the thread pool; idle workers sleep instead of scanning peers, and work distributes better.
  • GTK: GPU cache scaling limits, text view caches pixel height, motion history is always collected for input prediction.
  • Sysprof: libsysprof-capture optimizations.

Visual polish

New wallpaper set, including a default tweaked from feedback. Shell uses its own sound effects instead of the sound theme, animates app grid label expansion nicer, supports touch scrolling in ScrollView and start/end text alignment, exposes the slow-down-factor in looking glass, lights the audio-input icon only during actual recording, and the session/a11y menus at the login screen respond to both mouse buttons.

Maps moved settings (scale, user location, measurement system) from menus into the preferences dialog, larger place-name fonts in the sidebar match the new pill buttons, transit itineraries show walking durations, going-to animations are skipped over large distances, and tombs have a fresh icon 🙂

Nautilus widened the sidebar limit, shows an empty “Document” entry when the templates directory is empty, uses AdwComboRow for the open-action preference, hides the redundant “Open Parent Folder” row, puts the symlink emblem before read-only/unreadable ones, and badges the selection count while dragging files (alpha).

Sushi: a loading spinner for slow files, line wrapping in the text viewer, double-click fullscreen for images, a context menu in the HTML viewer, a prompt before loading remote resources, width-clamped media controls, and the headerbar hidden in fullscreen.

Control Center merged all panel CSS into one stylesheet, adopted clang-format globally, moved the About copy button to AdwButtonRow, modernized the Wacom button-mapping dialog, and hides the auto DNS/route toggles in Manual mode.

libadwaita 1.10.beta adds AdwSidebarItem :prefix and AdwSidebarSection :suffix, animates the title on the About dialog main page, and fixes adaptive preview issues (rounded corners, false minimum-size warnings).

Developer tools

Foundry 1.2.beta runs GitLab CI locally in Podman (includes, rules, stages, needs, artifacts), adds public CI and Git API abstractions, ships foundry ci list/run/shell/clean, bindable amend support, commit templates, and help generated from the command tree. Also: blueprint-compiler 0.22.2, Builder 50.0, and Vala 0.56.19 with gdbus and vala fixes plus updated bindings.

Epiphany, Nautilus, PyGObject, and GTK all adopted the gobject-linter CI job at scale. Sushi’s plugin API was overhauled with a system-wide plugin path and documentation, so previewer plugins can be written properly. GJS makes GNOME objects more transparent to the garbage collector, which gives Sysprof accurate memory stats; it is a prerequisite for removing the “big hammer” workaround. Smaller items: gtk-doc 1.36.1, gi-docgen dependency listings in libshumate, and completed dconf man pages.

Content and smaller apps

adwaita-fonts 51.0, Papers 50.2, Simple Scan 50.0, Music 50.0, and Decibels 49.6.1 (PipeWire stream metadata, MPRIS SetPosition/OpenUri fixes). Rygel 46.beta added Reciva devices to the seek hack and fixed a crash on address family mismatch. gdk-pixbuf 2.44.8 brings glycin x-/y-dpi support for PNG, TIFF, and JPEG.

glycin 2.2.beta: an API to disable ICC-to-sRGB conversion, frame format transformation, a Radiance HDR loader, and pixel density as its own object (breaking against the alpha API). gnome-user-docs updated GNOME Help.

Bug fixes

Compositor, display, input

Mutter: blurred rendering on non-pixel-aligned monitors, invalid redraw clips on rotated monitors, shader snippets reapplied correctly after resize and scale, unsupported fallback monitor modes no longer offered, wrong stacking order changes on workspace switches, fullscreening edge-tiled windows, alt-tab under sloppy/mouse focus, DND data offers on touch, tablet DND across surfaces, broken switch-monitor mapping on stylus buttons, unfullscreening maximized windows correctly, OSK triggering for text_input_v3 v1 clients, preferred_scale events delivered to clients, cursor position hints for Xwayland under scaling, tablet cursor hotspot scaling, moving maximized windows between monitors by keyboard, window size increases after fast unmaximize drags, plus a run of crash fixes (!5143, !5153, !5151, !5163, !5169, !5170).

Shell: a glitch when switching to a minimized window on another workspace, mis-scaled magnified cursors on HiDPI, sound glitches from redundant volume changes, wiggle feedback on non-password auth failures, the spinner resetting on every keystroke in overview search, layout reapplication on xkb-options changes, the “Install Updates” checkbox in the power dialog, autorun notifications for USB drives, spacing in lock screen media notifications, workspaces disappearing mid-animation, removing arbitrary providers when unregistering search providers, and one memory leak.

GTK: the X11 selection clipboard burned excessive CPU (#6493), animated SVGs frequently disappeared (#8195), type-to-search broke in Epiphany dialogs (#8291), GLArea leaked memory on unrealize, GtkPicture dispose left a dangling paintable, tooltips blocked on X11, a frame clock idle deadlock from counter underflow, munmap() of the wrong pointer in the dmabuf format table, CSS text-decoration needing a resize to apply (a regression), application menu items with multiple shortcuts showing none, and Super/Hyper no longer counting as text modifiers.

Login and sessions

GDM: Plymouth never quit on headless or monitor-less systems, so the machine never reached graphical.target; X11 sessions started with XDG_SESSION_TYPE=wayland; kernel VT cursor flicker when logging out; checks that PAM plugins do not drop fsuid privileges and break GDM; and PAM modules are notified when the user switches right before exec’ing the session leader (fixes pam_cap.so in defer mode).

gnome-session had a regression in screen blanking and idle handling, fixed in beta. gnome-settings-daemon: Housekeeping failed to launch Baobab, one use-after-free, and power temporary-unidle now cooperates with inhibitors.

Apps

Calendar: sporadically missing horizontal separators in month view, the event editor not saving duration changes, a week view crash with multiple overlapping events, and a tooltip on an invisible overflow button.

Nautilus: correct starred status and properties behavior in Recents, right-clicking the view background no longer clears the selection, manual selections survive file operation results, copied files get selected after the operation finishes, Escape closes the app chooser while the entry is focused, thumbnails update during loading, loading getting stuck while thumbnailing in Flatpak, the “Window is ready” notification firing when other apps call “Open location”, timed dialogs destroyed before their timeout, and a memory leak in create-links-in-place.

Epiphany: colons in app-mode URLs converted to “A”, crashes on invalid view-source: URIs, a memory leak in ephy_string_shorten(), an out-of-bounds assert in the JSON helper, duplicate password entries when editing usernames, crashes deleting password records, crashes after adding OpenSearch engines, a preferences crash after deleting the default search engine, a memory-corruption fix-of-fix in web-view, and F6 documented among shortcuts.

Connections: authentication dialog focus chain, cursor change propagation, IPv6 URI connections, NULL Common Name handling in RDP, and no longer storing already-stored connections. Initial Setup: a crash when the SSID got freed on the network page.

System Monitor: summary units in the process table, translatable disk read/write rate units, duplicate icon text in preferences. Calculator reports an invalid name entry to the accessibility layer. gexiv2 crashed opening files without preview images.

at-spi2-core: a crash in get_registered_event_listeners, grab id 0 assignments, wrongly deregistered event listeners, NULL dereferences when sending events, and detection of unresponsive applications, which no longer show up as desktop children.

GtkSourceView: the file loader rejects non-regular files, bounds expanded/decompressed input size, fails loads cleanly, plugs gutter and gutter-line leaks, breaks a circular reference with line numbers enabled, and fixes Vim emulation for repeated commands, r, cw/cW, +, X, gu, gU, g~, Ctrl-A/X, and :set aliases.

Orca: table presentation including Chrome’s history table, aria-busy respected, no percent value on indeterminate widgets, false-positive flat review resets in terminals, color-chooser button names, item counts in list boxes, and set_current_voice() persistence.

yelp fixed an issue that allowed remote access to local files (49.1, security relevant). zenity’s --hide-header actually hides the header now.

Security

GLib’s GDBusServer suffered a pre-authentication DoS through unbounded SASL line buffering (#3985).

Evolution Data Server got a hardening series: a shell command injection fix in NTLM SASL, ENVID sanitization against SMTP command injection, POP3 rejecting CRLF-bearing credentials (command injection), CardDAV validating photo/logo URI origins against SSRF, a MIME nesting depth limit against stack exhaustion, HTTPS-to-HTTP redirects rejected, and OAuth2 state parameters against CSRF.

gvfs hardened input validation across afp/dav/ftp/mtp/sftp backends, wipes passwords from memory before freeing them, and fixed crashes in the OneDrive, MTP, and SMB backends. glycin switched its sandbox seccomp policy from an allowlist to a blocklist, a sturdier second line of defense. Epiphany quotes command-line input before passing it to the shell (!2094) and carries the memory-corruption and crash fixes above. dconf’s safe GVDB writer protects settings integrity on NFS.

Libraries and build

GLib: an fd leak in g_file_set_contents_full(), a crash on gio help help, a GDBusActionGroupClass failure, Windows UNC paths in the spawn helper, and a massive purge of G_GNUC_CONST from _get_type() functions across the stack (GLib, glibmm, gtkmm, gvfs, libshumate…); GCC 17 risked miscompiling those.

libsoup HTTP/2: the content sniffer running while paused, failed messages requeued when a connection is not reusable, buffered bodies consumed before cancel, and reads limited to received content. Pango: CoreText variations and font features, overline/underline/strikethrough staying in sync, undefined-behavior fixes.

Evolution Data Server: LDAP Simple Paged Results (RFC 2696), IMAP4 Multimailbox SEARCH, junk folder unread counting, recurring task due-date reset, camel-lock-helper symlink handling, a deadlock with m365 GOA accounts, a pile of memory leak fixes, and gb2313 mapped to gb18030. gtk+-3, yelp, and tecla carried maintenance and build fixes.

Known regressions and deferred work

Sushi shows only the first frame of animated GIFs, and LibreOffice documents render as PDFs because the old method is incompatible with the GTK4 port. GTK deferred session save/restore to 4.26. Boxes missed the 51 train (Disks made it). GDM keeps PreSession/PostSession hook scripts removed; the decision from the 50.x series stands.
