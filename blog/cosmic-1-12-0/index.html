COSMIC Epoch 1.12.0: what actually changed since 1.11.0

COSMIC 1.12.0

System76 tagged Epoch 1.12.0 on November 24 with an empty release body. The real changes are in the submodule commits: theme bundles, a pointer size setting, Xwayland controls, and a batch of a11y and security fixes.

As of November 25 2026, COSMIC Epoch 1.12.0 is tagged and stable. Jeremy Soller created the annotated tag on November 24, roughly a month after 1.11.0 on October 20. There was no separate feature freeze announcement: an epoch is a coordinated bump of every submodule, and this one moves 28 of them. The GitHub release body contains only the tag message, “Epoch 1.12.0”, so the list below comes from the merged commits in the range rather than from official notes. What is still open is packaging: the tag is upstream, and distro packages will pick it up on their own schedule.

Things worth your attention

Theming: bundles, dark and light wallpapers, fades

This is the biggest user-facing area in 1.12.0. COSMIC Settings can now save a look as a self-contained theme bundle, import one, rename it, and keep several side by side (cosmic-settings, theme-bundle-config). The strings you will see are “Save as…”, “Save theme as”, “Rename theme”, and “Legacy theme file”. A bad import says “select a .zip bundle or .ron theme file”. Bundles write to /usr/share-style config and data roots with an x-cosmic-format metainfo marker, and the import path accepts old ThemeBuilder .ron files, so earlier custom themes are not stranded. Frosted glass is enabled by default in this cycle.

Backgrounds gained per-mode entries, so dark and light mode can use different wallpapers (cosmic-bg, cosmic-bg commit d6dcfa9). Switching between them fades over 500 ms by default through wp-alpha-modifier-v1 and subsurfaces; the config key is transition_duration, in milliseconds (cosmic-bg commit 203159b). The default wallpaper is now system76-cosmic-dark.png (cosmic-bg commit 803047f), also used as the greeter fallback (cosmic-bg commit 2439903). Several modules switched from the old JPEG XL decoder to jxl-rs, including cosmic-bg, cosmic-files, cosmic-greeter, and cosmic-settings.

Who it affects: anyone who customizes COSMIC themes, and theme authors who shipped .ron files. The bundle format is new, so expect a migration edge or two in the first packages.

Pointer size, end to end

COSMIC Settings has a “Pointer size” slider in Accessibility (cosmic-settings, cosmic-settings commit aaf58b4). It steps through 24, 32, 48, 64, and 96 logical pixels. On the compositor side, cursor_size is a new cosmic-comp config key that falls back to $XCURSOR_SIZE (cosmic-comp commit 0681eaf); changing it at runtime reloads every seat and the Xwayland cursor without a restart. cosmic-settings-daemon mirrors the value to GTK via org.gnome.desktop.interface cursor-size, which matters because GTK apps draw their own cursor (cosmic-settings-daemon commit ff28489).

Who it affects: HiDPI users, people with motor impairments, and anyone who found the old fixed cursor too small on a large monitor. This completes a loop that previously only worked through environment variables.

Compositor defaults and Xwayland controls

Mutter-style server-side decorations are now the COSMIC default. The new decoration_preference key sets DecorationPreference::ServerSide, and Settings exposes it as “Use system window headers when possible” with the note “Applications may use their own window headers in some cases” (cosmic-comp cosmic-comp commit 63dacd1, cosmic-settings cosmic-settings commit 5f43cfc). Touchpads default to natural scrolling (cosmic-comp commit 88a3421).

Xwayland can be disabled outright with COSMIC_DISABLE_XWAYLAND=1 (cosmic-comp commit ed9a71c). Font smoothing for Xwayland apps was added: the compositor now writes Xft/Antialias=1, Xft/Hinting=1, Xft/HintStyle=hintslight, and Xft/RGBA=none (cosmic-comp commit 8129317). cosmic-comp also retries opening GPU nodes at startup (cosmic-comp commit 0a67a6c), picks the highest refresh rate when a mode reports none (cosmic-comp commit 8e0b615), and resets GAMMA_LUT during CRTC init (cosmic-comp commit cb86b9e).

Who it affects: multi-monitor and hybrid-GPU setups, users who want a Wayland-only session, and anyone whose X11 apps looked rough on HiDPI. The environment variable is opt-in, not a default change.

Urgent notifications over fullscreen windows

cosmic-notifications gained a FullscreenBehavior setting with three values: None (the default, notifications stay behind fullscreen windows), UrgentOnly, and All (cosmic-notifications commit 2137773). The implementation keeps a second overlay layer surface and decides per notification which one to use. Critical alerts can now break through a fullscreen game or presentation, but only if you ask for it.

Who it affects: users who miss critical notifications during fullscreen work, and kiosk or signage setups where popping up over fullscreen would be unwanted.

App launching and GPU choice

Four modules now launch apps as .service units with XDG cgroup names: cosmic-app-library (cosmic-app-library commit e4c3d73), cosmic-applets (cosmic-applets commit 582281f), cosmic-launcher (cosmic-launcher commit 81647dd), and cosmic-store (cosmic-store commit 63e7650). cosmic-app-library also fixes daemonized apps such as Zed closing when the launcher exits (cosmic-app-library commit 096f348). GPU preference handling was corrected in three places: the default discrete GPU is retained and a preference override is no longer set when the ID already is the default (cosmic-launcher commit eb74145, cosmic-launcher commit 3c52515, cosmic-store commit bb24819).

Who it affects: hybrid-GPU laptop owners and anyone whose terminal-launched apps vanish on exit. Grouping apps into their own cgroups also makes per-app resource limits possible for distro integrators.

Updates pages on Pop!_OS

cosmic-settings gained a Pop!_OS-only OS updates page built on pop-system-updater-zbus (cosmic-settings commit 4d515f2). It offers Daily, Weekly, and Monthly schedules with AM/PM and weekday fields, visible in i18n/en/cosmic_settings.ftl. cosmic-initial-setup gained an automatic updates page using the same bindings (cosmic-initial-setup commit 282c01a), and the old update notification toggle was deliberately removed (cosmic-initial-setup commit 973f17c).

Who it affects: Pop!_OS users going through first-run setup or changing update policy. The removed toggle is intentional, so any workflow that depended on it needs the new schedule controls instead.

Lock screen and greeter hardening

The greeter hides the password prompt while you are typing a username (cosmic-greeter commit b7b59d4). The locker now rate-limits PAM retries to at least 500 ms per attempt (cosmic-greeter commit 84a04d3, PAM_MIN_ATTEMPT_DURATION). Bluetooth agent code answers authorize_service with the paired state (cosmic-applets commit 6f89bfa, cosmic-settings commit 057e2e7).

Who it affects: everyone at login, and more specifically anyone who mistypes a username on the first try or leaves a Bluetooth device paired but untrusted.

Smaller changes

Performance and internals

  • cosmic-comp removed internal mutexes and atomics from CosmicStackInternal, CosmicWindowInternal, and ContextMenu (cosmic-comp commit e10d1f9, cosmic-comp commit 73217f3, cosmic-comp commit 2f577fa); the Wayland connection buffer was enlarged (cosmic-comp commit 9b4296b).
  • cosmic-comp-ipc is a new crate for passing session environment variables over a Unix socket using JSON messages (cosmic-comp commit f2beba6); cosmic-session now uses it (cosmic-session commit efc36fc).
  • cosmic-files syncs copies in batches so large transfers do not exhaust open file descriptors (cosmic-files commit a7164ac, cosmic-files commit 84a32e1), reuses descriptors for batch sync (cosmic-files commit e03001c), and syncs copies before deleting sources (cosmic-files commit 3868a8e).
  • cosmic-files falls back to gio copy when reads from gvfs FUSE paths fail (cosmic-files commit 3204c6a) and keeps serving FileManager1 after the zbus 6 upgrade (cosmic-files commit 70f33d9).
  • cosmic-panel restarts applets killed by a signal and cleans up the client of one that exited (cosmic-panel commit 160a951, cosmic-panel commit 45340f5).
  • cosmic-store refreshes AppStream data for system Flatpak remotes (cosmic-store commit 8846658); cosmic-term displays every monospace font on the system (cosmic-term commit b209f70).
  • The whole stack moved to zbus 6 (cosmic-comp cosmic-comp commit 46b26e6, cosmic-session cosmic-session commit 3fe5d42, cosmic-settings-daemon cosmic-settings-daemon commit e3040f1, and others). cosmic-comp raised its MSRV to 1.95 (cosmic-comp commit 4d79aa0).

Visual polish

  • Panel border radius and padding now derive from the theme instead of fixed overrides (cosmic-panel commit 71c49f4). An unset override shows as “None” in the default schemas. The default dock size changed too (cosmic-panel commit add4154).
  • cosmic-files shows mounted drives in the move/copy-to dialog (cosmic-files commit 9e4d406) and image and video thumbnails in Trash (cosmic-files commit 8475dfd).
  • The audio applet no longer stretches album art and truncates long track titles at 32 characters with ContentFit::Contain (cosmic-applets commit dc252e3).
  • cosmic-edit uses the selected text as the new find value (cosmic-edit commit a741508) and fixes the highlight rectangle drawn at X position 0 while horizontally scrolled (cosmic-edit commit 9d19fd9).
  • cosmic-comp fixes title truncation to respect character boundaries (cosmic-comp commit 683ae8b) and replaces paragraph separators in window titles (cosmic-comp commit 59d98e5).
  • cosmic-settings tracks natural scrolling in the touchpad panel (cosmic-settings commit af9416c) and adds font and icon selection improvements in Appearance (cosmic-settings commit 74185d1).

Developer tools

  • cosmic-settings has a CLI path straight to the keyboard settings: keyboard shortcuts and keyboard shortcuts custom subcommands (cosmic-settings commit 5793cbb).
  • cosmic-osk gained a CI workflow for format, lint, and test (cosmic-osk commit 3dfc0b0).
  • The Nix flake builds with Rust 1.95 (cosmic-comp commit e716e74); the epoch version-update.sh script was updated (epoch commit 16883d0, cosmic-app-library commit c19e73e).
  • cosmic-session only imports SSH_AUTH_SOCK when it is actually set (cosmic-session commit 1de865b).

Content and smaller apps

cosmic-player, cosmic-randr, cosmic-screenshot, cosmic-viewer, cosmic-monitor, and cosmic-workspaces-epoch are version bumps plus translation updates in this epoch. cosmic-viewer has no functional commits beyond the version update and one Weblate batch (cosmic-viewer commit 57b134c, cosmic-viewer commit df2d02b, cosmic-viewer commit 067c4fd). pop-launcher moved to zbus 6 and updated dependencies (pop-launcher commit df5151e, pop-launcher commit 4111617).

Bug fixes

Compositor, display, input

  • Pointer motion uses the new position in PointerMotion, and is_legal uses the correct position (cosmic-comp commit 14513fa, cosmic-comp commit b9bd128).
  • Mismatched output groups are filtered (cosmic-comp commit de9a66d), submenus are not placed inside a tile when their parent is outside (cosmic-comp commit cfd6a50), and tiling no longer panics when focusing with an empty focus stack (cosmic-comp commit 6e29ee6).
  • Toplevel info updates when window geometry changes (cosmic-comp commit bb74e8a); saved sizes that no longer fit a group are not restored (cosmic-comp commit 66524a0).
  • Focus is repaired when there is no target but a session lock is active (cosmic-comp commit ec674cd); seats send wl_surface.enter and leave to client cursor surfaces (cosmic-comp commit 9cde272).
  • Output manager done events are scoped per output (cosmic-comp commit 2c30140), surface threads are joined on device_changed (cosmic-comp commit eeca8b0), and the compositor no longer sleeps its Wayland thread with an event queued (xdg-desktop-portal-cosmic commit 2d70101).
  • Screen sharing rejects a request with no selected source (xdg-desktop-portal-cosmic commit 67624f8) and avoids a double-response panic (xdg-desktop-portal-cosmic commit 3dbe884).

Login and sessions

  • Greeter hides the password field while a username is typed; locker rate-limits bad PAM attempts as described above.
  • cosmic-settings-daemon restores audio controls after PipeWire restarts (cosmic-settings-daemon commit a8d9d84) and fixes Bluetooth headset control on Ubuntu 26.04 (cosmic-settings-daemon commit 212f39a). It no longer divides by zero when no keyboard layout is set (cosmic-settings-daemon commit 108e095).
  • cosmic-initial-setup no longer panics when changing scale with no display loaded (cosmic-initial-setup commit 27b79e7).
  • Cosmic Settings re-registers the Bluetooth agent when bluetoothd restarts (cosmic-settings commit e82cbc4) and keeps the active audio device when the one before it is removed (cosmic-settings commit aaaf4e0).

Apps

  • App-list actions no longer do nothing when an item is selected (cosmic-applets commit ef6c9e6), and the applets no longer abort or wait forever on Wayland errors (cosmic-applets commit ecb6b61) or when the workspace manager disappears (cosmic-applets commit cb3ea91).
  • VPN state stays in the scrollable area (cosmic-applets commit 779f920); the panel redraws when an applet’s window goes away (cosmic-panel commit cc0bdb3).
  • cosmic-store remembers scroll position when opening app details (cosmic-store commit 18ba81b) and resets it on page switches (cosmic-store commit 5b9bbed).
  • File operations write every chunk in full (cosmic-files commit 76823cb), propagate sync errors (cosmic-files commit 3d3e70b), skip cleanup only when appropriate (cosmic-files commit 84ffd15), and do not follow a symlink given as the copy root (cosmic-files commit 8166f67).
  • cosmic-term no longer pastes while the search or context drawer is open (cosmic-term commit b0ab376, cosmic-term commit a5e1bb5).
  • cosmic-settings preserves interface and base state across bundle changes (cosmic-settings commit f8816b0), caps theme names (cosmic-settings commit b8a3b6c), truncates bundle titles at 40 characters (cosmic-settings commit b2db1bf), shows the current wallpaper on inactive theme cards (cosmic-settings commit 6aaf30d), and fixes a search navbar panic (cosmic-settings commit ee6ea8a).

Security

  • cosmic-files bumps zip-rs to 9.x (cosmic-files commit 4efe802).
  • The lock screen enforces the 500 ms PAM attempt floor, which limits rapid-fire guessing.
  • Screen sharing requires an explicit source selection and handles a duplicate dialog response safely.

Libraries and build

  • jxl-rs replaces the previous JPEG XL path in several apps; the pipeline uses PipeWire from crates.io in the portal (xdg-desktop-portal-cosmic commit 7b0864c) and jiff 1.0 (xdg-desktop-portal-cosmic commit ce75265).
  • cosmic-settings applies theme reset settings to packaged defaults (cosmic-settings commit b7920db) and no longer pins a cosmic-protocols revision (cosmic-settings commit b68d89d).
  • Debian packaging for cosmic-settings and initial setup builds with the pop-os feature (cosmic-settings commit 4d515f2, cosmic-initial-setup commit 282c01a).

Known regressions and deferred work

The release body is empty, so this post is reconstructed from commits and may miss packaging-only changes. The update notification toggle was removed on purpose, not deferred. Theme bundles are new in this epoch and are the most likely place for migration rough edges. There is no published list of known regressions for the tag yet.
