KDE Plasma 6.8 Beta: what actually changed since Plasma 6.7

KDE Plasma 6.8

The first beta is out, feature freeze started September 10, and the final release lands October 14. Here is everything noteworthy, everything minor, and the bug fixes worth knowing about, sorted into sections you can actually read.

As of September 10, 2026, Plasma 6.8 Beta 1 (versioned 6.7.90) is out. The final release is due October 14, coinciding with KDE’s 30th anniversary. The hard feature freeze and soft UI/string freeze took effect at this beta, so this covers practically the whole release: fixes and translations will still land before the final, new features will not. Beta 2 arrives September 24.

Things worth your attention

Window management and compositor

KWin now applies shadows, rounded corners, and outlines to client-side-decorated (CSD) windows that lack their own decoration — think Steam, Discord, and Electron apps. This is handled by a new Breeze decoration option called “shadow-only decorations” (KWin MR 583, KDE bug 504225). The effect is consistent across the desktop and works on Wayland.

Triple buffering is now enabled by default on NVIDIA GPUs. The bugs that blocked this in the past have been fixed, so NVIDIA users should see smoother rendering and lower latency (KWin MR 9472).

KWin internally uses only OpenGL ES now. The proprietary NVIDIA driver and older GPUs required this path anyway, and it turns out to be sufficient for everything KWin needs. Vulkan will replace it in a future release (KWin MR 9488).

Multi-GPU systems with external GPUs get a significant performance boost — up to 80% in some scenarios — because KWin now handles GPU selection more intelligently (zamundaaa.github.io write-up, July 2026).

HDR support expanded: KWin now supports the HLG transfer function in addition to PQ (KDE bug 508817). ICC profile handling for HDR content improved (KDE bug 524038).

KWin’s screenshot and screen-casting paths got faster and smoother on high-refresh-rate displays (KWin MR 9756, KDE bug 524129). Screen-casting latency dropped by one frame across the board, including the built-in RDP server (KPipeWire MR 274).

The Overview effect is slightly easier to trigger with a four-finger swipe gesture (KWin MR 9486).

Audio recording in Spectacle

Spectacle can now record audio during screen recordings. You can choose system audio (what the computer plays), microphone audio, or both (KDE bug 474798). This was the most-requested missing feature for screen recording and finally lands in 6.8.

Remote desktop improvements

KRDP, Plasma’s built-in RDP server, now supports bi-directional clipboard syncing (KRDP MR 213). Previously only the server’s clipboard was shared one-way to the client.

The RDP server can now dynamically adjust its quality level to match available network bandwidth, keeping frame rates consistent (KRDP MR 238).

Remote desktop sessions persist correctly across disconnects, and the System Tray icon for a severed connection now disappears as expected (KRDP MR 234).

A notification now appears when a pre-authorized app starts remote-controlling the system (KDE bug 571).

Lock screen and authentication

The lock screen got a significant overhaul. You can now select which authentication method to use when multiple are available (password, fingerprint, etc.), and the button alignment is improved across languages (Plasma Desktop MR 3689, Plasma Workspace MR 6542, KScreenLocker MR 318, Plasma Desktop MR 3951).

Lock screen notifications now trigger for all GPUs, not just the primary one (KWin MR 9768).

Auto-login works in Plasma Login Manager on distros with older systemd versions like KDE neon (KDE bug 522006).

System Settings search in English

When using the system in a non-English language, you can now search for System Settings pages using English keywords in KRunner and Kickoff, not just the local language (System Settings MR 418). For example, searching “mouse” finds “Souris” on a French system.

Wallpaper and theming

The default wallpaper changed from Waterfall to Hanabi (Breeze commit 0b1e6ce).

SVG-based wallpapers now fully participate in the automatic dark/light wallpaper switching feature (KDE bug 519168).

Wallpaper slideshows can be configured to not change automatically — you switch manually via the desktop context menu or a global shortcut (KDE bug 518669).

If all wallpaper plugins are broken, missing, or misconfigured, Plasma now launches with a plain background instead of failing to start (KDE bug 524875).

Union, KDE’s new CSS-based theming system, gained initial support for styling QtWidgets apps (Union MR 270). This is a tech preview — visual glitches are expected and known. Dolphin and other QtWidgets apps can now be themed through Union, unifying theming across QtQuick and QtWidgets apps.

Breeze styling for GTK4 apps’ menus and window borders improved (Breeze GTK MR 104).

Dark GTK2 theme detection improved, so old GTK2 apps get legible icons more reliably when using a dark color theme (Breeze MR 144).

System Monitor upgrades

System Monitor can now measure VRAM usage as a percentage of total VRAM, not just absolute bytes (KSystemStats MR 135). This mirrors how RAM usage is displayed.

You can set CPU affinity for processes — pin a process to specific cores or core groups (KSystemStats MR 420). This is a power-user feature for fine-tuned workload placement.

The Process Table view shows fractional axis values when needed, and the tree view has better text alignment (KDE bug 521041, KDE bug 442095).

System Monitor graphs request tabular (monospaced) numerals for legends when the font supports them, improving alignment (KQuickCharts MR 109).

Notifications and clipboard

Notifications now slide in from off-screen instead of fading in, with a more natural easing curve (KDE bug 522276). The sliding animation was refined after its initial introduction.

When you copy text marked as a secret (like a password), the clipboard history UI now shows a clear warning instead of hiding the entry and leaving you wondering why nothing appeared (KDE bug 508326).

The screen recording indicator only appears while recording is actually in progress, fixing cases where apps opened sessions early but started recording later (Portal MR 597).

The “Bouncing app icon” launch feedback animation uses a better physics model, easing curve, and higher frame rate (KWin MR 9487).

Input and accessibility

The Emoji Selector updated to Unicode 17, adding new emoji like 🫨 🫪 🐦‍🔥 🏴‍☠️ (KDE bug 3849). The emoji grid now has resize controls (Plasma Addons MR 3878).

Press-and-hold for alternative characters now triggers after 600 ms instead of 200 ms, making accidental activation much harder (KDE bug 157).

Dwell clicker support landed for accessibility on Wayland — you can click by hovering without pressing a physical button (Phoronix coverage).

Stylus interaction works in Overview and Custom Tiling overlays on Wayland (KDE bug 468396, KDE bug 522677).

System tray icons that open widgets now stay visible until the widget popup closes, so you can click a second time to dismiss it (KDE bug 521115).

Network and connectivity

Connecting to an enterprise Wi-Fi network for the first time takes you directly to the credential entry page (Plasma NM MR 635).

Wireless access points can be configured to automatically select a channel in the Networks System Settings page.

Bluetooth widget’s “Configure” button moved to the standard position for consistency (KDE bug 516134).

StrongSwan VPN support added EAP-TTLS authentication (Plasma NM MR 636).

Flatpak version of Microsoft Edge is now supported in Plasma Browser Integration (KDE bug 521109).

Performance and resource usage

Discover’s background notifier process uses much less memory when checking for updates (KDE bug 509180).

Plasma startup is slightly faster by avoiding unnecessary work when loading wallpapers (Plasma Workspace MR 6898).

SVG caching improved in Frameworks 6.30, increasing speed and reducing video memory usage (KDE bug 115).

Spectacle dropped the OpenCV dependency; blur effects are now implemented without it (Spectacle MR 561, KQuickImageEditor MR 53).

Thumbnail rendering in notifications and the Activities sidebar uses fewer resources (Plasma Workspace MR 6966, Plasma Desktop MR 3967). The Trash widget also uses less memory (Plasma Desktop MR 3965).

Disabling a System Tray widget frees its memory immediately, not just after restart (Plasma Workspace MR 6983).

The clipboard’s “Keep selection and clipboard the same” setting no longer breaks multi-cell copying in LibreOffice Calc (KDE bug 505209) and no longer unnecessarily disables other settings (KDE bug 492840).

Calendar and clock

Digital Clock widget text for calendar events is now fully selectable (KDE bug 433668).

Digital Clock requests tabular numerals, preventing width changes as time passes (Plasma Workspace MR 6797).

The Digital Clock tooltip expands to fit long text instead of overflowing (KDE bug 6950).

Drawing tablet and input devices

The Drawing Tablet settings page has a less awkward dialog for configuring pen button mappings (KDE bug 524720).

Amharic virtual keyboard layout added (Plasma Keyboard MR 118).

System Settings and configuration

You can disable autostart entries without deleting them (Plasma Workspace MR 6951).

The Remote Desktop System Settings page works on small/narrow window sizes like phones (KRDP MR 208).

Non-default settings highlighting works on the Remote Desktop page (KRDP MR 232) and the Plasma Search page (Plasma Desktop MR 3973).

The “Report a Bug in the Current Page” feature works for pages that list a bug reporting URL even if they didn’t come from KDE (System Settings MR 412).

KWin prevents setting a resolution so low you’d break your system and be unable to recover (KWin MR 9765).

Removed: X11 session

Plasma 6.8 drops the X11 session entirely — Wayland is now the only session. X11 applications still run via Xwayland. The X11 session will be supported by KDE into early 2027 through Plasma 6.7 bugfix releases. This is the biggest architectural change in Plasma’s 30-year history (announcement blog post, Nov 2025).

Smaller changes

Visual polish

  • Comboboxes in Plasma now use the active theme for their popups instead of hardcoded Breeze styling, and menu highlights no longer animate (Libplasma MR 1547, Libplasma MR 1550).
  • In-window dialogs in Kirigami apps are better highlighted against window content in dark themes (KDE bug 447965).
  • Audio Volume widget popup starts large enough to fit all content without scrolling (KDE bug 522654).
  • Cursor feedback effects dodge screen edges so they’re always fully visible (KDE bug 498068).
  • Menu Editor has fewer visual frames (Menu Editor MR 59).
  • “CD and DVD” category in Discover renamed to “Disc Burning” to match the FreeDesktop spec (Discover MR 1350).
  • Breeze icon theme adds icons for Android app bundle files (KDE bug 508430) and Typst documents (KDE bug 554).
  • System Tray crash icons: only one sad-face icon appears when many crashes occur; clicking it shows the full list (KDE bug 420443).

Developer tools and internals

  • showConfigurationInterface() now works in Plasma scripting (Plasma Workspace MR 6977).
  • System Settings Proxy page rewritten in QML for Plasma Mobile compatibility (kio-extras MR 536).
  • KGlobalAccel internals refactored: dropped X11 bits, normalized shortcut formats, improved lookups (multiple MRs).
  • Kirigami tab bars respond to scroll and standard tab-switching shortcuts (Kirigami MR 2123).
  • Frameworks 6.30 requires Qt 6.11 and KDE Frameworks 6.30 (version bumps across all modules).

Content and smaller apps

  • Ethiopian calendar (13-month) added to alternate calendars (Plasma Addons MR 1079).
  • Nepali (Bikram Sambat) and Ethiopian calendars supported in Plasma Addons (Addons commit 1445c41, Addons commit 076c13a).
  • Vietnamese lunar calendar shows text in Vietnamese regardless of system language (KDE bug 521787).
  • Time zone offset calculations fixed for half-hour offsets earlier than local time (KDE bug 522037).
  • Calendar widget no longer changes displayed date when dragged between screens (KDE bug 472360).
  • Weather widget centers location label, improves badge positioning, uses EnvCan icon codes, and fixes layout issues (multiple MRs).
  • Color Picker widget sizing fixes (KDE bug 522377, KDE bug 517052).
  • KDE Connect SMS app permissions page ported to new Forms (flatpak-kcm commit 1c4d978).
  • KWallet stops spamming logs in non-default configurations (KDE bug 524500).

Performance and technical

  • KWin’s “press and hold for alternative characters” implementation prioritizes app compatibility, fixing many bugs (KDE bug 152).
  • Spectacle no longer includes tooltip with image dimensions in final screenshot when accepting region by double-click (KDE bug 513715).
  • Mic tester records at system sample rate instead of forcing 44.1 kHz (KDE bug 523693).
  • Emulated Input protocol version 1.6 supported (KWin MR 9112).
  • KWin variable refresh rate crash on multi-monitor setups fixed (KDE bug 521909).
  • Full-screen video playback performance improved in Chromium-based apps (KDE bug 521960).
  • KWin no longer leaks CAP_SYS_NICE to child processes, fixing Bubblewrap sandboxing (KDE bug 521013).
  • XWayland apps behave correctly after XWayland crashes and restarts (KWindowSystem MR 220).
  • Task Manager hardened against maliciously-crafted .desktop files (Plasma Workspace MR 6817).
  • ksystemstats_intel_helper hardened against path traversal (KDE bug 141).

Bug fixes

Compositor, display, and input

  • Fixed most common Plasma crash (multi-screen related) (KDE bug 500044).
  • Fixed second-most-common crash on logout (Plasma Workspace MR 6973).
  • KWin crash on lock screen with NVIDIA GPU fixed (KDE bug 520842).
  • KWin crash with DisplayLink monitors fixed (KDE bug 520361).
  • Screens on hybrid NVIDIA/AMD laptops no longer freeze (KDE bug 521727).
  • Shader-based KWin effects (Burn My Windows) restored (KDE bug 521774).
  • Color-related effects (color blindness correction, screen inversion) restored (KDE bug 521737).
  • Corrupted visuals on rotated screens and older AMD GPUs fixed (KDE bug 521878, KDE bug 521764).
  • SDR content desaturation in HDR mode fixed (KDE bug 521759).
  • ICC profile color correctness fixed (KDE bug 522301).
  • KWin lag/hang with poorly-optimized Proton games fixed (KDE bug 522005).
  • Pointer movement in VMs with non-accelerated graphics fixed (KDE bug 524280).
  • Screens incorrectly notifying disconnect/reconnect loop after sleep fixed (KDE bug 521826).
  • Drag-and-drop of desktop files/folders between screens restored (KDE bug 521713).
  • Variable refresh rate crash on multi-monitor setups fixed (KDE bug 521909).
  • Right-to-left languages no longer prevent force-quitting processes in System Monitor (KDE bug 522233).

Login and sessions

  • Screen locker security issue fixed: manual config to turn off screen after “don’t require password” period no longer fails to lock (KDE bug 523504).
  • Auto-login works on older systemd versions (KDE bug 522006).
  • Logout sound no longer delays logout more than necessary (KDE bug 491745).
  • Wallpaper slideshows now remember last-seen wallpaper instead of restarting from first (KDE bug 512559).
  • Activity deletion no longer crashes Plasma; switches to next activity instead (KDE bug 521124).
  • System Monitor no longer crashes when quitting with column config dialog open (KDE bug 491000).
  • DrKonqi crash handler no longer crashes in a loop on severely broken systems (KDE bug 524048).

Apps

  • Discover no longer gets stuck checking for updates when Snap backend present but no upgradeable Snaps (KDE bug 524077).
  • Discover terminates all processes properly on quit (Discover MR 1393).
  • Discover remembers review usefulness ratings and doesn’t let you resubmit (KDE bug 521866).
  • Discover only offers .deb packages on distros that support them (Plasma Desktop MR 3957).
  • Discover fixes: updates stuck when fwupd unavailable (KDE bug 521682), Snap backend signals completion correctly (KDE bug 524077), AppStream preview backend added (Discover commit 4a02b82), package review usefulness persistent (KDE bug 521866).
  • Non-KDE apps no longer crash when closing a dialog (KDE bug 523039).
  • Calendar widget no longer shows info buttons for alerts that do nothing (KDE bug 519676).
  • Weather widget info buttons only appear when functional (KDE bug 519676, Addons commit d13f147).
  • Color Picker widget layout regressions fixed (KDE bug 522377).
  • System Monitor Configure Columns popup is now a traditional window, fixing scroll glitch (KDE bug 517723).
  • Networks widget: connecting to uneditable network no longer makes others look connected (KDE bug 461028).
  • Audio Volume widget shows correct panel icon under unusual conditions (KDE bug 422).
  • Remote desktop connection icon disappears correctly after unexpected disconnect (KDE bug 234).
  • RDP server systemd regression fixed (KDE bug 521776).
  • Chromium apps no longer freeze when another window forced “Keep Above Others” (KDE bug 521687).
  • Plasma no longer crashes after ejecting audio CD from Dolphin/Audex (KDE bug 522051).
  • Kickoff/Kicker: multiple widgets can all return search results for not-yet-installed apps (KDE bug 511220).
  • System Settings sub-category sidebar switching fixed in less-common interaction modes (KDE bug 415).
  • Digital Clock “Today” button highlights correct day in time zones later than UTC (KDE bug 521114).
  • Screencast permission no longer requires identical screen setup to when permission granted (KDE bug 519122).
  • Portal dialog explanatory text shows correctly (KDE bug 584).
  • Icons-Only Task Manager no longer breaks from metadata.desktop in home folder (KDE bug 521247).
  • Weather widget no longer endlessly reloads after wake from sleep (KDE bug 517280).
  • System Monitor graphs show fractional axis values (KDE bug 521041).
  • Un-favoriting apps with weird characters works (KDE bug 520894).
  • Notification icon no longer gets stuck half-rotated (KDE bug 458156).
  • Screen Locking page translated label no longer reverts to English after save (KDE bug 521293).
  • Color Picker widget no longer overflows in Grouping widget (KDE bug 517052).
  • Media Frame widget no longer displays every other image sharpened (KDE bug 521534).
  • Choose Application window no longer percent-encodes filename characters (KDE bug 521748).
  • Mouse page in System Settings no longer has layout glitches in X11 (KDE bug 521992).
  • Networks widget Details tab text no longer overflows (KDE bug 522333).
  • KRunner Bookmarks provider returns results for 2-char queries, uses fewer resources (KDE bug 6764).
  • Clipboard widget Actions Configuration page margins improved (KDE bug 6779).
  • Secret keyboard shortcut (Meta+Ctrl+x) for clipboard actions removed (KDE bug 6773).
  • DrKonqi tells you when safe to close window (KDE bug 397).
  • Kameleon system service disabled by default (KDE bug 521793).
  • Pointer with software rendering no longer disappears when panel dodges windows (KDE bug 521953).
  • Force-quitting processes in System Monitor works with RTL languages (KDE bug 522233).

Security

  • Task Manager hardened against malicious .desktop files (Plasma Workspace MR 6817).
  • ksystemstats_intel_helper hardened against path traversal (KDE bug 141).
  • Screen locker locking logic fixed for edge-case configuration (KDE bug 523504).
  • Flatpak background service crash fixed when allowing app update via KDE portal (KDE bug 6686).
  • KWin no longer leaks CAP_SYS_NICE to child processes (KDE bug 521013).

Libraries and build

  • Qt version requirement bumped to 6.11 across all Plasma modules.
  • KDE Frameworks requirement bumped to 6.30 across all Plasma modules.
  • KGlobalAccel dropped X11 code paths, normalized shortcut handling.
  • KWin split into kwin_wayland and kwin_x11 (from 6.4) — X11 bits now fully removed.
  • Multiple modules ported to KConfigXT, QML modules, and modern CMake patterns.

Known regressions and deferred work

  • Union theming for QtWidgets apps has known visual glitches (acknowledged in announcement).
  • Location-based timezone setting deferred; depends on Date & Time KCM QML conversion (Plasma Desktop MR 3653).
  • Some accessibility features from third-party apps may not work as well on Wayland-only session.
  • Output mirroring issues being actively worked on.
  • Session restore and window position memory still being improved.
