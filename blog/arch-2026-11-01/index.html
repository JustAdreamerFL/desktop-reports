Arch Linux 2026.11.01: the November ISO in plain language

Arch Linux 2026.11.01

Monthly snapshot built around Linux 7.2.11, still carrying Archinstall 4.5, plus the PHP RCE and compromised-CA security fixes that landed in October. Existing systems need only pacman -Syu.

Arch Linux’s monthly snapshot for November is out as 2026.11.01. As usual, the ISO itself only matters for fresh installs; existing systems get the same packages through pacman -Syu. The headline this month is a kernel bump to Linux 7.2.11, with the security work that landed in October riding along.

Things worth your attention

Kernel jump to 7.2.11

The kernel package was built for Arch on October 31, with matching headers and documentation. Last month’s ISO shipped 7.2.7, so this is a steady point release bump rather than a major promotion. Linux 7.2 itself was released around mid-August, and the 7.2.11 point release carries the accumulated stable fixes since then. The ISO is x86-64 only and weighs in at 1.2 GB, the leanest Arch disc in a while.

Archinstall 4.5 carries over

Archinstall 4.5, which arrived in the repositories near the end of September, is still the guided installer on this snapshot. It picked up RT kernel variants, AArch64 support for GRUB and Limine EFI, optdepends handling for the linux-firmware package, and a switch of polkit to systemd-logind for the Hyprland, Sway, Niri, and Labwc profiles. Archiso, the toolset Arch uses to build its installation and live media, is at version 91.

Security work from October

The November ISO inherits two security fixes that landed on October 21. PHP needed to move to 8.5.12 or php-legacy to 8.3.36 to close two remote-code-execution holes, CVE-2026-109618 and CVE-2026-109619. The advisory singles out systems publicly serving PHP apps, so anyone running a public PHP service should confirm the version. On the same date, Arch pulled compromised certificates out of the eMudhra intermediate CA through ca-certificates-mozilla 3.131.1-1 or newer. Skipping that one leaves you open to man-in-the-middle attacks.

TPM2-unlocked LUKS caveat

Since mkinitcpio 42, the systemd hook includes systemd-pcryptsetup.service, which shifts the measured PCR values used to unlock a TPM2-backed LUKS volume. If you rely on TPM2-unlocked disk encryption, re-enroll your TPM2 key after upgrading, as documented in systemd-cryptenroll(1). This is a one-time manual step, not something the upgrade does for you.

AUR hygiene reminder

The June 2026 AUR incident, where a high volume of malicious package adoptions and updates forced the project to lock down new accounts, updates, and adoptions for a stretch, is still the defining security moment of the year. Tampered PKGBUILDs had installed malicious npm packages. Arch’s advice has not changed: read your PKGBUILDs, especially when you rely on an automated AUR helper. Do not trust the latest version of an AUR package by version number alone.

Smaller changes

Repository health

Levente “anthraxx” Polyák won a second two-year term as Project Lead in the June 2026 election, so the leadership side stays put. The role breaks deadlocks, enforces the Code of Conduct, and handles money through the SPI foundation.

Package breadth

The snapshot inherits the October repository state: kernel 7.2.11, Archinstall 4.5, and the accumulated core-stack, graphics, desktop, and application updates that landed across September and October. A fresh ISO is the front door; what you build inside is up to you.

Bug fixes

Per-package Arch bug reports track the rest. The kernel bump to 7.2.11 carries the accumulated stable fixes since 7.2.7. The PHP and ca-certificates updates are the security-relevant fixes this cycle.

Known regressions and deferred work

None listed yet.
