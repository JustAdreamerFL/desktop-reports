COSMIC Epoch 1.9.0: what actually changed since 1.8.0

COSMIC 1.9.0

System76 tagged a coordinated submodule bump that adds two new modules to the epoch: cosmic-osk, the on-screen keyboard, and cosmic-viewer, the image viewer. git-lfs becomes a required dependency.

As of September 23 2026, COSMIC Epoch 1.9.0 is tagged. GitHub marks it as pre-release with release notes pending, but the tag itself is the pin point. The diff between 1.8.0 and 1.9.0 is seven commits: it adds two new submodules (cosmic-osk and cosmic-viewer), bumps git-lfs as a required dependency, and updates every existing submodule. The real story is the on-screen keyboard and image viewer joining the epoch.

Things worth your attention

New modules: cosmic-osk and cosmic-viewer

Two new submodules joined the epoch for the first time.

cosmic-osk is the COSMIC On-Screen Keyboard. It has been in development for over a year (55 commits) and uses libei sockets instead of the older virtual-keyboard-unstable-v1 protocol. It supports multiple keyboard layouts that change to match the group sent by the compositor, gamepad input via gilrs, drag on touch input, and a cosmic-session-lock-layer-v1 protocol for the lock screen. Settings control when the OSK appears, and checkboxes toggle gamepad and IME activation. The function row is hidden by default. A recent commit allows overriding the layer to be overlay, so the keyboard can appear over fullscreen apps. The OSK also implements dead key display improvements and xkb symbol-based key naming per level. Inline examples of new UI strings and icons: “Hide function row by default”, “Settings for when to show OSK”, “Add guide for controller bindings”, “Use symbols for some keys”, “Add gamepad icons”, and “Improve modifiers support”.

cosmic-viewer is the COSMIC Image Viewer. It has 203 commits and its own 1.9.0 tag. It includes a settings drawer for theme and startup preferences, text annotation with placeholder fixes, and a toolbar that uses the Primary style. A recent commit allows opening just a single file.

Who it affects: anyone who has been waiting for a native on-screen keyboard and image viewer in COSMIC. The OSK is the first to use libei rather than the deprecated virtual-keyboard protocol.

Build and packaging

git-lfs is now a required dependency. cosmic-edit uses it for PNG files, so distros packaging the epoch need to include it. The README build instructions were updated to reflect this. The justfile and version-update.sh script were also updated.

Submodule bumps

Every existing submodule received a version bump: cosmic-applets, cosmic-applibrary, cosmic-bg, cosmic-comp, cosmic-edit, cosmic-files, cosmic-greeter, cosmic-initial-setup, cosmic-launcher, cosmic-monitor, cosmic-notifications, cosmic-osd, cosmic-panel, cosmic-player, cosmic-session, cosmic-settings, cosmic-settings-daemon, cosmic-store, cosmic-term, cosmic-workspaces-epoch, and xdg-desktop-portal-cosmic.

Smaller changes

Performance and internals

  • cosmic-osk uses libei socket instead of virtual-keyboard-unstable-v1 (a1a57a2)
  • cosmic-osk supports multiple layouts with compositor-driven group switching (b7af9c0)
  • cosmic-osk implements gamepad support via gilrs with mouse emulation (52f2934)
  • cosmic-osk adds drag on touch input (4a757d6)
  • cosmic-osk blurs just the floating keyboard with rounded rectangle strips (fb7a36d)
  • cosmic-osk hides function row by default (22885b1)
  • cosmic-osk replaces settings link button with checkboxes for gamepad and IME activation (5f6c118)
  • cosmic-osk allows overriding the layer to be overlay (38e9625)
  • cosmic-viewer adds settings drawer for theme and startup
  • cosmic-viewer allows opening just a single file

Developer tools and packaging

  • git-lfs added as required dependency (#1324)
  • justfile updated
  • version-update.sh updated

Bug fixes

  • cosmic-osk fixes wrong height on startup (5feb77f)

Image viewer

  • cosmic-viewer fixes toolbar should use Primary style
  • cosmic-viewer fixes text / select and move

Known regressions and deferred work

  • cosmic-osk and cosmic-viewer are new modules and may have rough edges
