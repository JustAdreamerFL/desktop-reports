KDE Plasma 6.8.2: what actually changed since 6.8.1

KDE Plasma 6.8.2

The second stable 6.8 update disables troublesome Wayland commit timing, fixes multi-GPU rendering and Sticky Keys, and repairs desktop widgets. Remote desktop, Discover, and the login manager also get corrections.

Plasma 6.8.2 is a stable bugfix release, published on October 27, 2026. Compared with our 6.8 beta report, the feature-development period is over: this post covers the fixes since 6.8.1, not the whole 6.8 feature set. KDE has published the announcement, full changelog, and source downloads. Distribution packages may arrive later; there is no new feature-freeze milestone here.

Things worth your attention

Graphics and the compositor

KWin disables Wayland frame timing by default, fixing VRR problems and an NVIDIA Vulkan driver freeze. The commit explains why: a mechanism intended to help frame pacing was causing VRR problems, and an NVIDIA Vulkan driver bug could freeze mpv in some situations. This matters to people using variable-refresh displays or that playback path. The code still has an opt-in through KWIN_WAYLAND_SUPPORT_COMMIT_TIMING_V1=1; the default is now off.

Multi-GPU rendering gets two separate repairs. KWin checks buffer types more correctly in MultiGpuSwapchain and fixes synchronization when copying through EGL (buffer-type check, EGL copy synchronization). The direct-scanout device check also moves to the compositor. These changes concern systems where rendering and display output involve different GPUs, rather than promising a general frame-rate increase.

The DRM backend stops using post-blend offloading when color pipelines are unsupported (unsupported color pipelines), and disallows it on the legacy path. It also retries color-pipeline matching at the next hardware block. These are corrections to hardware color processing, not a newly enabled HDR feature.

Input and accessibility

Sticky Keys now latches and locks modifiers on key release rather than key press (modifier timing fix, key-release handling). The old ordering let XKB clear a modifier that the accessibility filter had just locked. The commit gives a useful example: pressing Shift twice and then typing a b c produced Abc instead of ABC. People who use Sticky Keys to avoid holding down modifiers should get the persistent state they requested.

KWin also preserves an application’s keyboard layout after its last window closes. This concerns per-application layout users. The Wayland pointer-constraints implementation fixes overwritten state, and the virtual keyboard’s D-Bus API reports its visibility correctly, which matters to programs integrating with the on-screen keyboard.

Remote desktop and recording

KRDP’s Plasma screencast session switches from the old fake-input path to libei. The commit identifies mapping pointers to individual screens as a reason for the change. That is relevant to remote-control users with multiple monitors; it is not a claim that this update adds every input-device type libei can support.

KRDP now starts with the client’s requested desktop size and listens for a portal response before making the request. It also stops tracking progressive frames while acknowledgements are suspended, a change linked to acknowledgement handling.

In kpipewire, the libx264 encoder is explicitly told the stream’s frame rate (frame-rate fix), and an encoded stream honors a requested size set before startup. These fixes are in the recording and streaming library used by Plasma tools, rather than new controls in Spectacle.

Shell, launchers, and desktop files

Plasma Desktop fixes disappearing desktop icons. Folder View’s row and column arrangement settings now match their actual behavior (row and column arrangement). The Pager keeps desktop labels and window icons bound to its model (label and icon binding, icon binding, model binding), so those representations stay connected to the underlying data.

Plasma Workspace puts running tasks in the positions of their launchers (task positioning) and re-filters launchers when a window changes screen. Kicker migrates the old favorite-ID format to the new one (favorite-ID migration). These are corrections for existing desktop and panel setups, not a redesigned Task Manager.

Login and session handling

Plasma Login Manager avoids autologin when someone explicitly switches to the greeter. People choosing the login screen should not be sent back through automatic login. Its settings module also checks configuration size before truncation, checks the child process’s exit status, and clears supplementary groups. Those changes matter to administrators and distributions shipping this login manager.

Smaller changes

Performance and internals

  • libksysguard limits the Line Chart applet to 2,000 data points (data-point limit). This bounds the chart’s displayed history rather than changing system-wide sensor collection.
  • KWin fixes a rendering-performance problem in the Touch Points effect and stops flipping screenshots on the CPU side.
  • KWin’s virtual backend takes the target presentation timestamp into account. Its animation timeline no longer limits animation steps on software renderers, linked to animation step handling.
  • Plasma Bigscreen improves homescreen blur performance.

Visual polish

Oxygen window-decoration buttons no longer look lumpy in certain fractional-scaling configurations (button scaling fix). KWin corrects startup-feedback icon sizing, including a 16-by-16 base icon size. Activities use cropped wallpaper previews instead of stretching them. Plasma Welcome corrects pixelation of its konqi-30.png image (image pixelation fix).

The Digital Clock preserves the system font’s OpenType features for the time (font feature preservation). PlasmaCore tooltips no longer lower label opacity when there is no heading (tooltip opacity fix). Kickoff ties sidebar spacing to its compact-list style (sidebar spacing), and Task Manager labels can wrap anywhere (label wrapping).

Developer tools and diagnostics

KWin adds KWIN environment variables to its support information and prints them before Wayland startup (support information, startup output). This gives bug reporters and developers a record of compositor overrides. Powerdevil includes the error code when a backlight-brightness job fails, linked to error-code reporting.

Union initializes element queries, indicator values, and tab spacing at construction. Its widget output also scales animation duration with the configured animation speed (animation duration scaling). These are changes to the theming implementation, not a new public styling language.

Content and smaller apps

Plasma Addons restores animated images in tiled wallpapers, repairs adding files and folders to Media Frame, and makes Picture of the Day previews match the “Scaled”, “Centered”, and “Tiled” modes (wallpaper preview modes). Those are the concrete options affected, rather than a new wallpaper collection.

The Web Browser widget reapplies its fixed zoom factor after each page load (zoom factor fix) and allows pages to read and write the clipboard (clipboard access). Kup fixes the checkbox connection for “Exclude user-level Flatpaks” (checkbox connection).

Plasma Mobile respects disabled animations for Quick Settings labels and lock-screen PIN dots, and makes its shell usable with Qt Quick’s software renderer. Bigscreen reworks homescreen rows and tiles, fixes its display settings, and sets “Show Virtual Keyboard” to “With Touch, Tablet, and Mouse”.

Bug fixes

Compositor, display, input

KWin stops hidden scene items from occluding other content (hidden item occlusion). It makes the OpenGL context current when grabbing the cursor, guards against resizes in EGLPlatformContext::swapBuffers() (swapBuffers resize guard), and fails makeCurrent() when the context has failed. Picture-in-picture surfaces are lowered in the stack (stack lowering).

Output identification uses the output name and EDID identifier instead of the raw EDID. The output configuration store can generate a completely new configuration (new configuration generation). KWin also adds a missing DPMS event filter and reloads screen-edge configuration when TouchTarget changes.

Sliding notifications handle instant animation speed correctly (animation speed fix). The dwell clicker stays open after a click when pinned (pinned dwell clicker). Kicker uses its containment’s screen when limiting popup size (popup size limit).

Login and sessions

Besides the greeter fix above, Plasma Workspace resets its entered-edit-mode state at startup (edit-mode state reset). Bigscreen fixes lock-screen state handling, a power-management inhibition failure that could occur at boot, and selection of the wrong desktop file when swapping sessions.

Apps and widgets

Discover’s update model reacts when resources disappear (resource disappearance handling). Its fwupd backend no longer passes the backend object to the connection thread, and its hidden desktop entries get X-KDE-AliasFor (hidden desktop entries).

Audio Volume plays feedback when increasing or decreasing volume (volume feedback), using the configured sound theme (sound theme). KWin’s system bell also updates its sound theme when settings change. The Battery Monitor initializes its switch state on first opening (switch state initialization), and Info Center avoids reading properties from a null battery.

Plasma notification markup accepts single-quoted attributes (markup attributes). Image wallpaper packages load correctly (wallpaper package loading), and the plain-color wallpaper derives the accent color from its configured color (accent color derivation). The calendar stops navigation before year 1 (calendar navigation).

The global play/pause shortcut no longer auto-repeats (shortcut auto-repeat). Media metadata fallbacks retain non-ASCII characters in titles and albums (metadata characters). The Activity Bar fixes Tab focus and arrow-key navigation (focus and navigation), the application menu automatically focuses its search field (search field focus), and restored applet layouts no longer take preferred size into account (applet layout sizing).

Security

Spectacle deletes its temporary OCR text file when the job finishes (OCR file cleanup). That reduces the lifetime of a file containing recognized screen text. Plasma Login Manager’s supplementary-group cleanup is also worth noting. The release announcement and changelog do not identify either as a CVE fix.

Libraries and build

System Monitor keeps its SplitView maximum width above its minimum width. qqc2-breeze-style restores contextual actions for TextArea (contextual actions) and closes the mobile text-action popup after an action. Union guards against a potential null dereference (null dereference guard), fixes TextArea background styling (background styling), adjusts list-delegate rounding (delegate rounding), and corrects menubar horizontal padding (menubar padding).

Known regressions and deferred work

None listed yet in the release announcement. Two deliberate rollbacks deserve separate mention: commit timing is disabled by default, as described above, and KWin reverts its default server-side drop-shadow rule for Steam (Steam shadow rule). The latter commit says the rule exposed visual flaws in Steam, including a more obvious black outline and child-window closing problems. A manually added or customized rule remains in the user’s configuration; the unmodified default goes away. This is narrower than removing shadow-only decorations generally.

Sources

KDE’s official Plasma 6.8.2 release announcement confirms the date and stable bugfix status. The complete per-module changes are in the 6.8.1 to 6.8.2 changelog, with published archives and signatures on the 6.8.2 source information page. Commit explanations in KDE’s official GitHub mirrors cover disabling frame timing, Sticky Keys modifier handling, KRDP’s libei port, and reverting the Steam shadow rule.
