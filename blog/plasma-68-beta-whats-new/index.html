KDE Plasma 6.8 Beta: what actually changed since Plasma 6.7

KDE Plasma 6.8

The first beta is out, feature freeze started September 10, and the final release lands October 14. Here is everything noteworthy, everything minor, and the bug fixes worth knowing about, sorted into sections you can actually read.

As of September 10, 2026, Plasma 6.8 Beta 1 (versioned 6.7.90) is out. The final release is due October 14, coinciding with KDE’s 30th anniversary. The hard feature freeze and soft UI/string freeze took effect at this beta, so this covers practically the whole release: fixes and translations will still land before the final, new features will not. Beta 2 arrives September 24.

Things worth your attention

Window management and compositor

KWin now applies shadows, rounded corners, and outlines to client-side-decorated (CSD) windows that lack their own decoration — think Steam, Discord, and Electron apps. This is handled by a new Breeze decoration option called “shadow-only decorations” (shadows for CSD windows, related report). The effect is consistent across the desktop and works on Wayland.

Triple buffering is now enabled by default on NVIDIA GPUs. The bugs that blocked this in the past have been fixed, so NVIDIA users should see smoother rendering and lower latency (triple buffering on NVIDIA).

KWin internally uses only OpenGL ES now. The proprietary NVIDIA driver and older GPUs required this path anyway, and it turns out to be sufficient for everything KWin needs. Vulkan will replace it in a future release (OpenGL ES only).

Multi-GPU systems with external GPUs get a significant performance boost — up to 80% in some scenarios — because KWin now handles GPU selection more intelligently (zamundaaa.github.io write-up, July 2026).

HDR support expanded: KWin now supports the HLG transfer function in addition to PQ (HLG transfer function). ICC profile handling for HDR content improved (HDR ICC profiles).

KWin’s screenshot and screen-casting paths got faster and smoother on high-refresh-rate displays (screenshot and screencast speed, related report). Screen-casting latency dropped by one frame across the board, including the built-in RDP server (screencast latency).

The Overview effect is slightly easier to trigger with a four-finger swipe gesture (four-finger swipe trigger).

Audio recording in Spectacle

Spectacle can now record audio during screen recordings. You can choose system audio (what the computer plays), microphone audio, or both (audio recording in screen recordings). This was the most-requested missing feature for screen recording and finally lands in 6.8.

Remote desktop improvements

KRDP, Plasma’s built-in RDP server, now supports bi-directional clipboard syncing. Previously only the server’s clipboard was shared one-way to the client.

The RDP server can now dynamically adjust its quality level to match available network bandwidth, keeping frame rates consistent.

Remote desktop sessions persist correctly across disconnects, and the System Tray icon for a severed connection now disappears as expected.

A notification now appears when a pre-authorized app starts remote-controlling the system.

Lock screen and authentication

The lock screen got a significant overhaul. You can now select which authentication method to use when multiple are available (password, fingerprint, etc.), and the button alignment is improved across languages (authentication method selection, button alignment).

Lock screen notifications now trigger for all GPUs, not just the primary one.

Auto-login works in Plasma Login Manager on distros with older systemd versions like KDE neon (auto-login on older systemd).

System Settings search in English

When using the system in a non-English language, you can now search for System Settings pages using English keywords in KRunner and Kickoff, not just the local language. For example, searching “mouse” finds “Souris” on a French system.

Wallpaper and theming

The default wallpaper changed from Waterfall to Hanabi (new default wallpaper).

SVG-based wallpapers now fully participate in the automatic dark/light wallpaper switching feature.

Wallpaper slideshows can be configured to not change automatically — you switch manually via the desktop context menu or a global shortcut.

If all wallpaper plugins are broken, missing, or misconfigured, Plasma now launches with a plain background instead of failing to start.

Union, KDE’s new CSS-based theming system, gained initial support for styling QtWidgets apps. This is a tech preview — visual glitches are expected and known. Dolphin and other QtWidgets apps can now be themed through Union, unifying theming across QtQuick and QtWidgets apps.

Breeze styling for GTK4 apps’ menus and window borders improved (GTK4 menu and border styling).

Dark GTK2 theme detection improved, so old GTK2 apps get legible icons more reliably when using a dark color theme (dark GTK2 icon legibility).

System Monitor upgrades

System Monitor can now measure VRAM usage as a percentage of total VRAM, not just absolute bytes. This mirrors how RAM usage is displayed.

You can set CPU affinity for processes — pin a process to specific cores or core groups. This is a power-user feature for fine-tuned workload placement.

The Process Table view shows fractional axis values when needed, and the tree view has better text alignment (fractional axis values, text alignment).

System Monitor graphs request tabular (monospaced) numerals for legends when the font supports them, improving alignment (tabular numerals in legends).

Notifications and clipboard

Notifications now slide in from off-screen instead of fading in, with a more natural easing curve (slide-in animation). The sliding animation was refined after its initial introduction.

When you copy text marked as a secret (like a password), the clipboard history UI now shows a clear warning instead of hiding the entry and leaving you wondering why nothing appeared (secret clipboard warning).

The screen recording indicator only appears while recording is actually in progress, fixing cases where apps opened sessions early but started recording later (recording indicator timing).

The “Bouncing app icon” launch feedback animation uses a better physics model, easing curve, and higher frame rate (bouncing icon animation).

Input and accessibility

The Emoji Selector updated to Unicode 17, adding new emoji like 🫨 🫪 🐦‍🔥 🏴‍☠️ (Unicode 17 emoji). The emoji grid now has resize controls (emoji grid resize controls).

Press-and-hold for alternative characters now triggers after 600 ms instead of 200 ms, making accidental activation much harder (press-and-hold timing).

Dwell clicker support landed for accessibility on Wayland — you can click by hovering without pressing a physical button (Phoronix coverage).

Stylus interaction works in Overview and Custom Tiling overlays on Wayland (stylus in Overview, stylus in Custom Tiling).

System tray icons that open widgets now stay visible until the widget popup closes, so you can click a second time to dismiss it (system tray icon visibility).

Network and connectivity

Connecting to an enterprise Wi-Fi network for the first time takes you directly to the credential entry page (enterprise Wi-Fi credentials).

Wireless access points can be configured to automatically select a channel in the Networks System Settings page.

Bluetooth widget’s “Configure” button moved to the standard position for consistency (Bluetooth Configure button).

StrongSwan VPN support added EAP-TTLS authentication (EAP-TTLS authentication).

Flatpak version of Microsoft Edge is now supported in Plasma Browser Integration (Microsoft Edge Flatpak support).

Performance and resource usage

Discover’s background notifier process uses much less memory when checking for updates (notifier memory use).

Plasma startup is slightly faster by avoiding unnecessary work when loading wallpapers (wallpaper loading work).

SVG caching improved in Frameworks 6.30, increasing speed and reducing video memory usage (SVG caching).

Spectacle dropped the OpenCV dependency; blur effects are now implemented without it (OpenCV removal, blur effects without OpenCV).

Thumbnail rendering in notifications and the Activities sidebar uses fewer resources (notification thumbnails, Activities sidebar thumbnails). The Trash widget also uses less memory (Trash widget memory).

Disabling a System Tray widget frees its memory immediately, not just after restart (System Tray memory release).

The clipboard’s “Keep selection and clipboard the same” setting no longer breaks multi-cell copying in LibreOffice Calc (multi-cell copying) and no longer unnecessarily disables other settings (other clipboard settings).

Calendar and clock

Digital Clock widget text for calendar events is now fully selectable (selectable event text).

Digital Clock requests tabular numerals, preventing width changes as time passes (tabular numerals).

The Digital Clock tooltip expands to fit long text instead of overflowing.

Drawing tablet and input devices

The Drawing Tablet settings page has a less awkward dialog for configuring pen button mappings (pen button dialog).

Amharic virtual keyboard layout added (Amharic keyboard layout).

System Settings and configuration

You can disable autostart entries without deleting them (disabling autostart entries).

The Remote Desktop System Settings page works on small/narrow window sizes like phones (narrow window support).

Non-default settings highlighting works on the Remote Desktop page (Remote Desktop highlighting) and the Plasma Search page (Plasma Search highlighting).

The “Report a Bug in the Current Page” feature works for pages that list a bug reporting URL even if they didn’t come from KDE (reporting URL pages).

KWin prevents setting a resolution so low you’d break your system and be unable to recover (unsafe resolution prevention).

Removed: X11 session

Plasma 6.8 drops the X11 session entirely — Wayland is now the only session. X11 applications still run via Xwayland. The X11 session will be supported by KDE into early 2027 through Plasma 6.7 bugfix releases. This is the biggest architectural change in Plasma’s 30-year history (announcement blog post, Nov 2025).

Smaller changes

Visual polish

  • Comboboxes in Plasma now use the active theme for their popups instead of hardcoded Breeze styling, and menu highlights no longer animate (themed combobox popups, menu highlight animation).
  • In-window dialogs in Kirigami apps are better highlighted against window content in dark themes (dialog highlighting).
  • Audio Volume widget popup starts large enough to fit all content without scrolling (popup sizing).
  • Cursor feedback effects dodge screen edges so they’re always fully visible (cursor feedback visibility).
  • Menu Editor has fewer visual frames (fewer visual frames).
  • “CD and DVD” category in Discover renamed to “Disc Burning” to match the FreeDesktop spec (Disc Burning category).
  • Breeze icon theme adds icons for Android app bundle files (Android app bundle icons) and Typst documents (Typst document icons).
  • System Tray crash icons: only one sad-face icon appears when many crashes occur; clicking it shows the full list (crash icon list).

Developer tools and internals

  • showConfigurationInterface() now works in Plasma scripting (scripting support).
  • System Settings Proxy page rewritten in QML for Plasma Mobile compatibility (Proxy page QML rewrite).
  • KGlobalAccel internals refactored: dropped X11 bits, normalized shortcut formats, improved lookups (multiple MRs).
  • Kirigami tab bars respond to scroll and standard tab-switching shortcuts (tab bar scroll).
  • Frameworks 6.30 requires Qt 6.11 and KDE Frameworks 6.30 (version bumps across all modules).

Content and smaller apps

  • Ethiopian calendar (13-month) added to alternate calendars (Ethiopian calendar).
  • Nepali (Bikram Sambat) and Ethiopian calendars supported in Plasma Addons (Nepali calendar, Ethiopian calendar).
  • Vietnamese lunar calendar shows text in Vietnamese regardless of system language (Vietnamese lunar calendar).
  • Time zone offset calculations fixed for half-hour offsets earlier than local time (half-hour time zone offsets).
  • Calendar widget no longer changes displayed date when dragged between screens (calendar drag behavior).
  • Weather widget centers location label, improves badge positioning, uses EnvCan icon codes, and fixes layout issues (multiple MRs).
  • Color Picker widget sizing fixes (widget sizing, sizing behavior).
  • KDE Connect SMS app permissions page ported to new Forms (permissions page port).
  • KWallet stops spamming logs in non-default configurations (log spam).

Performance and technical

  • KWin’s “press and hold for alternative characters” implementation prioritizes app compatibility, fixing many problems (alternative characters).
  • Spectacle no longer includes tooltip with image dimensions in final screenshot when accepting region by double-click (dimension tooltip).
  • Mic tester records at system sample rate instead of forcing 44.1 kHz (system sample rate).
  • Emulated Input protocol version 1.6 supported (Emulated Input protocol).
  • KWin variable refresh rate crash on multi-monitor setups fixed (refresh rate crash).
  • Full-screen video playback performance improved in Chromium-based apps (video playback performance).
  • KWin no longer leaks CAP_SYS_NICE to child processes, fixing Bubblewrap sandboxing (capability leak).
  • XWayland apps behave correctly after XWayland crashes and restarts (XWayland restart behavior).
  • Task Manager hardened against maliciously-crafted .desktop files (malicious .desktop handling).
  • ksystemstats_intel_helper hardened against path traversal (path traversal guard).

  • Corrupted visuals on rotated screens and older AMD GPUs fixed (rotated screen visuals, older AMD visuals).

Security

  • Task Manager hardened against malicious .desktop files (malicious .desktop handling).
  • ksystemstats_intel_helper hardened against path traversal (path traversal guard).
  • Screen locker locking logic fixed for edge-case configuration (locking logic).
  • Flatpak background service crash fixed when allowing app update via KDE portal (Flatpak service crash).

Libraries and build

  • Qt version requirement bumped to 6.11 across all Plasma modules.
  • KDE Frameworks requirement bumped to 6.30 across all Plasma modules.
  • KGlobalAccel dropped X11 code paths, normalized shortcut handling.
  • KWin split into kwin_wayland and kwin_x11 (from 6.4) — X11 bits now fully removed.
  • Multiple modules ported to KConfigXT, QML modules, and modern CMake patterns.

Known regressions and deferred work

  • Union theming for QtWidgets apps has known visual glitches (acknowledged in announcement).
  • Location-based timezone setting deferred; depends on Date & Time KCM QML conversion (Date & Time KCM QML).
  • Some accessibility features from third-party apps may not work as well on Wayland-only session.
  • Output mirroring issues being actively worked on.
  • Session restore and window position memory still being improved.
