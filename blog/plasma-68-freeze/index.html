KDE Plasma 6.8 freeze: what is already locked in

KDE Plasma 6.8

Soft feature freeze landed August 27, 2026. Plasma 6.8 branches from there, two betas follow, and the final release is due October 14. Here is what is settled so far, sorted into the sections you can read.

KDE Plasma 6.8 hit its soft feature freeze on August 27. That is when the 6.7.80 tag branched off and the 6.8 milestone stopped taking features. Two public betas come next: 6.7.90 on September 10 and 6.7.91 on September 24. The stable release is due October 14, 2026.

Beta 1 has not shipped yet, so everything below landed before the freeze. Bug-fix batches arrive with the betas. The 6.8 branch no longer accepts new features.

Things worth your attention

Wayland is the only session now

Plasma 6.8 removes the X11 session. The login screen no longer lists it as an option. KDE announced this direction in November 2025 (“Going all-in on a Wayland future”); 6.8 is the release that actually deletes the fallback. If you still run X11-only software, this is the cycle to make a plan. It affects everyone on X11 and the few tools that expect an X server.

NVIDIA triple buffering on by default

KWin now turns on triple buffering for NVIDIA GPUs by default. The option stayed disabled for a long time because of earlier bug reports, but the code is now stable enough to ship. NVIDIA users should see less stutter in windowed and full-screen use without touching settings. The work underneath is the dynamic triple buffering support that landed in Plasma 6.1 and had been off by default since.

Client-side decorations get shadows and rounding

KWin now draws a shadow, outline, and rounded corners on CSD (client-side-decorated) windows that do not ship their own. A “This Week in Plasma” post from July 18, 2026 (“Shadows for Steam and Discord”) covers the KWin commit. It matters for Steam, Discord, and other Electron or CSD apps, whose square corners now match the rest of the desktop.

Multi-monitor identification

Plasma 6.8 puts a color-coded number badge on each monitor wherever you set up displays. With two identical panels next to each other, the badge tells you which is which. Adjusting brightness on an external monitor is also faster. This helps anyone running more than one screen, especially with duplicate models.

Spectacle records audio

Spectacle can now capture system or microphone audio during a screen recording, not only the video. That closes a gap the built-in tool had next to standalone recorders. Anyone who records their screen and wants narration or system sound in the file gets it now.

Smaller changes

System Settings

  • Wi-Fi access points can pick a channel automatically on the Networks page.
  • Plasma Login Manager now handles distros with older systemd versions, such as KDE neon.

Theming and integration

  • Dark GTK 2 themes are detected better, and a matching icon theme is applied on its own.
  • Peek at Desktop and Window Aperture effects now follow the system-wide animation speed setting.

Apps

  • Emoji Selector moves to Unicode 17, so it can insert emoji such as 🫪 (distorted face), 🫍 (orca), 🫈 (hairy creature), 🪊 (trombone), and 🛘 (landslide). The full Unicode 17 set also adds 🫯 (fight cloud), 🪎 (treasure chest), and 🧑‍🩰 (ballet dancer).
  • Plasma Browser Integration supports the Flatpak build of Microsoft Edge.
  • The lock screen tells you when the Slow Keys accessibility feature is on.
  • Low-battery notifications for connected devices now show during full-screen apps.
  • Wallpaper slideshows can be set to stay on one image.
  • Emulated Input reaches version 1.6 for better virtual keyboard, mouse, and touch handling.

Bug fixes

None published yet. Beta 1 and Beta 2 each bring their own fix batches; this section fills in once those NEWS files are out.

Still in flight

These are proposed or under review for 6.8 but were not merged as of freeze. They may slip to a later release:

  • More NVIDIA Vulkan and Wayland work tied to the 610 driver series.
  • Extra CSD polish past shadows (mentioned in planning, no merged MR at freeze time).
  • Refinements to the color-coded monitor badges, for example remembering per-connector choices.

Under the hood

Plasma 6.8 builds on Qt 6.11 and KDE Frameworks 6.30. The merged “noteworthy” merge requests for the 6.8 milestone are tracked on Invent, and the list grows through the beta window. MR numbers are not all public at freeze time, so this section expands when Beta 1 NEWS lands.
