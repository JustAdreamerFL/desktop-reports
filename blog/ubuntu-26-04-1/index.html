Ubuntu 26.04.1 LTS: what the first point release actually fixes

Ubuntu 26.04.1

Resolute Raccoon's first point release shipped on August 27 with refreshed ISOs, a stack of desktop and kernel fixes, and security updates through August 25. No new HWE stack, that waits for 26.04.2.

Ubuntu 26.04.1 LTS, the first point release of Resolute Raccoon, landed on August 27. The official announcement is on the Ubuntu Discourse and the detailed per-package changelog lives on documentation.ubuntu.com. If you have been running 26.04 since April, you already have most of this through the archive. The point release matters most for fresh installs and for anyone upgrading from 24.04.

There is no new Hardware Enablement stack in 26.04.1. Canonical has held that back for 26.04.2, which will follow the 26.10 release. So 26.04.1 still ships the original 26.04 kernel and graphics stack, just with everything that has landed in the archive since the initial release rolled up into refreshed installation media.

Things worth your attention

Installation media

Several fixes went into livecd-rootfs. RISC-V no longer forces earlycon=sbi and uses the generic kernel flavour on desktop images instead of HWE. The nocloud data format was corrected, and kernel plus initrd now ship in the casper directory with mode 0644, which fixes a netboot tarball that previously arrived with a kernel readable only by root. If you have been building PXE or netboot images for arm or riscv hardware, that last one is the kind of bug you would have hit immediately and then spent an hour debugging.

Upgrade path from 24.04

ubuntu-release-upgrader had a few quirks smoothed out. DistUpgradeQuirks formatting and linting now pass cleanly. The Noble-to-resolute path is now marked Prompt=lts. On Raspberry Pi installs the upgrader forces piboot-try over flash-kernel. The mirror list was refreshed in both ubuntu-release-upgrader and python-apt.

Canonical will not offer the automatic 24.04 to 26.04.1 upgrade for a couple of weeks, while a planned backport addresses regressions in a recent rust-coreutils. If you do not want to wait, do-release-upgrade -d works right now.

Desktop fixes

The bulk of the work is in the desktop. Mutter got a series of Ubuntu patches: it no longer processes other events while waiting for a snap id during window creation (a synchronous operation that should not have been re-entrant), fixes a cursor that kept spinning after launching an app, fixes the cursor not changing inside popups, acknowledges snaps that ship non-desktop CLI apps, cherry-picks the upstream fix for a crash on hot-plugging similar monitors, and fixes a gdctl crash on invalid backlight values. The same-window drag and drop on touchscreens is repaired.

GNOME Shell picked up a fix for accidentally removing search providers when one was unregistered, a patch to load the Ubuntu logo image synchronously so the first frame of the login screen is the real one, and the dash no longer notifies the a11y layer twice per icon. Nautilus restores the progress bar indicator that had been showing zero progress, fixes a crash when opening bookmarks from the dock, restores the previous default action in the “permanently delete” confirmation dialog, and gets the fallback icon sizing back in sync with the zoom level. GNOME Control Center no longer resets the autostart toggle when you change apps. GDM fixes the wrong XDG_SESSION_TYPE for X11 sessions. gnome-initial-setup now has translatable release-notes copy and pulls in updated translations from Launchpad.

Several GNOME stack components moved to newer upstream bugfix releases: gtk4, libadwaita-1, gnome-session, gnome-text-editor, gdm3, nautilus, gnome-remote-desktop, papers, orca, and at-spi2-core. LibreOffice moved to a new upstream release twice. WSL setup syncs the terminal profile with the desktop theme. Ubuntu’s resources library now reads localized app names from langpacks, which fixes the English-only app names that showed up in the desktop search for many deb-installed apps. cups-filters no longer loads parport_pc unconditionally, fixing a boot hang on machines without a parallel port.

Fingerprint readers and biometrics

libfprint gained a new driver for the Egis ETU905 fingerprint reader, and the Goodix MoC driver no longer reports inconsistent enrollment progress when you swipe quickly.

Security updates in the archive

Several notable security items are bundled in. PackageKit had a TOCTOU race on transaction flags. Exim4 got two security updates: a one-byte write into a freed buffer, and an information disclosure in PROXYv2. Rsync carried a security regression fix from the May 2026 update. OpenSSL picked up a fix for the HollowByte denial-of-service issue. apparmor received a new upstream release as an SRU backport. systemd fixed the cloud-init delay caused by the systemd-networkd resolve hook. The full list of Ubuntu Security Notices through August 25, 2026 is included.

Smaller changes

Server, cloud, and virt

Libvirt fixes excessive memory allocation when physical_package_id is large and a logic bug that hurt performance for some interface types with ingress-only QoS rules. QEMU gets a fix for a virgl crash from an unset memory region, an early-stop fix for the module loading function, loads the kvm module for riscv64, makes the Zicbop extension available in RISC-V KVM VMs, and fixes a race with iothreads and throttle groups. cloud-init cherry-picks the iBFT-based iSCSI root detection for Oracle dracut images. resource-agents now stops the fsidd daemon before stopping nfs-server. Heat preserves auto-populated binding:profile fields during updates. byobu no longer writes the prompt runtime to stderr.

Kernel and hardware

Linux moved to 7.0.0-15.15 across the board. linux-raspi moved to 7.0.0-1010.10. linux-nvidia moved to 7.0.0-1006.6. The intel-ipu7 and intel-ipu7-isys modules were being shipped unsigned, which broke Secure Boot on systems that rely on them, and that is now fixed. Qualcomm X1E laptops were triggering hardware protection shutdowns from speaker overdrive, also fixed. nvidia-graphics-drivers-580 moved to 580.159.03 and fixes a suspend crash caused by a missing objtool jump_label NOP conversion. Canonical Kmod keys rotated to the 2025 set. libinput gained a quirk for the Synaptic 06CB:D024 touchpad found on HP haptic touchpads. webkit2gtk works on arm64 with 64KB page sizes. flash-kernel knows about the SpacemiT K3 CoM260 IFX board. ubuntu-raspi-settings lowers the zstd and xz compression levels to avoid OOM on memory-constrained boards and disables the tmpfs /tmp mount on systems with low RAM.

Foundations

systemd fixed the postinst order so rsyslog’s tmpfiles config is honored during upgrade, skips two flaky upstream tests on the build, and stops opening the netfilter socket on every system. debootstrap detects SHA512 in Release index files. grub-initrd-fallback.service now runs after grub2-common.service. distro-info-data records that the Ubuntu Legacy Support extension is now 15 years. tzdata updated to the current release.

Metapackage churn

The desktop metapackages now recommend gst-audio-thumbnailer and gst-video-thumbnailer. pollinate was removed from cloud-minimal, server, server-minimal, and server-raspi, and curl was added back to cloud-minimal and server-minimal to replace what had been pulled in implicitly by pollinate.

Bug fixes worth knowing about

A few items are worth flagging even if they are not headline features. software-properties crashed on Python 3.14 forkserver multiprocessing during driver detection and crashed on a typo in the section name check for manually installed drivers; both are fixed. libpciaccess pointed pc.ids at the wrong path. apport now handles zstd-compressed coredumps, retraces correctly behind an HTTP proxy, and no longer adds a stray .txt extension to retrace artifacts. update-notifier always shows a notification if one is requested. freerdp3 had a clipboard regression from a prior security update and is back. Remmina fixed pre- and post-connect command handling. systemd-tmpfiles runs after debhelper so rsyslog’s config is no longer dropped during an upgrade.

The AppArmor profile set picked up fixes for transmission-gtk, uucore locale reads, lsusb uevent file reads, and alsamixer asound config reads.
