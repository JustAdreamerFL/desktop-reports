KDE Plasma 6.8.2: what actually changed since 6.8.1

KDE Plasma 6.8.2

The second stable 6.8 update disables troublesome Wayland commit timing, fixes multi-GPU rendering and Sticky Keys, and repairs desktop widgets. Remote desktop, Discover, and the login manager also get corrections.

Plasma 6.8.2 is a stable bugfix release, published on October 27, 2026. Compared with our 6.8 beta report, the feature-development period is over: this post covers the fixes since 6.8.1, not the whole 6.8 feature set. KDE has published the announcement, full changelog, and source downloads. Distribution packages may arrive later; there is no new feature-freeze milestone here.

Things worth your attention

Graphics and the compositor

KWin disables Wayland commit timing by default (c74b9d2, #525514, #527500). The commit explains why: a mechanism intended to help frame pacing was causing VRR problems, and an NVIDIA Vulkan driver bug could freeze mpv in some situations. This matters to people using variable-refresh displays or that playback path. The code still has an opt-in through KWIN_WAYLAND_SUPPORT_COMMIT_TIMING_V1=1; the default is now off.

Multi-GPU rendering gets two separate repairs. KWin checks buffer types more correctly in MultiGpuSwapchain and fixes synchronization when copying through EGL (#527591, #527604). The direct-scanout device check also moves to the compositor (#527544). These changes concern systems where rendering and display output involve different GPUs, rather than promising a general frame-rate increase.

The DRM backend stops using post-blend offloading when color pipelines are unsupported (#527628), and disallows it on the legacy path (#527421). It also retries color-pipeline matching at the next hardware block (1b0a1de). These are corrections to hardware color processing, not a newly enabled HDR feature.

Input and accessibility

Sticky Keys now latches and locks modifiers on key release rather than key press (#509714, c4b0a90). The old ordering let XKB clear a modifier that the accessibility filter had just locked. The commit gives a useful example: pressing Shift twice and then typing a b c produced Abc instead of ABC. People who use Sticky Keys to avoid holding down modifiers should get the persistent state they requested.

KWin also preserves an application’s keyboard layout after its last window closes (07db8db). This concerns per-application layout users. The Wayland pointer-constraints implementation fixes overwritten state (#527675), and the virtual keyboard’s D-Bus API reports its visibility correctly (#527067), which matters to programs integrating with the on-screen keyboard.

Remote desktop and recording

KRDP’s Plasma screencast session switches from the old fake-input path to libei (8703881). The commit identifies mapping pointers to individual screens as a reason for the change. That is relevant to remote-control users with multiple monitors; it is not a claim that this update adds every input-device type libei can support.

KRDP now starts with the client’s requested desktop size (215ef0e) and listens for a portal response before making the request (#527555). It also stops tracking progressive frames while acknowledgements are suspended, a change linked to #520260.

In kpipewire, the libx264 encoder is explicitly told the stream’s frame rate (#526931), and an encoded stream honors a requested size set before startup (6cf1ead). These fixes are in the recording and streaming library used by Plasma tools, rather than new controls in Spectacle.

Shell, launchers, and desktop files

Plasma Desktop fixes disappearing desktop icons (fb2c22a). Folder View’s row and column arrangement settings now match their actual behavior (#512993). The Pager keeps desktop labels and window icons bound to its model (#522322, #501660, #506247), so those representations stay connected to the underlying data.

Plasma Workspace puts running tasks in the positions of their launchers (#527189) and re-filters launchers when a window changes screen (#527507). Kicker migrates the old favorite-ID format to the new one (#527651). These are corrections for existing desktop and panel setups, not a redesigned Task Manager.

Login and session handling

Plasma Login Manager avoids autologin when someone explicitly switches to the greeter (5715be5). People choosing the login screen should not be sent back through automatic login. Its settings module also checks configuration size before truncation, checks the child process’s exit status, and clears supplementary groups. Those changes matter to administrators and distributions shipping this login manager.

Smaller changes

Performance and internals

  • libksysguard limits the Line Chart applet to 2,000 data points (#527627). This bounds the chart’s displayed history rather than changing system-wide sensor collection.
  • KWin fixes a rendering-performance issue in the Touch Points effect (f42c6a0) and stops flipping screenshots on the CPU side (7c028ff).
  • KWin’s virtual backend takes the target presentation timestamp into account. Its animation timeline no longer limits animation steps on software renderers, linked to #522222.
  • Plasma Bigscreen improves homescreen blur performance (c143dd4).

Visual polish

Oxygen window-decoration buttons no longer look lumpy in certain fractional-scaling configurations (#527549). KWin corrects startup-feedback icon sizing (#527308), including a 16-by-16 base icon size. Activities use cropped wallpaper previews instead of stretching them (#478784). Plasma Welcome corrects pixelation of its konqi-30.png image (2f151d2).

The Digital Clock preserves the system font’s OpenType features for the time (#524257). PlasmaCore tooltips no longer lower label opacity when there is no heading (caedc25). Kickoff ties sidebar spacing to its compact-list style (#524003), and Task Manager labels can wrap anywhere (#526972).

Developer tools and diagnostics

KWin adds KWIN environment variables to its support information and prints them before Wayland startup (87a60b0, 47470e8). This gives bug reporters and developers a record of compositor overrides. Powerdevil includes the error code when a backlight-brightness job fails, linked to #527520.

Union initializes element queries, indicator values, and tab spacing at construction. Its widget output also scales animation duration with the configured animation speed (#527527). These are changes to the theming implementation, not a new public styling language.

Content and smaller apps

Plasma Addons restores animated images in tiled wallpapers (#516541), repairs adding files and folders to Media Frame, and makes Picture of the Day previews match the “Scaled”, “Centered”, and “Tiled” modes (#505690). Those are the concrete options affected, rather than a new wallpaper collection.

The Web Browser widget reapplies its fixed zoom factor after each page load (#485583) and allows pages to read and write the clipboard (#523381). Kup fixes the checkbox connection for “Exclude user-level Flatpaks” (8ae47dd).

Plasma Mobile respects disabled animations for Quick Settings labels and lock-screen PIN dots, and makes its shell usable with Qt Quick’s software renderer. Bigscreen reworks homescreen rows and tiles, fixes its display settings, and sets “Show Virtual Keyboard” to “With Touch, Tablet, and Mouse”.

Bug fixes

Compositor, display, input

KWin stops hidden scene items from occluding other content (edf9738). It makes the OpenGL context current when grabbing the cursor, guards against resizes in EGLPlatformContext::swapBuffers() (#527269), and fails makeCurrent() when the context has failed. Picture-in-picture surfaces are lowered in the stack (#527648).

Output identification uses the output name and EDID identifier instead of the raw EDID. The output configuration store can generate a completely new configuration (#527401). KWin also adds a missing DPMS event filter and reloads screen-edge configuration when TouchTarget changes.

Sliding notifications handle instant animation speed correctly (#527478). The dwell clicker stays open after a click when pinned (43848d5). Kicker uses its containment’s screen when limiting popup size (#527385).

Login and sessions

Besides the greeter fix above, Plasma Workspace resets its entered-edit-mode state at startup (#527738). Bigscreen fixes lock-screen state handling, a power-management inhibition failure that could occur at boot, and selection of the wrong desktop file when swapping sessions.

Apps and widgets

Discover’s update model reacts when resources disappear (483cd16). Its fwupd backend no longer passes the backend object to the connection thread, and its hidden desktop entries get X-KDE-AliasFor (#511886).

Audio Volume plays feedback when increasing or decreasing volume (#527775), using the configured sound theme (#525954). KWin’s system bell also updates its sound theme when settings change. The Battery Monitor initializes its switch state on first opening (#527560), and Info Center avoids reading properties from a null battery.

Plasma notification markup accepts single-quoted attributes (#506733). Image wallpaper packages load correctly (#527150), and the plain-color wallpaper derives the accent color from its configured color (#513851). The calendar stops navigation before year 1 (#525980).

The global play/pause shortcut no longer auto-repeats (#521448). Media metadata fallbacks retain non-ASCII characters in titles and albums (#503405). The Activity Bar fixes Tab focus and arrow-key navigation (#527235), the application menu automatically focuses its search field (#525569), and restored applet layouts no longer take preferred size into account (#490687).

Security

Spectacle deletes its temporary OCR text file when the job finishes (e853a02). That reduces the lifetime of a file containing recognized screen text. Plasma Login Manager’s supplementary-group cleanup is also worth noting. The release announcement and changelog do not identify either as a CVE fix.

Libraries and build

System Monitor keeps its SplitView maximum width above its minimum width. qqc2-breeze-style restores contextual actions for TextArea (#526591) and closes the mobile text-action popup after an action. Union guards against a potential null dereference (#527459), fixes TextArea background styling (#527455), adjusts list-delegate rounding (#527087), and corrects menubar horizontal padding (#527213).

Known regressions and deferred work

None listed yet in the release announcement. Two deliberate rollbacks deserve separate mention: commit timing is disabled by default, as described above, and KWin reverts its default server-side drop-shadow rule for Steam (fba4609). The latter commit says the rule exposed visual flaws in Steam, including a more obvious black outline and child-window closing problems. A manually added or customized rule remains in the user’s configuration; the unmodified default goes away. This is narrower than removing shadow-only decorations generally.

Sources

KDE’s official Plasma 6.8.2 release announcement confirms the date and stable bugfix status. The complete per-module changes are in the 6.8.1 to 6.8.2 changelog, with published archives and signatures on the 6.8.2 source information page. Commit explanations in KDE’s official GitHub mirrors cover disabling commit timing, Sticky Keys modifier handling, KRDP’s libei port, and reverting the Steam shadow rule.
