GNOME 51 “A Coruña”: the release candidate

GNOME 51.rc

The 51.rc tarballs shipped the week of August 29, string freeze is in, and the stable 51.0 release lands September 16. Here is what the rc pulled in over the beta, what is already locked, and what is still being chased for the final.

GNOME 51 has reached its release candidate. The 51.rc tarballs were due on August 29 before 23:59 UTC, and the build-meta tarball covers the same module set as the beta plus a small rc-only batch. String, UI, feature, and API/ABI freezes all started on August 1; the string freeze itself began August 22. GNOME 51.0 stable is scheduled for September 16, with 51.0 tarballs due September 12. Bug fixes and translations can still land before the final. Anything new that wants to ship has to clear a freeze-exception approval, and very little did.

This post covers what changed between the beta and the rc. The full set of changes from alpha through beta is already in the GNOME 51 alpha/beta write-up.

Things worth your attention

Graphics and the compositor

Mutter’s biggest rc addition is cross-GPU buffer scan-out support, which Tyler Schicke wired up (!5219). The compositor can now attempt to hand a buffer directly to the display controller when the buffer lives on a different GPU than the one driving the output, with an automatic test for the path. Hybrid laptops in particular should see less copying between the discrete and integrated GPUs. Michel Dänzer also added the primary GPU rendering path using FBOs (!4921) and throttles timelines that do not produce a frame every cycle (!5252). The background effect protocol that beta added now has a policy with sane defaults (blur radius 24, saturation 1.25, noise 0.015), and shells are free to override that policy (!5160).

Michel also fixed the hardware cursor for SVG themes (!5217), which had been broken since the alpha introduced SVG cursor support. Night Light now works on hardware that lacks a GAMMA_LUT (!5205), stylus eraser button configuration is hooked up (!4819), and direct scan-out works again for captures that do not have a DMA-BUF (!5276). The compositor also stopped requiring EDID to generate a device color profile (!4961), auto-rotates on phones without a tablet-mode switch (!4962), fixes a possible hang on external monitor hot-plug (!5255), stops desaturating SDR content in HDR mode (!5230), and stops reporting multiple monitors as primary (!5228). Crashes and leaks across input capture, the KMS path, and the input event handling also went out, plus a fix for offscreen effect glitches when a resource’s scale changes (!5233).

Shell switched background image loading and caching to Glycin, the Rust image loading library (!4134), which means the same code path that Nautilus and the previewer use now serves Shell. Smoother workspace transitions when direct scan-out is active also went in (!4320).

Login and sessions

GDM gained pre-authenticated remote displays for Kerberos single sign-on with gnome-remote-desktop. Follow-up fixes to the $GDM_AUTH_SESSION_ID environment variable, the redone PAM service loading logic, and the pam_gdm keyring buffer bounds check are also in. The greeter-side autologin bypass that beta fixed has follow-up hardening, and the Fedora PAM rules now prefer oo7 over gnome-keyring for secret storage.

gnome-session switched to D-Bus for looking up the logind graphical session, and downgraded logout inhibitors from strong to weak as a stop-gap for buggy third-party inhibitors. GDM’s enum of conflicting sessions over logind still picks up ThinLinc and TigerVNC sessions, and the headless local greeter toggle and KMSCON VT compatibility from beta are still in.

gnome-initial-setup zeroises the Kerberos password before freeing it, fixes a markup injection in the privacy policy URL, and fixes a potential command injection in the keyboard preview (!later-rc). It now requires accountsservice >= 26.12.8 for act_user_uses_homed, and the realm manager migration from GSimpleAsyncResult to GTask is finally done.

Apps

Epiphany shipped two security fixes that made it into the rc tarball: CVE-2026-77682, an autofill JavaScript injection via a crafted CSS selector (#2921, Michael Catanzaro), and CVE-2026-77679, a path traversal in the WebExtension XPI installer (#2922, Fernando Muñoz). Catanzaro also fixed an XSS or HTML injection in the error page (#2903). On the UX side, the “Not Secure” label in the address bar no longer gets truncated and glued to the domain in translated locales (#2938), the caret stops jumping to the start when you switch keyboard layout (#2929), and Epiphany stops offering to save a password that it just autofilled itself after a CSV import (#2940). The download path stops firing when the MIME type is missing or the HTTP response failed (#2159), and the canary build no longer points to the wrong WebKitGTK bundle (!2152).

Calendar went through a small Month-view polish run: events can now be dragged on top of other events, Ctrl+Tab from a focused event jumps focus to the month cell behind it, and Shift+Tab from a month cell jumps back to the first event in front of it. The inverted Ctrl+Scroll zoom direction in the Week view is fixed, the popover no longer shows outside the window when the left mouse button is released outside, and a rare crash in the Month view when scrolling is gone. Calendar also accepts iCalendar files with LF line breaks now, which RFC 5545 does not technically allow but real-world files use.

Sushi in 51.rc picked up F2 to rename, Del to trash, O to open the file in its default app, and P to play or pause audio and video. Videos now render on a dark background, and folders opened from the previewer reuse the currently previewed Nautilus window. The plugin API was reworked: markReady/markInitialized were renamed, markFailed is the explicit error path, and ResizePolicy.CUSTOM is gone in favor of ResizePolicy.SCALED. The text UI is now Blueprint, long filenames no longer make the window absurdly wide, animated images play through Glycin, and the HTML renderer no longer requires WebKit.

Maps switched its public-transit routing to v6 of the MOTIS /plan endpoint, refreshed highway shields from OpenStreetMap-Americana, and updated OpenStreetMap POI types. AppData screenshots were updated.

Loupe stopped asking to save an edited file that the user already cancelled, and “Save as…” no longer leaves unsaved-changes state hanging after the new file is written.

GNOME Characters gained Lao and Norwegian Bokmål, and a long translation batch including Slovak, Indonesian, and Cornish. gnome-clocks, gnome-console, gnome-system-monitor, gnome-software, gnome-calendar, and gnome-calculator each shipped translation updates; Connections shipped an rc.1 the day after rc to fix a Flatpak build. Characters and Clocks dropped a couple of G_GNUC_CONST decorations in _get_type functions as part of the broader GLib cleanup.

APIs, libraries, platform

GLib 2.89.4 is in rc. The big one for framework developers is improved nanosecond source timeouts (#4012, #4018, #4025, work by Benjamin Otte), and gio/outputstream now uses a larger splice buffer that meaningfully improves stream splice throughput (!5316, Christian Hergert). The Windows notification backend can finally react to notification icon clicks (!5019). Security: CVE-2026-16118, a heap overflow in _xdg_mime_magic_parse_magic_line() triggered by user-writable XDG data locations, is fixed, and GDesktopAppInfo now validates desktop file path snippets (#4003, Philip Withnall).

GJS 1.89.90 has two backwards-incompatible cleanups. Gio.DBus.makeProxyWrapper() now returns a class expression and should be called with new; calling it as a function still works but prints a deprecation warning. The internal GJS_ALWAYS_INLINE macro from gjs/macros.h is now also deprecated for outsiders; do not depend on it. The Maps slow-routing fix is in (!1104).

PyGObject 3.58.0 is the rc-stable release. Stable release means no surprises relative to 3.57.x, but a couple of new APIs landed in 3.57.1: GLib.Pid is now a number with a special close method (!556), bytearray marshals to GBytes quickly (!558), Gtk.Template accepts PathLike objects (!555), GValue no longer crashes on NULL (!559), and the destroy-notifier path got extra safety (!560). The breaking change from beta, that GFile children are now reachable via the / operator, is in.

Glycin 2.2.beta.1 fixed a deadlock in libglycin’s sync API when consumers exhaust the GTask thread pool by spawning many g_task_run_in_thread() calls, which Nautilus, GNOME Shell, and gdk-pixbuf were doing. The sync API now uses sync GIO under the hood. There is also a workaround for a memory leak in gtk-rs (#314).

Pygobject’s Generic annotations on Async and the / operator on GFile from the beta write-up are still in, and safe GVDB writer for home directories on NFS from dconf is still part of the platform story.

What left the platform

Removed modules from the beta list are unchanged in rc: gcr-3, gnome-keyring, evince (Papers replaces it), and gtksourceview-4. The Fedora PAM rules prefer oo7 over gnome-keyring, and gnome-remote-desktop Kerberos auth is the path forward for smartcard and pre-authenticated sessions.

Smaller changes

Performance and internals

GNOME Shell limited parallel texture loading operations (!4349) and tracks the magnifier mouse position without polling (!4344). The frame clock work from the beta is unchanged in rc but Mutter’s timeline decoupling (!5157) and the new throttling (!5252) line up with it. libdex’s thread pool work-stealing rework is unchanged. Localsearch 3.12.rc avoids needlessly re-extracting files, and tinysparql 3.12.rc plugs memory leaks in the JSON-LD serializer and the SPARQL parser. Sysprof’s libsysprof-capture optimizations are unchanged from alpha.

Visual polish

GTK 4.23.4 added a setting for an accent color (!10266, Matthias Clasen), a setting for the inspector frametime overlay (!9982, Benjamin Otte), and gtkadjustment honors the reduced-motion setting (!10251). The symbolic rendering path in GTK’s SVG code is now opt-in (!10214) with tests (!10215) and proper state handling (!10275, !10278). Vertical color scales with alpha work now (!10253, !10267). The new folder-projects-symbolic icon is in (!10250, g.willems). The shortcutswindow can document clicks (!10268).

GNOME Calendar Month-view polish was already covered above. Nautilus added Santali and added a shortcut to focus the file chooser filename entry, plus renaming, trashing, and folder-opening to the previewer. The app chooser uses the type-to-search pattern and only shows apps in one section, and the view’s clear-on-navigation delay is gone. adwaita-icon-theme picked up the XDG Projects folder icon (#219). Sushi’s video dark background, GTK’s folder-projects-symbolic, and Nautilus’s single-section app chooser are all small polish items that add up to a cleaner desktop.

Developer tools

GJS 1.89.90’s class-expression makeProxyWrapper() and the deprecated GJS_ALWAYS_INLINE macro are documented above. GTK 4.23.4 dropped a deprecated os.path.commonprefix() use in mkenums (!5312). glibmm 2.89.1 exposes connect_ns() and connect_ns_once() on SignalTimeout, get_time_ns() on Source, property_is_remote() on ApplicationCommandLine, property_filename() on DesktopAppInfo, and peek(), lookup(), append_take() on UnixFDList (Kjell Ahlstedt). GLib’s installed service file no longer contains the build path (#4011). Gio’s gio/tests/services regression is fixed.

xdg-desktop-portal-gnome cleaned up the Global Shortcuts portal, stopped using G_GNUC_CONST in _get_type functions, and fixed input-only Remote Desktop sessions.

Content and smaller apps

gnome-autoar 0.5.0 added zstd to the supported archive formats and removed the GTK module. adwaita-icon-theme 51.beta added the XDG Projects folder icon. gst-thumbnailers 1.1.0 updated dependencies. msgraph 0.3.5 falls back to /me/drive when /me/drives is denied. gnome-app-list 2026.08 refreshed the app list and fixed data fetching from GNOME GitLab. Rygel 46.rc only bumped gsettings-desktop-schemas for the Flatpak CI pipeline.

Bug fixes

Compositor, display, input

Mutter in rc fixed: the hardware cursor for SVG themes, multiple monitors being reported as primary, desaturated SDR content in HDR mode, hangs on external monitor hotplug, broken direct scan-out for captures without a DMA-BUF, modifier release stopping key repeat (!4974), drag icon coordinates not snapping to the pixel grid (!5212), offscreen effect glitches on resource scale changes, fallback resolution listing, software cursor overlay visibility, and stylus eraser button configuration. Auto-rotate on phones without a tablet-mode switch works. Night Light works on hardware that lacks a GAMMA_LUT. The compositor no longer requires EDID for a device color profile.

GNOME Shell in rc fixed: a glitch when switching workspaces with direct scan-out (!4320), a glitch when cancelling the lock screen prompt with Esc (!4326), a race condition that prevented the password prompt from showing (!4336), the magnifier mouse position polling (!4344), the busy cursor appearing when activating actions (!4325), a race condition when enabling extensions (!3640), wireless toggle blocking (!4323), new-window action workspace handling (!4071), the focus on the calendar app from reminder notifications (!4327), and unlocking the screen after the screen time limit was hit (!4321). The first menu item is now focused when opened via keyboard (!4189).

GTK 4.23.4 fixed AT-SPI attempts to use /org/a11y/atspi/cache before it is ready in GTK 4 (#7879), GtkListView missing items (#8137), a SIGSEGV in text_input_preedit_hint() when using IBus Chewing in GTK 4 apps on Wayland (#8334), and several macOS regressions around DnD and popovers. The cut/copy/delete virtual-cursor regression in GtkTextView is fixed (#8351). The menu bar focus with F10 is corrected (#8359), and GtkAccessibleTextInterface documentation matches its implementations (#8360). Shortcut labels in menus now show regular keys instead of keypad ones (#8367). Several SVG state-handling bugs in the renderer are fixed (!10249, !10275).

Login and sessions

GDM in rc fixed: a follow-up issue in $GDM_AUTH_SESSION_ID, follow-up fixes in the redone PAM service loading logic, and a keyring buffer bounds check in pam_gdm. The Fedora PAM rules now prefer oo7 over gnome-keyring. The autologin bypass from beta still has hardening follow-ups. PAM modules continue to be notified when the user switches right before exec’ing the session leader.

gnome-session in rc downgraded logout inhibitors from strong to weak to work around buggy third-party inhibitors, and switched the logind graphical session lookup to D-Bus.

gnome-initial-setup zeroises the Kerberos password before freeing it and fixes markup injection in the privacy policy URL and a potential command injection in the keyboard preview.

Apps

Epiphany 51.rc fixed: an invalid-bookmark import crash (#2898), XSS or HTML injection in the error page (#2903), autofill JavaScript injection via a CSS selector (#2921, CVE-2026-77682), WebExtension XPI path traversal (#2922, CVE-2026-77679), a link from another app opening in the fullscreen window during fullscreen video (#2928), a caret jump when switching keyboard layout (#2929), a truncated “Not Secure” label (#2938), Epiphany offering to save a password it just autofilled (#2940), missing MIME type or failed HTTP responses firing downloads (!2159), and the canary build pointing at the wrong WebKitGTK bundle (!2152). highlight.js bumped to 11.2.0 (!2145).

Calendar 51.rc fixed: a rare Month-view crash on scroll, an inverted Ctrl+Scroll zoom direction in Week view, an event popover showing outside the window, and a tooltip on an invisible overflow button.

Nautilus 51.rc fixed: tab overview behavior with a single tab, an empty list state in the app chooser, only apps being shown in one section in the app chooser, a missing parent folder row when the properties dialog is detached, memory trimming on window closure, non-keypad shortcuts in menus, focus and selection when a file gets removed, the app closing when only property windows are left, and shortcut labels in menus showing keypad keys instead of regular ones.

Loupe 51.rc fixed: an “ask to save the image” flow that fired after the user cancelled the edit, and “Save as…” leaving unsaved-changes state hanging after the new file is written.

Sushi 51.rc fixed: animated image playback through Glycin, dialog re-attachment to Nautilus, errors from stopped or cancelled renderers, the HTML renderer working without WebKit, open-with portal dialogs, window resizing detection, the window resizing on opening, image renderer width/height ratio, scaling up small images, TIFF loading through Glycin rather than Papers, and long filenames making the window too wide.

Orca 51.rc added MathCAT 7.6-rc.3, added an Atspi version API to extensions, and gave assertive live regions higher priority in the event manager’s queue. Orca-controlled text selection is now behind a flag for app and browser developers to fix bugs against before v52 goes live with it. Several caret control bugs in non-web content are fixed, and some Say All line repetition in GTK4 text views is gone.

Connections 51.rc.1 fixed a Flatpak build, and 51.rc added a long translation batch.

Security

Epiphany shipped two CVEs in rc: CVE-2026-77682 (autofill JS injection via CSS selector, #2921) and CVE-2026-77679 (WebExtension XPI path traversal via ZIPSLIP, #2922). XSS or HTML injection in the error page (#2903) is also fixed. GLib’s CVE-2026-16118, the heap overflow in _xdg_mime_magic_parse_magic_line() from user-writable XDG data, is fixed (#3992, Philip Withnall). GDesktopAppInfo validates desktop file path snippets (#4003). gnome-initial-setup zeroises the Kerberos password before freeing it.

Libraries and build

GLib 2.89.4 fixed: a fd leak in g_file_set_contents_full() (already mentioned in beta), an installed service file containing the build path (#4011), gio/tests/services regressions (!5259, !5267), the GLib test failures on RISC-V (#4012), Hurd (#3836, #4019), FreeBSD (#4023), and msys2-clang64 (#4020). ASAN and TSAN data races in gobject and binding tests are fixed (#3359, #3695). A potentially quadratic-time regex was rewritten to be linear (!5296). The G_GNUC_CONST purge from beta continued through GLib, glibmm, gtkmm, gvfs, and the rest of the stack. CVEs aside, GLib also added a CI job for UBSAN (!5277).

GTK 4.23.4 enabled UBSAN in the sanitizers CI build (!6178), moved its Fedora CI to F45 (!10193), and fixed static linking on Windows (!10243).

xdg-desktop-portal-gnome stopped using G_GNUC_CONST in _get_type functions.

Still in flight

What 51.0 will land with versus what was tagged in 51.rc is a short list. As of this writing, the 51.0 newstable tarballs are due September 12 and the release date is September 16, so anything still open at the rc has about ten days:

  • The “Boxes missed the 51 train” item from the beta write-up remains. Disks made it, Boxes did not, and there is no sign of a rebase before 51.0.
  • GTK session save and restore was deferred to 4.26 by the GTK team. Apps that depended on the GTK 3 session manager continue to need their own approach.
  • The gnome-control-center 51.rc.1 translation batch and dependency bump on gsettings-desktop-schemas to 51.beta are the last items there; the requests for rebinding global shortcuts on removal and the screen-reader launcher fix are stable.
  • Orca’s Orca-controlled text selection is behind a flag in 51.rc and will go live in v52. There is no expectation that it will flip in 51.0.
  • gst-thumbnailers 1.1.0 was the rc-stable tag, with only a dependency bump. No fixes are queued for 51.0 unless a regression is filed in the next ten days.
  • libshumate 1.7.rc has no changes since 1.7.beta, so the rc is effectively the final API for the 1.7 series.

Known regressions and deferred work

Sushi shows only the first frame of animated GIFs in some cases, and LibreOffice documents render as PDFs because the old rendering method is incompatible with the GTK4 port. The GTK team’s session save/restore is deferred to 4.26. Boxes missed the 51 train. The Sushi HTML renderer needs WebKit at runtime; without it, that renderer is unavailable. GDM keeps the PreSession and PostSession hook scripts removed; the decision from the 50.x series stands. The xdg_session_management_v1 protocol landed, but no major session manager besides GNOME Shell itself implements it yet, so practical use is limited to Mutter-aware compositors. Nautilus’s tab overview behavior with a single tab is fixed in rc, but AdwTabOverview in narrow mode is still narrower than the design intent.
