Fedora Linux 45: what actually changed

Fedora 45

Fedora 45 went GA on November 3, 2026 after two postponements. It ships GNOME 51, KDE Plasma 6.8, Linux 7.2, and a long list of system-wide changes: kmscon as the VT console, enforced RPM signature checking, oo7 secret storage, Stratis in Anaconda, Podman 6, and more.

Fedora Linux 45 reached general availability on November 3, 2026, after two NO-GO decisions pushed the original October 20 target back. It is a stable release: GNOME 51 on Workstation, KDE Plasma 6.8 on the KDE edition, Linux 7.2 underneath, and 46 approved changes in the ChangeSet. This post covers what actually shipped, not the beta promises.

Things worth your attention

Desktop: GNOME 51 and KDE Plasma 6.8

Fedora Workstation 45 ships GNOME 51, which brings reworked frame scheduling in Mutter for steadier frame rates under load, faster screen capture, better display management, and the oo7 secret service provider. Settings gained automatic screen rotation, remembered monitor brightness, and a touchpad-disable-when-mouse-connected option. Nautilus picked up a drag-and-drop counter badge, non-blocking directory reloads, and grouped notifications. Calendar’s view rendering was rebuilt for speed, and the file previewer (Sushi) was redesigned on GTK 4 and libadwaita. GNOME Maps can download maps for offline use.

The KDE Plasma Desktop edition ships Plasma 6.8.2, with per-screen virtual desktops, a system tray light/dark toggle, microphone testing, improved remote desktop with bidirectional clipboard and virtual display support, and the completed retirement of native X11 desktop sessions (X11 apps still run through XWayland).

Security: signature checking and ptrace restrictions

Two security defaults changed. RPM 6.1 now enforces signature verification by default: an unsigned package cannot be installed, dnf refuses it from a repository, and the local-file path warns. Separately, ptrace permissions for unprivileged users are restricted by default, so malware cannot inspect other processes belonging to the same user; full debugging returns when development tools are installed.

Secret storage: oo7 replaces GNOME Keyring

oo7, a modern Secrets Service implementation written in Rust, replaces GNOME Keyring (and KWallet) as the secret service provider on supported configurations. This is the same oo7 stack GNOME 51 adopted, now the Fedora default.

Console: kmscon replaces fbcon

The VT console moved from the in-kernel fbcon to the userspace kmscon. The new console gives improved Unicode and font rendering, better keyboard layout handling, and less console code running inside the kernel. The Cloud image does not enable the service, so the visible difference is on Server and Workstation.

Installer and storage: Stratis and Anaconda WebUI

Anaconda now supports installing Fedora on Stratis-managed storage, including manual configuration through the WebUI (with Cockpit Storage launched directly from the installer) and automated installs via Kickstart (--type=stratis, stratispool, stratisfs). Atomic Desktop variants (Silverblue, Kinoite, Sericea) moved from the legacy GTK-based Anaconda to the WebUI, and gained secure remote installation over HTTPS with PIN-based authentication. Atomic Desktop installation images are now built with image-builder, with extra qcow2 and raw image artifacts.

Toolchain and runtimes

GCC 16.2, binutils 2.47, glibc 2.44, gdb 17.2, LLVM 23, Go 1.27, Perl 5.44, Python 3.15, RPM 6.1, OpenSSL 4.0, Fontconfig 2.18. Also Pandas 3, Podman 6, Lua 5.5, and NodeJS metapackages (no single default stream anymore).

Repository configuration moved to /usr

The distribution’s own .repo files moved from /etc/yum.repos.d to /usr/share/dnf5/repos.d. Custom repositories still live in /etc/yum.repos.d and dnf still reads both.

Smaller changes

  • Removed legacy VPN plugins: NetworkManager-vpnc and NetworkManager-fortisslvpn are removed automatically during upgrades to Fedora 45. Affected users should migrate to supported alternatives such as OpenConnect or Libreswan.
  • CoreOS: enables systemd-oomd and zram swap by default for better memory management.
  • IBus 1.5.35 and the usual self-contained change set (MySQL 9.7, MariaDB 12.3, Ruby on Rails 8.1, Erlang 27, and others from the approved ChangeSet).
  • Kernel: Linux 7.2 with broad hardware support, improved laptop power management, and enhanced container performance.

Bug fixes

None published as a discrete batch for this release. Fedora tracks fixes through updates after GA; see the common issues thread on Ask Fedora for workarounds.

Known regressions and deferred work

  • No kmscon console on the Cloud image: the service is disabled on the Cloud variant by design; use Server or Workstation to see the console difference.
  • Local RPMs can still install unsigned packages: dnf install ./x.rpm only warns; rpm -i refuses. Use a repository with gpgcheck=1 when a hard block is needed.
  • Installer hangs with network --device=link: observed on Beta; using --device=<actual NIC name> works around it.
