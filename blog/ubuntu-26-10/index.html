Ubuntu 26.10 Stonking Stingray: what actually changed

Ubuntu 26.10

The October 2026 interim release ships Linux 7.3, GNOME 51, completes the Rust coreutils migration, and introduces Myna local speech-to-text. Nine months of support, until July 2027.

Ubuntu 26.10, codenamed Stonking Stingray, shipped on October 15. It is the first interim release since 26.04 LTS and carries nine months of support through July 2027. The headline items are Linux 7.3, GNOME 51, the completion of the Rust coreutils migration, and a local speech-to-text preview called Myna. There is also a new window tiling interface, TPM-backed full disk encryption without a hardware root of trust, and RISC-V desktop images for the first time.

Things worth your attention

Rust coreutils migration complete

The transition to Rust uutils finished in this release. The remaining cp, mv, and rm commands are now the Rust implementations, completing a migration that started in earlier releases. For most users this is invisible, but it matters for anyone who scripts around edge cases in coreutils behavior. The Rust implementations have been in testing for several release cycles.

D-Bus switches to dbus-broker

Both the system bus and the per-user session bus now run on dbus-broker instead of dbus-daemon. Canonical points to better accounting, reliability, and scalability from its asynchronous, event-driven architecture. The change is documented in a dedicated Discourse post. If you have custom D-Bus policy or monitoring tooling, this is worth a look.

Myna speech-to-text preview

Myna is an early, opt-in speech-to-text feature for Ubuntu Desktop. Hold a configurable key to dictate into the focused app. Transcription runs locally on the machine, with no audio sent to a network service. It is not preinstalled and its features may change before a stable release. Canonical frames this as the first step toward a more context-aware desktop. Read the Myna technology preview announcement for details.

TPM-backed FDE without a hardware root of trust

Computers without a hardware root of trust can now be installed with TPM-backed full disk encryption, provided a PIN or passphrase is also set on the TPM-backed key. This was backported to 26.04.1, but 26.10 is the first release where it is available out of the box. Upgrade support for systems already running under TPM-backed FDE is not ready on release day; Canonical anticipates enabling it during the 26.10 lifecycle.

New window tiling interface

Dragging a window to the edge of the screen now shows a popup offering tiling layout options. This comes from the Tiling-Assistant project and is tracked in ubuntu/Tiling-Assistant#451. It brings Ubuntu closer to the tiling behavior that GNOME extensions have provided for years.

GNOME 51

The desktop is GNOME 51, which brought its own set of changes: smoother frame scheduling, monitor brightness persistence, improved accessibility (reduced motion extended, keyboard-adjustable screenshot selections, Orca improvements), and a more responsive Calendar. The full GNOME 51 changes are covered in the GNOME 51 release notes. Ubuntu-specific additions on top include a unified app-details view in App Center, a dedicated Drivers page, and on-demand multimedia codec installation.

App Center changes

App Center now presents Snap and Debian package details in a unified view, bringing publisher, ratings, permissions, version, package size, screenshots, and description together with the relevant install, open, or uninstall action. A dedicated Drivers page lets you review available graphics drivers, including NVIDIA branches, with clearer metadata for comparison. When a media file uses a codec that is not installed, App Center can offer to install the needed codec for one-time playback.

Ubuntu Certified hardware status in Settings

Settings can now show whether a computer is certified for Ubuntu. The status is checked using the Ubuntu Hardware API, with caching to avoid repeated checks. The hwctl client is included as a snap. For details on what data is collected, see the System Information Notice.

Microsoft Entra ID authentication

The authd service gained support for signing in with a Microsoft Entra ID password and completing MFA challenges on the desktop, in terminal and SSH sessions, and in Polkit dialogs. Passwordless sign-in with FIDO2 security keys, Microsoft Authenticator, or Temporary Access Passes is also supported. New authctl commands cover user management tasks like changing home directories, login shells, and deleting users and groups. See the Entra ID sign-in announcement and the authd documentation.

New wallpapers

Ubuntu 26.10 includes new Stonking Stingray wallpapers, including designs selected through a community wallpaper competition. See the wallpaper announcement.

RISC-V desktop images and amd64v3 optimization

For the first time, Ubuntu ships desktop images for RISC-V. The amd64 installation images are now optimized for amd64v3 (x86-64-v3), which means CPUs from roughly 2013 onward with AVX2 support. Older hardware will need the generic amd64 images.

Post-quantum-ready package signing

Ubuntu 26.10 includes post-quantum cryptography support in package signing, preparing for the transition to quantum-resistant algorithms. The libp11 package also gained post-quantum support for ML-DSA, SLH-DSA, and FALCON key operations.

Smaller changes

Toolchain upgrades

GCC 15.2.0 with C++ modules support, .NET 10.0.112, Go 1.27, LLVM 22.1.8, OpenJDK 25.0.4 (with OpenJDK 27 available), Python 3.14.7, Rust 1.97.1, and Zig 0.16. Ubuntu 26.10 sticks with GCC 15 as the default compiler.

Server and infrastructure

FreeRADIUS 3.2.10, FRRouting 10.7.1, HAProxy 3.4.2 (LTS until 2031-Q2, with a new default load balancing algorithm), iPXE 2.0.0 (UEFI Secure Boot, RISC-V and LoongArch64 support), Postfix 3.11.7 (JSON output in postconf/postalias/postmap/postmulti), Samba 4.24.7, MySQL 9.7 LTS (from 8.4 LTS), Valkey 9.1, strongSwan 6.0.7, and rdma-core 64.0. The ssl-cert package increased the default generated key length from 2048 to 3072 bits.

Virtualization and cloud

QEMU 11.0 drops 32-bit host builds. libvirt 12.6.0 drops group-based socket access in favor of polkit and encrypts libvirt secrets. Subiquity 26.10 adds new /boot storage requirements for signed GRUB, experimental TPM/FDE use-gap support, Btrfs resize support, and multi-layout keyboard configuration documentation. edk2 2026.05 brings confidential computing improvements and LoongArch64 Secure Boot support.

System-level opt-out for Ubuntu Insights

Administrators can now opt out of anonymous Ubuntu Insights system report collection for the entire system. The configuration overrides individual opt-ins, so they are interpreted as opt-outs instead. The setting is available in Settings or through the Ubuntu Insights CLI.

Bug fixes

Desktop and GNOME

GNOME 51 brought its own batch of fixes across Mutter, Shell, GTK, and apps. On the Ubuntu side, the Showtime video player might not display subtitles and playback might stall when changing subtitle tracks; the issue is being addressed in GStreamer base plugins (LP: #2119649).

Server and packages

The OpenSSH package was split into GSSAPI/Kerberos and non-GSSAPI variants that conflict with each other. Purging a package in rc state after switching variants can break the openssh configuration and cause loss of remote access. Do not purge an openssh package in rc state until the fix in LP: #2169738 is released. Only openssh-gssapi was fixed for 26.10; the main openssh package will receive an SRU.

Hardware support

On Raspberry Pi CM5 and potentially other Pi 5 models, there is significantly larger power draw at boot time. If you experience boot issues and are not using an official 5A-capable power supply, try one before debugging further. The gnome-initial-setup time zone dropdown can wobble (LP: #2084611). On server images, cloud-init configurations that rely on networking must ensure at least one network interface is marked optional: false in network-config due to Netplan changes to the wait-online service (LP: #2060311). WiFi wlan0 may not activate on first boot (LP: #2170885).

On SpacemiT K3 platforms, the second PCIe slot, DisplayPort and HDMI audio, GPU/VPU/G2D hardware nodes, and power balance elements are not supported. Initial support landed in 26.10 but these gaps remain.

Security

strongSwan 6.0.7 fixed CVE-2026-47895 (libstrongswan identity cloning leading to double-free, potential RCE). The 6.0.6 release fixed seven additional CVEs across libtls, pkcs7, libsimaka, constraints, libradius, and gmp plugins. Exim4 4.99.4 fixed CVE-2026-48840 (uninitialised-stack disclosure in the PROXYv2 parser). The 4.99.2 and 4.99.3 releases fixed eight more CVEs including a musl DNS crash and a use-after-free in GnuTLS BDAT/CHUNKING.

Known regressions and deferred work

Systems running under TPM-backed FDE will not be able to upgrade from Ubuntu 26.04 LTS to 26.10 on release day. Canonical anticipates enabling these upgrades during the 26.10 lifecycle. The App Center is not installed by default on the RISC-V desktop image; users can install it with sudo snap install snap-store. Showtime subtitle issues are tracked but not resolved at release time.
