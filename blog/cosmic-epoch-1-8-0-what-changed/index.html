COSMIC Epoch 1.8.0: what actually changed since 1.7.0

COSMIC 1.8.0

System76 tagged a coordinated submodule bump centered on a major cosmic-comp compositor overhaul. Tablet emulation, libei pasteboard sharing, rounded window corners, and multi-factor PAM login are the headliners, plus a raft of fixes across applets, files, and the greeter.

As of September 9 2026, COSMIC Epoch 1.8.0 is tagged. Epoch releases are not traditional feature drops — they are coordinated snapshots pinning twenty-plus independently developed submodules to a single, tested commit. Pop!_OS gets these changes through its internal pipeline; the epoch tag gives Arch, Fedora, NixOS, and other distros a reliable pin point. The diff between 1.7.0 and 1.8.0 is one commit (e7bc6be) that bumps every submodule; the real story lives in those submodule diffs.

Things worth your attention

Compositor and Wayland protocols

The heavy lifting happened in cosmic-comp, the Wayland compositor. Nearly fifty files were touched, with the tiling layout grab handlers receiving a full rewrite for more accurate resize behavior. Three new protocol handlers landed:

  • tablet emulation (tablet_emu.rs, 256 new lines): drawing tablets now get proper input routing at the compositor level. Pressure, tilt, and rotation are exposed through the ei_stylus interface via libei. Krita and other stylus-aware apps should now register pen input correctly.
  • libei pasteboard sharing: copy text in an X11 app and paste it into a Wayland one without a clipboard daemon throwing a fit. The libei.rs module wires up the pasteboard protocol so copy/paste crosses the XWayland boundary cleanly.
  • cornerRadius protocol (src/wayland/protocols/corner_radius.rs): finally allows rounded window borders. The handler lives in src/wayland/handlers/corner_radius.rs; themes and apps can now request corner radii without hacks.
  • pointer-warp-v1 (src/wayland/handlers/pointer_warp.rs): cross-window cursor syncing for remote-desktop and gaming use cases.
  • keyboard-layout-unstable-v1 (src/wayland/handlers/keyboard_layout.rs): proper layout switching at the compositor level, replacing the previous config-file workaround.

XWayland received fractional-scaling border fixes. KMS/DRM cleanup got more robust error handling. The shadow rendering module was quietly stripped out as dead code. Input handling modules grew from roughly 105 net lines to 332, reflecting a complete overhaul of pointer warping and grab state management.

Who it affects: users with drawing tablets, anyone copying between X11 and Wayland apps, theme authors wanting rounded corners, remote-desktop users, and anyone on fractional-scaling setups.

Bluetooth, audio, and system tray fixes

Outside the compositor, the changes are quieter but immediately noticeable:

  • Bluetooth applet (cosmic-applets/cosmic-applet-bluetooth/src/bluetooth.rs): now displays device alias names instead of raw MAC addresses. The Settings panel lets you rename paired devices directly without digging into the command line.
  • Audio source volume slider (same applet): a long-standing bug finally got fixed — the slider now actually adjusts the input device instead of silently rewriting the output volume.
  • Network manager applet: bumped its Rust client to nmrs 3.5.2, smoothing compatibility with newer NetworkManager releases.
  • System tray icons: stopped rendering downsampled when scaled below 1:1, fixing the persistent fuzzy-icon issue in smaller panels.

Who it affects: Bluetooth headphone/speaker users, anyone adjusting microphone volume, multi-monitor setups with mixed DPI panels.

File manager and settings polish

  • cosmic-files: the rubber-band selection no longer redraws incorrectly when you drag it. Tab focus behavior now correctly stays put when you close a different tab. The search drawer in Settings preserves your scroll position instead of resetting to the top of every section.
  • cosmic-launcher: switched to a standard build.rs, added its first official CI pipeline for clippy and formatting, and stopped leaking environment variables into downstream builds.
  • cosmic-greeter: finally chains sequential PAM prompts, which fixes login failures for users running dual-factor setups (e.g., password + YubiKey, or password + TOTP). It also ships full Nix flake packaging now.

Who it affects: file-manager power users, NixOS users, anyone with multi-factor authentication.

Localization and new modules

  • Initial setup wizard picked up Filipino and Hungarian translation coverage.
  • cosmic-sound-theme and cosmic-screenshot modules were added to the repository structure for the first time (still early, not fully baked).
  • The logind feature gate now compiles cleanly when building without systemd dependencies, removing a long-standing pain point for non-systemd distributions.
  • Weblate pushed a massive localization sweep across fifteen languages (Czech to Traditional Chinese).

Who it affects: non-English users, non-systemd distro packagers, anyone waiting on a native screenshot tool or system sound theme.

Smaller changes

Performance and internals

  • Tiling layout grab handlers rewritten for more accurate resize behavior (fewer visual glitches when dragging window edges).
  • Input subsystem overhaul: pointer warping and grab state management consolidated, reducing latency spikes during rapid window operations.
  • KMS/DRM error paths hardened; compositor recovers more gracefully from display hotplug races.
  • Build system hygiene: logind feature gate no longer forces systemd at compile time.

Visual polish

  • System tray icons render crisp at sub-1x scaling (no more fuzzy Bluetooth/battery icons in compact panels).
  • New printer queue icon and refreshed browser icon in cosmic-icons.
  • Rounded window borders now possible via the cornerRadius protocol (theme support required; not yet exposed in Settings).

Developer tools and packaging

  • cosmic-launcher gained a standard build.rs and CI pipeline (clippy + fmt).
  • Full Nix flake packaging for the greeter.
  • Environment variable leakage in launcher builds plugged.
  • cosmic-applibrary and cosmic-store received version bumps and dependency updates only.

Bug fixes

Compositor, display, input

  • Tablet input now registers in stylus-aware apps (Krita, GIMP) — previously only pointer movement worked.
  • X11 ↔ Wayland copy/paste works without a clipboard daemon.
  • Fractional-scaling borders on XWayland clients no longer show gaps or double borders.
  • Pointer warping no longer snaps cursor to (0,0) intermittently (fixes relative mouse input in games).
  • Shadow rendering dead code removed, eliminating a minor memory leak path.
  • Keyboard layout switching at the compositor level now works without editing xkb_config manually.

Login and sessions

  • Greeter PAM chaining: sequential prompts (password → second factor) no longer deadlock or drop the second factor.
  • NixOS users can now install the greeter via flake without patching.

Apps and applets

  • Bluetooth device list shows human-readable aliases; renaming works from Settings.
  • Microphone volume slider adjusts the correct stream (input, not output).
  • System tray icons stay sharp at all panel sizes.
  • File manager rubber-band selection no longer flickers/redraws incorrectly.
  • Tab focus preserved when closing background tabs.
  • Settings search drawer remembers scroll position.

Libraries and build

  • logind feature gate compiles without systemd.
  • nmrs bumped to 3.5.2 for NetworkManager compatibility.
  • Various Cargo.lock and dependency updates across all submodules.

Known regressions and deferred work

  • cosmic-sound-theme and cosmic-screenshot are present in the repo but not yet functional — treat as preview only.
  • Rounded window corners require theme support; no Settings UI to toggle them yet.
  • Tablet emulation covers pressure/tilt/rotation; advanced stylus features (e.g., eraser end, barrel buttons) not yet mapped.
  • The unified changelog for end users is still absent; you have to read submodule diffs to know what actually shipped versus what just compiled.
