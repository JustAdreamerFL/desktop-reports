GNOME 51 "A Coruña": the final release

GNOME 51.0

GNOME 51.0 is out. The beta we previewed in August has shipped, with cross-GPU scan-out, custom pointer acceleration profiles, and a final batch of bug fixes added since the freeze report.

GNOME 51.0 is out. The beta we previewed in August has now shipped, and a few things have changed since that freeze report: Mutter gained cross-GPU buffer scan-out support, custom pointer acceleration profiles landed, and a last batch of bug fixes cleared the final milestone. This post covers everything that made it into the stable release.

Things worth your attention

Graphics and the compositor

Mutter gained cross-GPU buffer scan-out support in the final week before release. This lets a secondary GPU scan out buffers directly, avoiding a copy step on hybrid graphics laptops.

Custom pointer acceleration profiles are another last-minute addition. Mutter now supports libinput’s user-defined acceleration curves through a new gsettings-desktop-schemas key (MR !99 on schemas, matching Mutter MR from February 2025). You can tune pointer speed at different movement rates instead of being stuck with the flat default.

The changes from the freeze report all made it in: Mutter blurs window backgrounds through the ext-background-effect-v1 Wayland protocol with GTK 4.24 on the client side, Michel Dänzer’s frame scheduling patches landed, Benjamin Otte reworked the GTK frame clock, cursors ship as SVG now, and Mutter fills in mastering display metadata for HDR output.

Mutter also dropped legacy NVIDIA drivers (!5079). Old proprietary versions stop working; current NVIDIA and open kernel modules are fine.

APIs, protocols, platform

GTK jumped from 4.21.6 to 4.24.0. The new version supports the ext-background-effect protocol for blurred backgrounds, reworked the frame clock for better precision, supports the CSS font-width property, and lets you change the visible focus timeout with gtk-keyboard-focus-visible-timeout. Session save/restore was deferred to GTK 4.26.

GLib 2.90.0 shipped with UAPI file masking and drop-ins for GKeyFile, g_string_free_deep(), g_set_date_time(), GUnixFDList helpers, and finer g_timeout APIs. A heap overflow in _xdg_mime_magic_parse_magic_line() was fixed (#3992, CVE-2026-16118), among several out-of-bounds read fixes.

libsoup 3.7.3 added compression dictionaries (dcb/dcz) and SoupCompressionDictionaryRequest. libadwaita 1.10.0 shipped.

GJS 1.90.0 carries the breaking change where GObject.Interface no longer installs methods as unbound statics. Extensions calling Interface.method(obj) must switch to Interface.prototype.method.call(this).

The platform-level changes from the freeze report all landed: text_input_v3 version 2, xdg_session_management_v1, global shortcut inhibitors for a11y shortcuts, Input Capture portal session persistence and clipboard access, oo7-portal as the Secret portal implementation, and new D-Bus properties SessionIsLocked and SessionClass on gnome-session.

dconf 51.0 ships the safe GVDB writer for home directories on NFS by default.

Shell and login

Web login and the unified auth mechanism (!3212) are in. The login screen can offer several authentication mechanisms side by side, including logging in through the web. This is the biggest GDM and Shell change in years.

Shell started honoring the reduced-motion setting (initial support), holding back motion animations for people who want less of them. The COPY, CUT, and PASTE keys work in Shell text entries now.

Calendar reminders pop up as Shell notifications (!1064), so you no longer need to open the calendar app to see them. Monitor brightness is saved and restored across sessions.

GDM 51.0 has a fallback session setting, an option to turn off the local greeter on headless machines, KMSCON VT compatibility, conflicting sessions enumerated through logind, and Kerberos support for remote login. Fingerprint login is no longer allowed for initial system login; the sensor now works only for re-authentication, both for security reasons and because various parts of the system (like the keyring) break when logging in via fingerprint.

The VA-API H.264 screencast pipeline gained rate control, so screen recording loads the machine less. The extensions app moved to its own repository. Extension authors should note that async disable() is explicitly disallowed now.

Applications

Papers can insert visual signatures into documents. Right-click anywhere on a page, draw a signature with mouse or touchscreen, or import an image; Papers removes the background so the signature blends in. The feature was developed by Malika Asman during her Outreachy internship. Papers also prints free text annotations by default, renders fractional scales better using GTK’s new snapping API, and describes paper sizes with more detail in properties.

Loupe shows the ICC or CICP profile description along with metadata like author, copyright, lens, and software.

Maps can download map areas for offline use. Downloaded regions are managed from a simple list. Public transit directions gained live departures, real-time delay information, track and stop details, and walking times. Tapping a station or stop shows live departure and arrival times where data is available.

Files shows a drag counter badge when moving multiple items, auto-selects copied files, stops clearing the selection on right-click in empty space, groups its notifications, and reloads folder views faster.

Web has a keyboard shortcut for copying the page URL (Ctrl+Shift+C), secure password generation via libpwquality, and a cleaned-up address bar that no longer shows raw URLs in search suggestions.

Software warns before installing end-of-life apps, lists more Flatpak permissions, and starts faster thanks to cached AppStream data and optimized icon loading.

Calendar went through its GListModel rework and is noticeably faster in Month view with large schedules. Event locations can be opened directly in Maps, Week view works with the high-contrast setting, and the event editor was cleaned up with better Microsoft Teams link support.

Sushi is now GTK4 and libadwaita. The file previewer got a full interface revamp, supports dark mode, displays images at real size, and uses the same modern loading and rendering libraries as the rest of GNOME.

Calculator remembers calculation history across restarts, shows the exponent in the current base, and does exact rational arithmetic via GMP.

Settings got a new fingerprint management interface in Users, an About panel with a button to open the release notes, an Accessibility setting to disable the focus timeout, an Auto Rotate row for devices with accelerometers, center-aligned display snapping, an option to disable the touchpad when a mouse is plugged in, DNS domain search, Wi-Fi sharing through the QR widget, “ConfigureShortcuts” in Global Shortcuts, reworked panel navigation, and stricter policies for systemd-homed accounts. WEP support is gone. Remote Login now supports SSH socket servers in addition to the service-based setup.

Orca 51 is nearly a release of its own: user plugins and extensions, MathCAT for MathML, announcing formatting changes while reading, language-specific voice sets activated by command, automatic sleep mode for chosen apps, configurable flat review, double-tapped Orca+F showing all font and formatting info in a window, and configurable speech inflection.

Nautilus opens locations from other apps in new tabs, has AdwTabOverview in narrow mode, moves search focus to the most relevant result, ignores duplicate entries in the app chooser, and gives the Projects bookmark its own symbolic icon.

Remote Desktop supports smartcard redirection and Kerberos multi-user remote login. Connections handles H.264 encoding in Flatpak builds, captions in app screenshots, and IPv6 URIs.

GNOME Circle gained three new apps: Bobby for browsing SQLite databases, Tally for simple counting, and Bazaar, a new app store focused on discovering and installing apps and add-ons from Flatpak remotes.

Initial Setup supports systemd-homed accounts and got error indications plus accessibility states for enterprise accounts.

What left the platform

Removed modules: gcr-3, gnome-keyring, evince (Papers replaces it), and gtksourceview-4. Together with oo7-portal from the API section, the direction for secret storage is clear: the oo7 stack. Distros can still package these themselves, but they are no longer part of the GNOME platform.

Smaller changes

Performance and internals

  • Nautilus: faster view reloading, blocking IO pushed off the main thread, no duplicated loading locations.
  • Software: faster icon loading and PackageKit repository refinement.
  • System Monitor: reworked cgroups performance.
  • tinysparql: faster ICU full-text tokenizer; localsearch refactored code shared between processes.
  • GtkSourceView: faster context engine and search context.
  • Shell screencasts minimize stage paints and buffer copies.
  • GLib: the GNetworkMonitor netlink backend behaves like iproute2 and pulls the route table less often.
  • libdex: reworked work stealing in the thread pool; idle workers sleep instead of scanning peers, and work distributes better.
  • GTK: GPU cache scaling limits, text view caches pixel height, motion history is always collected for input prediction.
  • Sysprof: libsysprof-capture optimizations.
  • glycin: fixed a deadlock when consumers exhausted the GTask thread pool by blocking on the sync API. libglycin now uses sync GIO operations when the sync API is used. Also fixed mmap of write-sealed memfds on Linux < 6.7.

Visual polish

New wallpaper set. The default is “Roundhex” (shape interest in the top right corner, tweaked from feedback), joined by “Glass Stripes” and “Curvaturingster” in the chooser.

Shell uses its own sound effects instead of the sound theme, animates app grid label expansion nicer, supports touch scrolling in ScrollView and start/end text alignment, exposes the slow-down-factor in looking glass, lights the audio-input icon only during actual recording, and the session/a11y menus at the login screen respond to both mouse buttons.

Maps moved settings from menus into the preferences dialog, larger place-name fonts in the sidebar match the new pill buttons, transit itineraries show walking durations, going-to animations are skipped over large distances, and tombs have a fresh icon.

Nautilus widened the sidebar limit, shows an empty “Document” entry when the templates directory is empty, uses AdwComboRow for the open-action preference, hides the redundant “Open Parent Folder” row, puts the symlink emblem before read-only/unreadable ones, and badges the selection count while dragging files.

Control Center merged all panel CSS into one stylesheet, adopted clang-format globally, moved the About copy button to AdwButtonRow, modernized the Wacom button-mapping dialog, and hides the auto DNS/route toggles in Manual mode.

libadwaita 1.10 adds AdwSidebarItem :prefix and AdwSidebarSection :suffix, animates the title on the About dialog main page, and fixes adaptive preview issues.

Developer tools

Foundry 1.2.0 runs GitLab CI locally in Podman (includes, rules, stages, needs, artifacts), adds public CI and Git API abstractions, ships foundry ci list/run/shell/clean, bindable amend support, commit templates, and help generated from the command tree. Debugger fixes include better DAP thread, stop, continue, and stack-frame state tracking, plus regression tests.

Builder 50.0 shipped. blueprint-compiler 0.22.2. Vala 0.56.19 with gdbus and vala fixes plus updated bindings. gtk-doc 1.36.1.

Epiphany, Nautilus, PyGObject, and GTK all adopted the gobject-linter CI job at scale. Sushi’s plugin API was overhauled with a system-wide plugin path and documentation. GJS makes GNOME objects more transparent to the garbage collector for accurate Sysprof memory stats.

Content and smaller apps

adwaita-fonts 51.0, Papers 51.0, Simple Scan 50.0, Music 50.0, and Decibels 49.6.1 (PipeWire stream metadata, MPRIS SetPosition/OpenUri fixes). Rygel 46.0 added Reciva devices to the seek hack and fixed a crash on address family mismatch. gdk-pixbuf 2.44.8 brings glycin x-/y-dpi support for PNG, TIFF, and JPEG.

glycin 2.2.1 fixed mmap of write-sealed memfds on older kernels. gnome-user-docs updated GNOME Help.

Bug fixes

Compositor, display, input

Mutter: blurred rendering on non-pixel-aligned monitors, invalid redraw clips on rotated monitors, shader snippets reapplied correctly after resize and scale, unsupported fallback monitor modes no longer offered, wrong stacking order changes on workspace switches, fullscreening edge-tiled windows, alt-tab under sloppy/mouse focus, DND data offers on touch, tablet DND across surfaces, broken switch-monitor mapping on stylus buttons, unfullscreening maximized windows correctly, OSK triggering for text_input_v3 v1 clients, preferred_scale events delivered to clients, cursor position hints for Xwayland under scaling, tablet cursor hotspot scaling, moving maximized windows between monitors by keyboard, window size increases after fast unmaximize drags, plus a run of crash fixes (!5143, !5153, !5151, !5163, !5169, !5170).

Shell: a glitch when switching to a minimized window on another workspace, mis-scaled magnified cursors on HiDPI, sound glitches from redundant volume changes, wiggle feedback on non-password auth failures, the spinner resetting on every keystroke in overview search, layout reapplication on xkb-options changes, the “Install Updates” checkbox in the power dialog, autorun notifications for USB drives, spacing in lock screen media notifications, workspaces disappearing mid-animation, removing arbitrary providers when unregistering search providers, one memory leak, and a glitch with direct scanout on workspace switches.

GTK: the X11 selection clipboard burned excessive CPU (#6493), animated SVGs frequently disappeared (#8195), type-to-search broke in Epiphany dialogs (#8291), GLArea leaked memory on unrealize, GtkPicture dispose left a dangling paintable, tooltips blocked on X11, a frame clock idle deadlock from counter underflow, munmap() of the wrong pointer in the dmabuf format table, CSS text-decoration needing a resize to apply (a regression), application menu items with multiple shortcuts showing none, Super/Hyper no longer counting as text modifiers, AT-SPI using the cache before it was ready (#7879), GtkListView missing items (#8137), macOS re-entrant GMainContext stale poll array (#8263), a macOS memory leak when unfocusing with an open popup (#8343), GtkColumnView sortable headers exposing no AT-SPI action (#8354), and media queries not respected (#8382).

Login and sessions

GDM: Plymouth never quit on headless or monitor-less systems, so the machine never reached graphical.target; X11 sessions started with XDG_SESSION_TYPE=wayland; kernel VT cursor flicker when logging out; checks that PAM plugins do not drop fsuid privileges and break GDM; PAM modules notified when the user switches right before exec’ing the session leader; autologin bypass where a compromised greeter could request arbitrary usernames; PAM substack safety net so authentication cannot be bypassed; double-free in session worker; path traversal vulnerability where a compromised greeter could load arbitrary .desktop files via SelectSession; and input sanitation when forwarding unknown usernames to the audit subsystem.

gnome-session had a regression in screen blanking and idle handling, fixed in beta. gnome-settings-daemon: Housekeeping failed to launch Baobab, one use-after-free, and power temporary-unidle now cooperates with inhibitors.

Apps

Calendar: sporadically missing horizontal separators in month view, the event editor not saving duration changes, a week view crash with multiple overlapping events, a tooltip on an invisible overflow button, rare crash on Month view scrolling, inverted Ctrl+Scroll zoom direction in Week view.

Nautilus: correct starred status and properties behavior in Recents, right-clicking the view background no longer clears the selection, manual selections survive file operation results, copied files get selected after the operation finishes, Escape closes the app chooser while the entry is focused, thumbnails update during loading, loading getting stuck while thumbnailing in Flatpak, the “Window is ready” notification firing when other apps call “Open location”, timed dialogs destroyed before their timeout, and a memory leak in create-links-in-place.

Epiphany: colons in app-mode URLs converted to “A”, crashes on invalid view-source: URIs, a memory leak in ephy_string_shorten(), an out-of-bounds assert in the JSON helper, duplicate password entries when editing usernames, crashes deleting password records, crashes after adding OpenSearch engines, a preferences crash after deleting the default search engine, a memory-corruption fix-of-fix in web-view, CVE-2026-18487 (address bar host spoofing via userinfo), CVE-2026-77682 (autofill JS code injection via CSS selector), CVE-2026-77679 (WebExtension XPI path traversal ZIPSLIP), and XSS/HTML injection in the error page.

Connections: authentication dialog focus chain, cursor change propagation, IPv6 URI connections, NULL Common Name handling in RDP, and no longer storing already-stored connections. Initial Setup: a crash when the SSID got freed on the network page.

System Monitor: summary units in the process table, translatable disk read/write rate units, duplicate icon text in preferences. Calculator reports an invalid name entry to the accessibility layer. gexiv2 crashed opening files without preview images.

at-spi2-core: a crash in get_registered_event_listeners, grab id 0 assignments, wrongly deregistered event listeners, NULL dereferences when sending events, and detection of unresponsive applications. libatspi gained a Ready signal on the cache, ATSPI_STATE_DEFAULT alias, and main-loop reentrancy control.

GtkSourceView: the file loader rejects non-regular files, bounds expanded/decompressed input size, fails loads cleanly, plugs gutter and gutter-line leaks, breaks a circular reference with line numbers enabled, and fixes Vim emulation for repeated commands.

Orca: table presentation including Chrome’s history table, aria-busy respected, no percent value on indeterminate widgets, false-positive flat review resets in terminals, color-chooser button names, item counts in list boxes, and set_current_voice() persistence.

yelp fixed an issue that allowed remote access to local files (49.1, security relevant). zenity’s --hide-header actually hides the header now.

Security

GLib’s GDBusServer suffered a pre-authentication DoS through unbounded SASL line buffering (#3985, CVE-2026-16118 for the heap overflow). Several out-of-bounds reads were fixed in GRegex, GMarkup, GDateTime, GIOChannel, GDBus, and GKeyFile. GDesktopAppInfo now validates desktop file path snippets (#4003).

Evolution Data Server got a hardening series: a shell command injection fix in NTLM SASL, ENVID sanitization against SMTP command injection, POP3 rejecting CRLF-bearing credentials (command injection), CardDAV validating photo/logo URI origins against SSRF, a MIME nesting depth limit against stack exhaustion, HTTPS-to-HTTP redirects rejected, and OAuth2 state parameters against CSRF.

gvfs hardened input validation across afp/dav/ftp/mtp/sftp backends, wipes passwords from memory before freeing them, and fixed crashes in the OneDrive, MTP, and SMB backends. glycin switched its sandbox seccomp policy from an allowlist to a blocklist. Epiphany quotes command-line input before passing it to the shell (!2094) and carries the CVE fixes above.

glib-networking fixed out-of-bounds reads in the OpenSSL backend (CVE-2025-60018, CVE-2026-2574) and an infinite loop in certification path building (CVE-2026-10028).

GDM: path traversal vulnerability where a compromised greeter could load arbitrary .desktop files; autologin bypass where a compromised greeter could request arbitrary usernames; denial of service where an invalid session name caused the daemon to exit; ASLR leak in D-Bus object path generation; and PAM passphrase handling now wipes cached plaintext passwords.

Libraries and build

GLib: an fd leak in g_file_set_contents_full(), a crash on gio help help, a GDBusActionGroupClass failure, Windows UNC paths in the spawn helper, and a purge of G_GNUC_CONST from _get_type() functions across the stack (GCC 17 risked miscompiling those).

libsoup HTTP/2: the content sniffer running while paused, failed messages requeued when a connection is not reusable, buffered bodies consumed before cancel, and reads limited to received content. Pango: CoreText variations and font features, overline/underline/strikethrough staying in sync, undefined-behavior fixes.

Evolution Data Server: LDAP Simple Paged Results (RFC 2696), IMAP4 Multimailbox SEARCH, junk folder unread counting, recurring task due-date reset, camel-lock-helper symlink handling, a deadlock with m365 GOA accounts, a pile of memory leak fixes, and gb2313 mapped to gb18030. gtk+-3, yelp, and tecla carried maintenance and build fixes.

Known regressions and deferred work

Sushi shows only the first frame of animated GIFs, and LibreOffice documents render as PDFs because the old method is incompatible with the GTK4 port. GTK deferred session save/restore to 4.26. Boxes missed the 51 train (Disks made it). GDM keeps PreSession/PostSession hook scripts removed; the decision from the 50.x series stands.
