Debian 13.8: what actually changed

Debian 13.8

The eighth trixie point release landed on November 21, 2026. It folds in a large batch of security fixes, a GRUB Secure Boot fix, fresh Intel microcode, glibc corrections, and an installer kernel bump. Here is the concrete list.

Debian 13.8 is a stable point release, the eighth update of trixie, published on November 21, 2026. It is not a new version of Debian 13 and there is no feature freeze involved. The release adds corrections for security issues plus fixes for a set of serious problems. Security advisories went out separately and are referenced in the announcement. Old 13.x media still installs, then upgrades to current packages through any up-to-date mirror. There is a lot here: 122 source packages in the miscellaneous bugfix table and well over a hundred DSAs rolled into the stable set. Most of the DSA packages will already be current on machines that follow security.debian.org.

Things worth your attention

Boot, firmware and the C library

Change Where Who it affects
GRUB: Secure Boot bypass (CVE-2026-97876), use-after-free denials of service (CVE-2025-54770, CVE-2025-54771, CVE-2025-61661 to CVE-2025-61664), SBAT revision bump, riscv64 crash fix grub2 and the amd64, arm64, ia32 signed EFI builds Anyone booting with UEFI Secure Boot. The signed packages and grub2 all get the same fix, and the SBAT bump matters for dual-boot setups with shim.
glibc: buffer over-reads (CVE-2026-6238, CVE-2026-97399), out-of-bounds writes (CVE-2026-5435, CVE-2026-19542), stack overflows (CVE-2026-6791, CVE-2026-89092, CVE-2026-95818), buffer overflows (CVE-2026-19499, CVE-2026-18374), UTF-32 decode hangs (CVE-2026-77117, CVE-2026-80489), a wordexp WRDE_APPEND state fix (CVE-2026-6368) and a race condition (CVE-2026-86805) glibc Everyone. On Intel CPUs, ld.so now caches cpuid results, which is a small startup-path change worth watching if you run unusual CPUID-overriding tools.
New upstream microcode with twelve CVEs, among them CVE-2024-24853 and CVE-2026-20917 intel-microcode Intel CPU owners. This is a firmware-level fix delivered as a package, so a reboot is needed before it takes effect.
New upstream stable release openssl Anything doing TLS. No CVE is named for this one in the announcement; it arrives folded in with the earlier DSA-6531.

The glibc entry also changes zic so TZif files keep a needed last transition to a new type. That is a data-format detail, but it is the kind of change that quietly breaks hand-rolled timezone tooling.

Time zones and the calendar

tzdata gets a substantial data update. Cuba moves to permanent daylight saving time, which means no more twice-yearly clock changes there. Manitoba and the Northwest Territories get updated rules, Ireland, Iran, Colombia, Brazil and Ukraine get historical corrections, and the upstream signing key is rotated. Anyone with recurring meetings across those zones will want the update. The Perl side follows with libdatetime-timezone-perl moving to Olson DB 2026f and the same Manitoba data.

Databases and server software

mariadb moves to a new upstream stable release with a long security list: code execution fixes (CVE-2026-44168, CVE-2026-48163, CVE-2026-48165), an authorization bypass (CVE-2026-44169), path traversal (CVE-2026-44171), SQL injection (CVE-2026-44172), an incomplete privilege check (CVE-2026-44173), and six further CVEs. It also clears two concrete errors users hit: “Illegal mix of collations”, and Mroonga hanging on an invalid index flag, plus a crash in information_schema.table_constraints and a regression with temporal result columns. Database admins should treat this as more than a routine bump.

The OpenStack stack gets a broad set of authorization and injection fixes. glance stops unrestricted image downloads and blocks access to internal services through image imports and HTTP image locations (CVE-2026-71196, CVE-2026-71197, CVE-2026-71198), prevents DNS rebinding during downloads and enforces URI filtering for legacy import tasks (CVE-2026-77648). nova strips internal scheduler hints on server creation (CVE-2026-46448) and stops WebSocket Origin allow-list poisoning. octavia fixes cross-tenant QoS authorization (CVE-2026-74248) and HAProxy configuration injection through redirect URLs and TLS cipher settings (CVE-2026-94571, CVE-2026-94572). aodh, manila, gnocchi, watcher, zaqar and ironic-python-agent carry related fixes. postgresql-17 arrives through DSA-6625.

sssd fixes a use-after-free (CVE-2026-12610), a privilege escalation (CVE-2025-11561), path traversal (CVE-2026-14476), information disclosure (CVE-2026-68744) and two denial-of-service issues. It also warns when ldap_sudo_search_base falls back to the root DN (CVE-2026-14474). This one matters most on machines bound to LDAP or FreeIPA.

Browser and desktop stack

kwin fixes Wayland colour management handling and a null output dereference when unplugging monitors. If you run KDE on Wayland and regularly hot-plug displays, that second fix is the one that stops a crash. chromium accumulates a long run of DSAs from DSA-6408 through DSA-6605, and firefox-esr gets DSA-6501, DSA-6560 and DSA-6573.

Thunderbird 153 compatibility gets a small cluster of fixes: allow-html-temp, mailmindr and xnote are all updated to keep working with that version. Lomiri gets a reworked scaling path instead of Qt-native HiDPI handling: lomiri-session now applies a scaling factor from GSettings, and lomiri-schemas provides the new upstream way of defining it. Lomiri terminal and telephony components get use-after-free and systemd service fixes alongside it.

Smaller changes

Rebuilds and toolchain

A sizeable slice of the 122 packages are rebuilds with no functional change of their own. Rust rebuilds cover atuin, bankstown-lv2, bpftop, btm, cyme and dwarf2sources. docker.io rebuilds cover cosign, crowdsec and distrobuilder, while dar is rebuilt against openssl, zsh against pcre2, and user-mode-linux against the updated kernel. cosign and crowdsec follow the docker.io rebuild; distrobuilder follows both docker.io and incus. llvm-toolchain-22 fixes its armel build.

Networking and system utilities

bird2 and bird3 both fix FlowSpec decoder bounds and validation, authentication key handling and BGP timer calculations. bird3 additionally fixes route display, hostentry stripping, log rotation, RCU journal synchronisation and allocator prefill. proftpd-dfsg fixes a remote denial of service in TLS handling, a denial of service (CVE-2026-119146), an authorization bypass (CVE-2026-119147) and a link-following issue (CVE-2026-119364). sudo blocks TZ variable poisoning (CVE-2026-96512). parted fixes two heap buffer overflows (CVE-2026-89088, CVE-2026-89095), and patch prevents creation of out-of-tree files (CVE-2026-115207). rsync blocks unauthenticated resource exhaustion (CVE-2026-119741), neovim fixes filename command injection (CVE-2026-11487), and nghttp2 fixes HTTP request and response smuggling (CVE-2026-58055). composer gets path traversal and command injection fixes plus sanitising of URL-embedded usernames and tokens in verbose output.

brltty now times out quickly on localhost connections and fixes IPv6 localhost connections. efivar adds SetVariable runtime support. dhcpcd fixes occasional corruption of its NTP server list. wireless-regdb updates regulatory data, and mdadm fixes a memory leak.

Installer and media

debian-installer bumps the Linux ABI to 6.12.117+deb13 and is rebuilt for the point release. debian-installer-netboot-images is rebuilt against proposed-updates. Debian says new installation images will be available soon at the regular locations, so the ISO you download today may still be the older build even though the packages it installs are current.

Bug fixes

Compositor, display and input

kwin: Wayland colour management handling and the monitor-unplug null dereference described above. btrfs-assistant no longer clobbers the user xdg-runtime-dir when running under Wayland. xorg-server and gst-plugins-base1.0 arrive with fixes through DSA-6497 and DSA-6489. brltty’s localhost timeouts and IPv6 fix are also in this area.

Login and sessions

sssd and sudo carry the fixes listed above. lomiri-session, lomiri-telephony-service and lomiri-terminal-app fix systemd user services, a use-after-free and a settings-dialog refocus bug. network-manager-l2tp and network-manager-iodine arrive through DSA-6498 and DSA-6629.

Apps

mariadb, chromium, firefox-esr, thunderbird extension helpers, neovim, vim (DSA-6600), libreoffice (DSA-6512, DSA-6543, DSA-6615), roundcube, wordpress and tor all receive fixes. xiphos fixes a code execution issue (CVE-2026-79079). tone-generator fixes generation of call progress and DTMF tones. spice-vdagent fixes a heap buffer overflow (CVE-2026-57965) and path traversal (CVE-2026-57966).

Security

The DSA tables run from DSA-6408 (chromium) to DSA-6629 (network-manager-iodine), with multiple advisories for chromium, firefox-esr, linux, tor, apache2, nginx, bind9, php8.4, libreoffice, openssl, vim, curl, xz-utils and apt. apt itself is DSA-6607. The complete DSA-to-package mapping is in the announcement, linked below. Many of these were already available individually before 13.8; the point release pulls them into the installable stable set.

Libraries and build

glibc, openssl, freetype (CVE-2026-95512), pygments (CVE-2026-4539), zlib (DSA-6613), expat (DSA-6566), libpng1.6 (DSA-6537), libheif (DSA-6524, DSA-6583) and nss (DSA-6599) get fixes. The Perl stack is busy: libdbi-perl, libnet-dns-perl, libtemplate-perl, libtie-hash-regex-perl, libwww-perl, libxml-bare-perl and libyaml-perl all fix security issues, with libwww-perl stripping the Authorization header on cross-origin redirects (CVE-2026-8368) and refusing insecure downgrades by default. mongo-c-driver, libmongocrypt and qpid-proton carry large CVE batches of their own.

Known regressions and deferred work

There are no 13.8-specific errata entries. The trixie errata page still lists one historical known problem from 13.0: netboot installer packages such as debian-installer-13-netboot-amd64 were initially missing and were meant to be corrected through trixie-updates. The release planning page still shows 13.8 with a January 2027 date, which disagrees with the announcement, the release page and the errata page; all three of those put the release on November 21, 2026. Treat the planning entry as stale.

Sources

Official announcement on the debian-announce list and the matching debian.org News page. The full package-to-change mapping is in the trixie ChangeLog, and the point-release history plus known problems are on the trixie errata page. Individual advisories are indexed on the Debian security tracker.
