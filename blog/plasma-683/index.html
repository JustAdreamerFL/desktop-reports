KDE Plasma 6.8.3: what actually changed since 6.8.2

KDE Plasma 6.8.3

The third stable 6.8 update repairs multi-GPU workarounds, screencast frame pacing, and a suspend delay. Desktop focus, panel cloning, screenshots, and everyday widgets also get fixes.

Plasma 6.8.3 is a stable bugfix release, published on November 10, 2026. It follows 6.8.2 with two weeks of fixes and translations, not another feature-development milestone. The broader changes from our 6.8 beta report are already part of the released series. KDE has published the announcement and source archives; distribution packages may follow later.

Things worth your attention

Graphics and the compositor

KWin repairs both NVIDIA and AMD workarounds in MultiGpuSwapchain. The NVIDIA condition was inverted, so the intended exclusion of a problematic Vulkan copy path was wrong (NVIDIA workaround, Vulkan copy fix). On AMD, the selected linear buffer modifier was overwritten immediately afterward; that assignment is now kept (AMD modifier workaround, linear buffer fix). These matter when rendering and display output involve different GPUs. They are repairs to existing workarounds, not a new rendering backend or a general performance claim.

Frame pacing gets a separate correction. KWin now advances Wayland FIFO and commit timing through one relevant scene view rather than every view for an output (scene view timing, FIFO pacing, related timing). Mirroring and screencasting can create multiple views of the same output; advancing through all of them could double the FIFO frame rate or cause commit-timing stutter. The render loop also fixes scheduling with triple buffering and commit timing (render loop scheduling). These are specific scheduling fixes, not measured frame-rate gains.

KWin corrects the linear segment of its inverse sRGB transfer function (inverse sRGB segment, transfer function fix). The low-luminance branch now multiplies the normalized value by 12.92 instead of dividing it. This concerns color conversion near black, not newly added HDR support. The DRM backend also clears damage tracking for non-shadow-buffer swapchains and overrides a buffer modifier with INVALID where required, both linked to buffer modifier handling.

Suspend, brightness, and display defaults

KWin ignores requests to wake displays once the system is committed to sleeping (display wake requests, sleep transition fix). Previously, input arriving while the screens were turning off could cancel that transition but leave the sleep-delay inhibitor active. The result was a visible lock screen and a wait for logind’s timeout before suspend. Input can wake the displays again after resume. This is particularly relevant if a last mouse movement made closing down for sleep feel unreliable.

Powerdevil fixes screens remaining dimmed after brightness control is lost (dimmed screens after brightness loss). The Battery Monitor limits its charge-limit hint to the system battery (system battery hint, hint scope), rather than applying the hint indiscriminately to other batteries.

Default scaling now distinguishes tablets and handhelds from phones (handheld default scaling, scaling behavior). KWin’s added test expects a 1.5 scale for the Legion Go S at 1920 × 1080. This changes automatic scale selection, not a promise to replace everyone’s saved settings. Automatic mode selection also avoids interlaced modes when the preferred mode is progressive (interlaced mode avoidance).

Recording and remote desktop

KWin smooths the cursor image written into PipeWire screencast metadata (cursor image smoothing, screencast cursor fix). People sharing or recording their screen should no longer get the jagged cursor caused by that scaling path. The KDE desktop portal fixes duplicate virtual-output names (duplicate output names).

Spectacle initializes final image data when the captured images have the same scale and calculates the combined image size more accurately (final image data, combined image size). These are screenshot assembly fixes, especially relevant to combined captures. It also skips QR-code scanning in background mode.

KRDP explicitly disables RDSTLS, which it does not implement, instead of relying on FreeRDP’s default (RDSTLS disablement, RDP negotiation). That is one RDP negotiation mode. The patch retains the existing TLS and NLA selection according to the authentication path; it does not turn off encrypted remote desktop generally.

Shell, panels, and desktop files

Plasma Desktop fixes a panel hang when layout spacing is zero. Plasma Workspace assigns a cloned panel to the screen it was cloned to. Those are useful corrections for people arranging panels across several displays.

Desktop clicks now give the desktop focus, and Show Desktop manually restores focus for minimized windows. Scrolling the Pager no longer triggers Show Desktop. Adding a launcher to the desktop targets the current Activity, while launching through shortcuts no longer hits the reported segmentation fault.

Folder View removes invalid or nonexistent files from its positioner, fixes press-position resets when its model resets, and handles drag images better during very fast drags. Widgets no longer offer unsupported manual sorting (manual sorting) and can shrink to a single cell (single-cell shrinking). The desktop’s “Create New” menu now shows Ctrl+Shift+N beside “Folder…” (shortcut in menu, menu label). The shortcut already worked; the menu finally tells you about it.

Smaller changes

Performance and internals

  • The image wallpaper loader stops launching overlapping loads during rapid screen-size changes. It lets the current request finish, then checks whether the latest options need another load (overlapping load fix). This fixes a race that could replace the chosen wallpaper with the default during repeated rotations or resizes.
  • libksysguard cancels its ReadPids runnable if the corresponding cgroup is destroyed (cgroup cancellation), relevant to process monitoring while groups disappear.
  • KWin deletes the forwarding input devices belonging to OffscreenQuickView (input device cleanup).
  • Union raises its cache allowance and skips cache updates for pixel metrics, linked to pixel metric caching. This is internal widget-style work, not a published benchmark.

Visual polish

Oxygen restores a missing outline for borderless decorations, adjusts neutral and negative text colors (text color adjustments), and fixes lines in menus under fractional scaling (menu line rendering). Breeze’s Plasma desktop theme stops drawing a faint background on the active tab (active tab background). Attached desktop tooltips inherit Plasma styling correctly with Qt 6.12 (tooltip styling).

Volume percentages and on-screen progress labels use tabular digits without overriding the font’s other default features. The brightness applet gets the same preservation fix. Kicker keeps its current list index while scrolling, Kickoff scrolls to the correct position, and Window List elides long titles instead of growing without limit (long title elision).

The Timer’s default notification stops forcing the English text “Timer finished” in every language (Timer notification text, translated notification). Existing translated text is used when no custom message is set. Its preset configuration also shows seconds. The Digital Clock zero-pads hours when 24-hour display is forced in a 12-hour locale (hour zero-padding), so an hour such as 9 appears as 09.

Developer tools and diagnostics

KWin adds an opt-in hang-detection thread (hang detection, hang-detection option, related report). A positive KWIN_HANG_DETECTION_TIMEOUT, in microseconds, enables periodic pings of the main thread. A missed response produces a warning and provides Application::onMainHang as a breakpoint target; recovery logs how long the thread was busy. This helps developers collect evidence about stalls. It is not an automatic recovery mechanism or an always-running watchdog.

KWin logs input devices during libinput setup and exposes left, top, right, and bottom properties on its internal Rect and RectF types. libkworkspace exposes session management to QML. Both libkscreen and plasma-workspace raise their plasma-wayland-protocols dependency to 1.23, which distribution builders need to account for.

Content and smaller apps

Plasma Addons updates the Astronomy Picture of the Day provider’s URL, corrects Picture of the Day context-menu icons, and fixes the tiled wallpaper’s default directory. Media Frame passes cached remote files as URLs (remote file URLs), uses a hover handler, and updates its icon immediately when a new image is selected. These repair existing content providers and widgets; there is no new wallpaper collection announced here.

Info Center’s energy graph shows the correct date and value (energy graph values). Plasma Welcome fixes its KDE Connect AppStream link and Mac detection on the Meta-key page. Bigscreen reconnects its CEC adapter after libcec reports a lost connection and allows switching settings modules while the settings app is open (settings module switching).

Bug fixes

Compositor, display, input

KWin ends an interactive move or resize without waiting for every mouse button to be released (interactive move handling). Picture-in-picture windows preserve their resize anchors at screen edges (resize anchors). Maximize guides work with floating-point geometry, and a typo in window-size adjustment is corrected (window-size adjustment). The Zoom effect finds adjacent monitors correctly in Push mode.

The Screen Transform effect paints the entire snapshot instead of only a subset. Window-opacity changes emit the damage notification needed for repainting (opacity damage notification). KWin handles a missing render device (render device handling), honors KWIN_DISABLE_UDMABUF_IMPORT even without a DRM device, and cancels touch sequences when displays turn off. Its Dim Screen effect recognizes pinentry-qt’s Wayland window class. Display Configuration avoids a zero preferred height for its panel view (panel view height), and the Touchscreen settings device selector gets its missing text role.

Login and sessions

The SDDM theme restores the Qt Virtual Keyboard fallback on X11 (Qt Virtual Keyboard fallback). The lock-screen UI ignores empty authentication messages instead of bringing up its login interface (empty authentication messages). kscreenlocker uses the view as the context for its frameSwapped connection (connection context).

Plasma Workspace restores the Show Desktop state when leaving edit mode (Show Desktop state). Bigscreen’s on-screen-keyboard toggle now changes KWin’s virtual-keyboard mode correctly. These are separate from the suspend-delay fix above.

Apps and widgets

Discover corrects keyboard-shortcut handling and settings indentation in right-to-left layouts. KRunner and Milou repair pseudo-Vim keyboard navigation (pseudo-Vim navigation). Plasma Addons fixes keyboard use of the Calculator on the desktop, keyboard movement of Quicklaunch items between models, preset-timer keyboard navigation and reordering, the Color Picker’s circle border and middle-click preview, and Disk Quota hover highlighting.

The Audio Volume OSD appears only for the currently preferred output device (OSD device selection). The Digital Clock passes its current font only after the dialog exists (font after dialog, related timing). The calendar moves its selected date along with today at midnight (selected date at midnight, date movement) and stops interpreting years 0–99 as 1900–1999 (year interpretation).

System Monitor closes its column-configuration dialog when pages change (column dialog). The Colors settings grid recalculates its sample text and cell height (sample text and cell height), and the Wallpaper settings module guards against a null screen (null screen guard). The global application menu loses a stray black pixel (stray pixel). Desktop context menus open at the current item for keyboard menu requests (keyboard menu position).

Security

The announcement and changelog do not identify a CVE fix. KRDP’s explicit RDSTLS disablement is the security-protocol correction described above; it should not be read as a switch to unencrypted RDP.

Libraries and build

libplasma avoids a crash on an invalid tooltip component, uses the parent’s screen for nested-containment geometry (nested geometry), and reports shell-package load failures (load failure reporting). plasma-integration restores the color picker’s alpha channel (alpha channel).

Union fixes checkbox alignment (checkbox alignment), spinbox sizing and backgrounds (spinbox styling), combo-box text (combo-box text), and mnemonic drawing (mnemonic drawing). It reserves menu-icon columns, corrects font metrics, improves header and element fallbacks, and respects palette text and background overrides (palette overrides). Library-directory checks now require a directory rather than merely an existing path (directory checks).

Known regressions and deferred work

None listed yet. KDE’s announcement does not publish a new regression or deferred-feature list for 6.8.3. The issues above are fixes included in this release, not a claim that all outstanding 6.8 bugs are resolved.
