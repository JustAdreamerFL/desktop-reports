KDE Plasma 6.8.1: what actually changed since 6.8.0

KDE Plasma 6.8.1

A bugfix update that landed six days after 6.8.0. Kwin gets the bulk of the fixes: pointer constraints, slowkeys, color pipelines, and suspend handling. Plasma Desktop and Workspace pick up smaller corrections.

Plasma 6.8.1 is a bugfix update that shipped on October 20, six days after 6.8.0. It is the first point release of the 6.8 series. No official announcement page exists yet; the tag is on Invent and the tarballs are on download.kde.org. The changes are drawn from the compare views for plasma-desktop, plasma-workspace, and kwin.

Things worth your attention

Kwin: pointer constraints and pointer focus

Xaver Hugl fixed a cluster of Wayland pointer handling issues. The pointerconstraints_v1 implementation no longer requires a commit for locking or unlocking, which fixes problems with Wine Wayland (BUG: 526010). Implicit pointer grabs on subsurfaces were broken; they now work correctly. The effective pointer focus surface was not always updated, making the pointer position calculate as if it were on the toplevel surface. An autotest for pointer warping with pointer locks was added, and another for implicit pointer grabs. The OSK now hides immediately when the input method deactivates (BUG: 459136).

Kwin: slowkeys accessibility filter

Vlad Zahorodnii fixed the slowkeys accessibility filter, which was dropping key release events in certain cases (BUG: 523419). The filter logic now correctly sends the release event when a client has seen at least one press. Cleanup includes removing an unused KF6::WindowSystem dependency and using Q_UNREACHABLE_RETURN.

Kwin: color pipelines disabled for 6.8

Color pipelines in the DRM backend are disabled for the 6.8 series (BUG: 525839). The OpenGL shader now matches the color pipeline calculations more closely, and the compositor takes floating point buffers into account. This is a conservative move: the color pipeline code is not ready for prime time, and disabling it avoids regressions on hardware that depends on it.

Kwin: suspend and screen handling

Screens now turn off before suspend (again), and suspend is delayed correctly. Sleep inhibition is removed when no outputs are connected. The zoom effect zooms towards the pointer in push mode (BUG: 508098). The tabbox thumbnail grid switcher is now a non-grabbing popup (BUG: 520537).

Plasma Desktop: KCM and applet fixes

The landing page KCM now shows default KCMs when there are no most used KCMs (BUG: 522711). The touchpad and mouse KCMs get indentation fixes for checkboxes and scroll-button behavior options, with proper right-to-left layout support. Action names are corrected (BUGS: 526886). The kicker applet inherits LayoutMirroring, adds an inner right margin when scrollable, and only sets drag mimedata URL when one exists. Desktop containments no longer always forward Shift+key to krunner.

Plasma Workspace: floating panels and notifications

The scripting API now saves and restores floating panel config correctly (BUG: 526843). The freespacenotifier configure action is connected (it never was), and the XDG activation token is set on launch jobs and config. Device notifications ignore virtual screens, so starting a screenshare no longer shows a spurious notification about a screen being connected. Klipper requests activation when showing its popup (Bugs: 527326). The Colors KCM unexports top-level on editor close (Bugs: 527382). The wallpaper image view handles the case where the type cannot be determined, falling back to a static image view.

Smaller changes

Performance and internals

Kwin: the renderloop makes VRR scheduling use an item instead of a window. The effect timeline does not assume frames are at least 1ms apart. The workspace scene takes layer repaints into account in collectDamage and does not ignore repaints on BackgroundEffectItems. The compositor accumulates cursor updates with a timer (Bugs: 527145, 527273). The DRM backend resolves symlinks in KWIN_DRM_DEVICES when adding GPUs (Bugs: 527309), preserves preferred modes below minimum resolution, and makes DrmVirtualOutput::m_layer a unique_ptr. The multigpuswapchain re-adds the DCC workaround for AMD Cezanne (Bugs: 521716) and enforces the host memory workaround for Nvidia GPUs (Bugs: 527163).

Visual polish

Kwin: the OpenGL texture uses swizzles to ignore non-existent alpha channels. The compositor does not present the cursor if rendering it failed. The scene avoids repainting for blocked timed commits (Bugs: 527144). The effect timeline does not limit animation steps while repaints are throttled (Bugs: 526290). SSD titlebar is permitted when an SSD drop-shadow is applied (Bugs: 527391).

Accessibility

Kwin: slowkeys cleanup (see above). The OSK hides immediately on input method deactivation. The zoom effect zooms towards the pointer in push mode.

Developer tools

Kwin: a new KWIN_WAYLAND_SUPPORT_COMMIT_TIMING_V1 environment variable helps debug performance issues (CCBUG: 525514). Autotests for pointer warping with pointer locks and implicit pointer grabs were added.

Bug fixes

Compositor and display

Kwin: pointer constraints no longer require a commit for locking (BUG: 526010). Implicit pointer grabs on subsurfaces fixed. Effective pointer focus surface updates correctly. Color pipelines disabled for 6.8 (BUG: 525839). OpenGL shader matches color pipeline calculations. Compositor takes floating point buffers into account. Scene takes layer repaints into account. Repaints on BackgroundEffectItems no longer ignored. Cursor updates accumulated with a timer (Bugs: 527145, 527273). Compositor does not present cursor if rendering failed. Scene avoids repainting for blocked timed commits (Bugs: 527144). Effect timeline does not limit animation steps while repaints throttled (Bugs: 526290). VRR scheduling uses an item instead of a window. Tabbox does not show while fullscreen effect active (BUG: 495720). Tabbox thumbnail grid is a non-grabbing popup (BUG: 520537). SSD titlebar permitted with SSD drop-shadow (BUG: 527391). DRM preserves preferred modes below minimum resolution. OpenGL texture uses swizzles for non-existent alpha channels. OpenGL EGL backend does not filter out external-only linear for YUV formats.

Input

Kwin: slowkeys filter sends released events correctly (BUG: 523419). Key repeat disabling fixed (Bugs: 514747, 526575). Tablet mode manager does not let pointer devices override tablet mode switch. Desktop containments do not always forward Shift+key to krunner.

Login and sessions

No changes in this release.

Apps

Plasma Workspace: freespacenotifier configure action connected. Freespacenotifier sets XDG activation token. Device notifications ignore virtual screens. Klipper requests activation on popup (Bugs: 527326). Colors KCM unexports top-level on close (Bugs: 527382). Wallpaper image view handles undetermined type. Scripting saves and restores floating panel config (BUG: 526843). Shell corona sets default containment.

Security

No security fixes in this release.

Libraries and build

Kwin: slowkeys removes unused KF6::WindowSystem dependency. DRM backend makes DrmVirtualOutput::m_layer a unique_ptr. DRM backend renames DrmVirtualOutput::recreateSurface(). DRM backend destroys virtual egl layers in releaseBuffers(). Kwin QPA fixes crash without render device. Kwin scripting destroyed before workspace goes down. Kwin fixes cases where renderItem return value was ignored. Kwin input method does not try to show without context (Bugs: 524506). Kwin screencast closes screencasts for removed outputs.

Known regressions and deferred work

None listed yet. The release is too fresh for a formal regressions list.
