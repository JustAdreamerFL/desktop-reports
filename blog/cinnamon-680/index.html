Cinnamon 6.8.0: what actually changed

Cinnamon 6.8.0

Cinnamon 6.8 brings finger-tracking gestures, per-monitor backgrounds and a Wayland session without the experimental label. The release also changes input methods, notifications and the lock screen, with limits worth checking before switching sessions.

Cinnamon 6.8.0 has a stable upstream source tag, created on November 4, 2026. This covers the 6.7 development cycle as well as the final 6.8.0 changes, rather than just the last batch of commits. Distribution integration is a separate step: Linux Mint’s June preview placed the next Mint release at Christmas, so this tag is not an announcement that existing Mint installations have received the new desktop.

Worth your attention

Graphics and the Wayland session

The Wayland session no longer has “experimental” in its name. That change is in the tagged source (d4b411858a02), not just a plan in a monthly news post. Linux Mint says both X11 and Wayland will be supported; X11 has not been removed.

For people testing Wayland, the cycle includes HiDPI icon and image resource scaling, screenshots at physical monitor resolution, and capturing all monitors. The keyboard indicator also reacts to scale changes. These are desktop components and capture fixes, not a promise that every application will scale correctly. The Display panel still hides its fractional-scaling controls in Wayland sessions, which is an important limit behind the new session label.

The background system now has a dedicated daemon and per-monitor configuration (3f134e604a08). Backgrounds offers “Configure monitors individually”, “Use the same background on all monitors” and “Span a single background across all monitors”. People with two differently shaped displays can choose separate pictures rather than crop one image across both. The daemon watches image-file changes, respects embedded orientation and runs as a systemd user service when active. This is wallpaper handling, not a new wallpaper collection.

Gestures that follow your fingers

Workspace switching, Expo, Scale, the window switcher, tiling, maximizing and minimizing can now follow a swipe continuously, then commit or cancel when the fingers lift. The implementation uses a native gesture source on Wayland and Touchegg on X11. X11 users still need the Touchegg package and a running service; switching to the new desktop alone does not remove that dependency.

The Gestures panel includes “Easy Workspace Gestures” and “Easy Window Management Gestures” presets, sensitivity controls, and a marker explaining that selected gestures “can follow your fingers as they move”. Available actions depend on the input device and session type. Laptop users get the most obvious benefit, though the implementation also handles touchscreen gestures.

The work originated in #13992. That pull request is not marked merged by GitHub, but the implementation is present in the release through commit 21280f90440b, followed by fixes for canceled gestures, second swipes and Expo/window-switcher edge cases. This is included code, not a feature still waiting for review.

Shell, notifications and the lock screen

Per-application notification settings landed in #13598. The Notifications panel now has an “Application notifications” button, so people who need different rules for different apps are no longer limited to the desktop-wide switches.

The grouped window list can scroll when its buttons overflow (#13352), and overflowing thumbnail popups can scroll too (#14080). That matters on crowded panels, especially when a grouped application has many open windows. The traditional window list gains an “Always on top” context-menu action through #13351.

Cinnamon also includes a native screen locker, introduced in #13432, with a controller shared by locking and session-switching paths. Wayland requires the internal locker and ignores custom screensaver commands. X11 can use the internal locker, enabled by default in upstream settings, or retain an external-locker configuration. The cycle adds busy indicators while authentication is checked, prevents typing during that check, and tells logind about the locked state. Users and distro maintainers should check their session type and locker configuration rather than assume the same behavior everywhere.

Input methods and accessibility

Fcitx5 support reaches the input-method setup, Wayland session and virtual keyboard. The Wayland hookup is in 7274117c2349. Keyboard settings also gains a layout viewer instead of depending on gkbd-capplet (467c8d3e0340). People using IMEs, rather than a single XKB layout, are the audience for these changes.

IBus shows the newly selected layout at the text cursor, but only when an entry has focus. Cinnamon applies the engine’s layout variant and replaces an already running IBus daemon at login. These changes address the relationship between the visible layout indicator and the actual input method, rather than adding more keyboard layouts.

Accessibility work replaces the separate hover-click helper with a native palette, fixes magnifier pointer events on Wayland and disables magnification while the screensaver is active. The accessibility applet also gets a working Wayland keymap.

Storage, networking and desktop services

Pulling a removable drive out while it is still mounted now produces a persistent “Device removed unsafely” notification (#13899). Its text explains that pending writes can remain even when no file appears in use, and names “Safely Remove Drive” and “Eject” as the alternatives. Clean unmounts and ejects do not trigger this warning. It reports a mistake after it happens; it cannot recover the missing writes.

WireGuard and VPN-plugin connections share “VPN Connections” in the network applet (#13913). Rows show the connection kind, such as “WireGuard” or “OpenVPN”, instead of putting WireGuard in its own section. The final batch restores the VPN “More” overflow and removes the heading switch, so the original pull-request description is not a complete description of the finished menu.

For distro maintainers, the Secret portal preference now lists gnome-keyring;oo7-portal;, and pam_oo7 is an optional authentication module (#14062). GNOME Keyring is still first in that preference list. This is support for another provider, not evidence that Cinnamon has removed the existing one.

What left the desktop

The old cinnamon2d session definitions are gone (3ba28f61071c). Downstream references to those definitions need reviewing, but the cinnamon2d launcher itself remains available.

Cinnamon removes its OpenSearch provider (34dbda8778fe) and the grouped window list’s autostart toggle. Settings drops the “Looking for something else?” section. The older edge-flip feature was removed during the cycle (#13581); that removal is separate from the new swipe-driven workspace controls.

Smaller changes

Performance and internals

  • Settings-file writes, bookmark loading, media-key proxy creation and power-profile provider lookup are asynchronous in the final batch. These remove synchronous work from desktop paths; upstream does not supply a release-wide startup benchmark.
  • The St toolkit avoids blurring a full widget-sized shadow where a smaller corner-sized silhouette can be stretched instead (#14046). Tall notification menus and HiDPI notification popups were the reported problem cases. The same change reorganizes the CPU blur loops. This is a targeted fix for stalls when shadows are built, not a general compositor frame-rate claim.
  • Spice rows load in batches when opening the Download tab. Xlet loading and versioned-xlet handling were also reworked (#13479).
  • Clearing notifications avoids redundant list updates (#13704). The notifications applet cancels timers and disconnects signals on removal instead of leaving callbacks behind.
  • The calendar backend moves to Clockenstein (#13972). Follow-up work keeps backend lifecycles consistent and avoids reporting out-of-range events as removed.

Visual polish

The sound applet expands output devices by default, keeps the input selector available after recording ends, and shows that selector when multiple inputs are connected (#13977). It also supports multiple applet instances (#14083), useful for panels on separate monitors.

The grouped window list keeps space between labels and button edges, gives unlabeled buttons equal widths, and shows the title when a pinned app opens a window. Its scrollbar takes space only when needed.

Removable-drive notifications and the drives applet use xsi-media-removable, the USB-stick symbol, rather than the old missing or less appropriate icon names (#13899). Other icon fallbacks stop assuming that the current theme is a Mint theme (#13995).

Polkit translates PAM messages through the authentication modules’ catalogs (#14064), while the password entry keeps the plain “Password” placeholder. Users see translated prompts without an arbitrary PAM message replacing that hint.

Developer tools and configuration

Looking Glass gains Muffin debug controls, scanout controls and an effects slow-down control. Its session type appears in the headerbar, the KMS debug flag goes to Wayland, and file watching uses Gio.FileMonitor instead of pyinotify (#13898).

Extension and effect authors get CinnamonGLSLEffect.get_pipeline() (#13939). Cinnamon adds GIRepository 2.0 support (#13474), while remaining global.screen use is removed from its own JavaScript and deprecated for callers. Several UI objects move to GObject or newer JavaScript class styles.

Power settings adds ambient-light-sensor support (#13649). Window settings adds focus-stealing prevention and a “Traditional” button-layout option (#13326). Availability still depends on the relevant hardware and session.

Bug fixes

Compositor, display, input

St buttons no longer depend on hover state to accept a click (#14048). Viewport and slicer changes fix pick clipping and stale paint volumes. On-screen keyboard positioning is corrected, and the startup pointer stays on the primary monitor.

The cycle fixes panel layout restoration after monitor hotplugging, fullscreen pointer grabs when raising panels on X11, and drag grabs left behind when a drag actor disappears. Alt+Shift+Tab is repaired (#13743). Keyboard-shortcut conflict checks now include actions with the same label (#14053).

Screenshot fixes cover clipboard output on Wayland, shadows around client- and server-decorated windows, canceled area selections (#13948) and a crash when capturing a server-decorated window without its frame. Scrollbars respect disabled animations.

Login and sessions

The desktop locks before switching to the greeter. Screen-lock teardown errors no longer block state updates, and the external-locker controller watches logind lock requests. Session startup fixes argument and environment handling and closes a leaked X connection.

Applets and settings

Network fixes cover removing one of several saved Wi-Fi profiles (#14073), updating access points with multiple profiles (#14075), duplicate rows after a network gains a profile (#14076), and WPA3/SAE and OWE classification (#14074). An unmanaged device providing connectivity no longer leaves the applet showing the offline icon (#13924).

Window-list fixes preserve ungrouped window order (#14089), refresh labels after workspace changes and avoid duplicate signal connections (#14055). Notification icons can resolve desktop-entry hints without a PID match (#14090), and a notification removed while appearing no longer gets a fresh timeout (#14079). Menu search discards results belonging to an older query (#14071).

Calendar events ending exactly at midnight no longer occupy another day. Settings avoids crashing on an unreadable user avatar (#14077), repairs HiDPI chooser thumbnails, and rebuilds an unparseable icon-theme cache. The sound applet no longer duplicates player open/quit buttons (#14060).

Security

cin-debug-run stops building a shell pipeline from the target program and generated GDB script. It invokes GDB with an argument list and passes the script through standard input instead (#14084). This removes that shell-interpolation path. The report describes a CWE-78 finding from static analysis and does not demonstrate a deployment exploit or establish that arbitrary debugger input is safe.

Libraries and build

Python code replaces pytz with datetime.timezone and zoneinfo. Packaging and imports receive cleanup, including a Cinnamon Settings module-name collision (#13492). Tray and XApp-status changes address icon lifecycle problems, redisplay races and misbehaving clients (#13965, #13966).

Known regressions and deferred work

The tagged Display settings module still exposes fractional-scaling controls only outside Wayland. Custom screensavers are disabled on Wayland, and some unsupported commands and menu options are hidden for that session. Removing “experimental” from the session name does not erase these differences.

The unsafe-removal warning relies on GVfs knowing about the mounts; unmount operations outside that knowledge are a documented limitation of #13899. Its author also notes that the per-device rate limit was not tested with a physically faulty connector and that a real multi-partition device was not tested. Those are coverage limits, not confirmed regressions.

Sources

Official Cinnamon source and release history: the 6.8.0 tag, its annotated tag metadata, and the tagged Debian changelog covering 6.7.x and 6.8.0. Linux Mint’s June 2026 monthly news explains the Wayland support policy and distinguishes desktop development from the upcoming Mint release. Implementation details are in the included gesture commit, per-monitor background change, notification settings pull request, shadow-rendering fix, unsafe-removal warning, and debug-helper security patch. Current session limits and portal ordering can be read directly in the tagged Display settings module and portal configuration. Locker selection is defined by the screensaver controller and the upstream settings defaults, while the remaining cinnamon2d launcher distinguishes the executable from the removed session definitions.
