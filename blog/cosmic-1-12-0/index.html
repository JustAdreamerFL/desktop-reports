COSMIC Epoch 1.12.0: what actually changed since 1.11.0

COSMIC 1.12.0

System76 tagged Epoch 1.12.0 on November 24 with an empty release body. The real changes are in the submodule commits: theme bundles, a pointer size setting, Xwayland controls, and a batch of a11y and security fixes.

As of November 25 2026, COSMIC Epoch 1.12.0 is tagged and stable. Jeremy Soller created the annotated tag on November 24, roughly a month after 1.11.0 on October 20. There was no separate feature freeze announcement: an epoch is a coordinated bump of every submodule, and this one moves 28 of them. The GitHub release body contains only the tag message, “Epoch 1.12.0”, so the list below comes from the merged commits in the range rather than from official notes. What is still open is packaging: the tag is upstream, and distro packages will pick it up on their own schedule.

Things worth your attention

Theming: bundles, dark and light wallpapers, fades

This is the biggest user-facing area in 1.12.0. COSMIC Settings can now save a look as a self-contained theme bundle, import one, rename it, and keep several side by side (cosmic-settings, theme-bundle-config). The strings you will see are “Save as…”, “Save theme as”, “Rename theme”, and “Legacy theme file”. A bad import says “select a .zip bundle or .ron theme file”. Bundles write to /usr/share-style config and data roots with an x-cosmic-format metainfo marker, and the import path accepts old ThemeBuilder .ron files, so earlier custom themes are not stranded. Frosted glass is enabled by default in this cycle.

Backgrounds gained per-mode entries, so dark and light mode can use different wallpapers. Switching between them fades over 500 ms by default through wp-alpha-modifier-v1 and subsurfaces; the config key is transition_duration, in milliseconds. The default wallpaper is now system76-cosmic-dark.png, also used as the greeter fallback. Several modules switched from the old JPEG XL decoder to jxl-rs, including cosmic-bg, cosmic-files, cosmic-greeter, and cosmic-settings.

Who it affects: anyone who customizes COSMIC themes, and theme authors who shipped .ron files. The bundle format is new, so expect a migration edge or two in the first packages.

Pointer size, end to end

COSMIC Settings has a “Pointer size” slider in Accessibility. It steps through 24, 32, 48, 64, and 96 logical pixels. On the compositor side, cursor_size is a new cosmic-comp config key that falls back to $XCURSOR_SIZE; changing it at runtime reloads every seat and the Xwayland cursor without a restart. cosmic-settings-daemon mirrors the value to GTK via org.gnome.desktop.interface cursor-size, which matters because GTK apps draw their own cursor.

Who it affects: HiDPI users, people with motor impairments, and anyone who found the old fixed cursor too small on a large monitor. This completes a loop that previously only worked through environment variables.

Compositor defaults and Xwayland controls

Mutter-style server-side decorations are now the COSMIC default. The new decoration_preference key sets DecorationPreference::ServerSide, and Settings exposes it as “Use system window headers when possible” with the note “Applications may use their own window headers in some cases”. Touchpads default to natural scrolling.

Xwayland can be disabled outright with COSMIC_DISABLE_XWAYLAND=1. Font smoothing for Xwayland apps was added: the compositor now writes Xft/Antialias=1, Xft/Hinting=1, Xft/HintStyle=hintslight, and Xft/RGBA=none. cosmic-comp also retries opening GPU nodes at startup, picks the highest refresh rate when a mode reports none, and resets GAMMA_LUT during CRTC init.

Who it affects: multi-monitor and hybrid-GPU setups, users who want a Wayland-only session, and anyone whose X11 apps looked rough on HiDPI. The environment variable is opt-in, not a default change.

Urgent notifications over fullscreen windows

cosmic-notifications gained a FullscreenBehavior setting with three values: None (the default, notifications stay behind fullscreen windows), UrgentOnly, and All. The implementation keeps a second overlay layer surface and decides per notification which one to use. Critical alerts can now break through a fullscreen game or presentation, but only if you ask for it.

Who it affects: users who miss critical notifications during fullscreen work, and kiosk or signage setups where popping up over fullscreen would be unwanted.

App launching and GPU choice

Four modules now launch apps as .service units with XDG cgroup names: cosmic-app-library, cosmic-applets, cosmic-launcher, and cosmic-store. cosmic-app-library also fixes daemonized apps such as Zed closing when the launcher exits. GPU preference handling was corrected in three places: the default discrete GPU is retained and a preference override is no longer set when the ID already is the default (in the launcher, also in the launcher, and in the store).

Who it affects: hybrid-GPU laptop owners and anyone whose terminal-launched apps vanish on exit. Grouping apps into their own cgroups also makes per-app resource limits possible for distro integrators.

Updates pages on Pop!_OS

cosmic-settings gained a Pop!_OS-only OS updates page built on pop-system-updater-zbus. It offers Daily, Weekly, and Monthly schedules with AM/PM and weekday fields, visible in i18n/en/cosmic_settings.ftl. cosmic-initial-setup gained an automatic updates page using the same bindings, and the old update notification toggle was deliberately removed.

Who it affects: Pop!_OS users going through first-run setup or changing update policy. The removed toggle is intentional, so any workflow that depended on it needs the new schedule controls instead.

Lock screen and greeter hardening

The greeter hides the password prompt while you are typing a username. The locker now rate-limits PAM retries to at least 500 ms per attempt (PAM_MIN_ATTEMPT_DURATION). Bluetooth agent code answers authorize_service with the paired state (in the applets, in Settings).

Who it affects: everyone at login, and more specifically anyone who mistypes a username on the first try or leaves a Bluetooth device paired but untrusted.

Smaller changes

Performance and internals

  • cosmic-comp removed internal mutexes and atomics from CosmicStackInternal, CosmicWindowInternal, and ContextMenu; the Wayland connection buffer was enlarged.
  • cosmic-comp-ipc is a new crate for passing session environment variables over a Unix socket using JSON messages; cosmic-session now uses it.
  • cosmic-files syncs copies in batches so large transfers do not exhaust open file descriptors, reuses descriptors for batch sync, and syncs copies before deleting sources.
  • cosmic-files falls back to gio copy when reads from gvfs FUSE paths fail and keeps serving FileManager1 after the zbus 6 upgrade.
  • cosmic-panel restarts applets killed by a signal and cleans up the client of one that exited.
  • cosmic-store refreshes AppStream data for system Flatpak remotes; cosmic-term displays every monospace font on the system.
  • The whole stack moved to zbus 6 (in cosmic-comp, cosmic-session, cosmic-settings-daemon, and others). cosmic-comp raised its MSRV to 1.95.

Visual polish

  • Panel border radius and padding now derive from the theme instead of fixed overrides. An unset override shows as “None” in the default schemas. The default dock size changed too.
  • cosmic-files shows mounted drives in the move/copy-to dialog and image and video thumbnails in Trash.
  • The audio applet no longer stretches album art and truncates long track titles at 32 characters with ContentFit::Contain.
  • cosmic-edit uses the selected text as the new find value and fixes the highlight rectangle drawn at X position 0 while horizontally scrolled.
  • cosmic-comp fixes title truncation to respect character boundaries and replaces paragraph separators in window titles.
  • cosmic-settings tracks natural scrolling in the touchpad panel and adds font and icon selection improvements in Appearance.

Developer tools

  • cosmic-settings has a CLI path straight to the keyboard settings: keyboard shortcuts and keyboard shortcuts custom subcommands.
  • cosmic-osk gained a CI workflow for format, lint, and test.
  • The Nix flake builds with Rust 1.95; the epoch version-update.sh script was updated (for the epoch, for cosmic-app-library).
  • cosmic-session only imports SSH_AUTH_SOCK when it is actually set.

Content and smaller apps

cosmic-player, cosmic-randr, cosmic-screenshot, cosmic-viewer, cosmic-monitor, and cosmic-workspaces-epoch are version bumps plus translation updates in this epoch. cosmic-viewer has no functional commits beyond a version update, one Weblate batch, also in cosmic-viewer. pop-launcher moved to zbus 6 and updated dependencies.

Bug fixes

Compositor, display, input

  • Pointer motion uses the new position in PointerMotion, and is_legal uses the correct position.
  • Mismatched output groups are filtered, submenus are not placed inside a tile when their parent is outside, and tiling no longer panics when focusing with an empty focus stack.
  • Toplevel info updates when window geometry changes; saved sizes that no longer fit a group are not restored.
  • Focus is repaired when there is no target but a session lock is active; seats send wl_surface.enter and leave to client cursor surfaces.
  • Output manager done events are scoped per output, surface threads are joined on device_changed, and the compositor no longer sleeps its Wayland thread with an event queued.
  • Screen sharing rejects a request with no selected source and avoids a double-response panic.

Login and sessions

  • Greeter hides the password field while a username is typed; locker rate-limits bad PAM attempts as described above.
  • cosmic-settings-daemon restores audio controls after PipeWire restarts and fixes Bluetooth headset control on Ubuntu 26.04. It no longer divides by zero when no keyboard layout is set.
  • cosmic-initial-setup no longer panics when changing scale with no display loaded.
  • Cosmic Settings re-registers the Bluetooth agent when bluetoothd restarts and keeps the active audio device when the one before it is removed.

Apps

  • App-list actions no longer do nothing when an item is selected, and the applets no longer abort or wait forever on Wayland errors or when the workspace manager disappears.
  • VPN state stays in the scrollable area; the panel redraws when an applet’s window goes away.
  • cosmic-store remembers scroll position when opening app details and resets it on page switches.
  • File operations write every chunk in full, propagate sync errors, skip cleanup only when appropriate, and do not follow a symlink given as the copy root.
  • cosmic-term no longer pastes while the search drawer is open or while the context drawer is open.
  • cosmic-settings preserves interface and base state across bundle changes, caps theme names, truncates bundle titles at 40 characters, shows the current wallpaper on inactive theme cards, and fixes a search navbar panic.

Security

  • cosmic-files bumps zip-rs to 9.x.
  • The lock screen enforces the 500 ms PAM attempt floor, which limits rapid-fire guessing.
  • Screen sharing requires an explicit source selection and handles a duplicate dialog response safely.

Libraries and build

  • jxl-rs replaces the previous JPEG XL path in several apps; the pipeline uses PipeWire from crates.io in the portal and switches to jiff 1.0.
  • cosmic-settings applies theme reset settings to packaged defaults and no longer pins a cosmic-protocols revision.
  • Debian packaging for cosmic-settings and for initial setup builds with the pop-os feature.

Known regressions and deferred work

The release body is empty, so this post is reconstructed from commits and may miss packaging-only changes. The update notification toggle was removed on purpose, not deferred. Theme bundles are new in this epoch and are the most likely place for migration rough edges. There is no published list of known regressions for the tag yet.
