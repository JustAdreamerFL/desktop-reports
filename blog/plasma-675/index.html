KDE Plasma 6.7.5: the September bugfix update

KDE Plasma 6.7.5

Released September 8, 2026, this is the fifth maintenance update in the Plasma 6.7 series. It brings a month of translation updates and targeted fixes across KWin, Discover, the Task Manager, and system daemons.

KDE Plasma 6.7.5 landed on September 8, 2026, one month after 6.7.4. This is a pure bugfix and translation update — no new features — and it is the last planned point release before Plasma 6.8 arrives on October 14 with its Wayland-only session. The next 6.7.x update would be 6.7.6 in November, but the project has indicated 6.7 will be supported longer to bridge the gap to the 6.8 series.

Things worth your attention

KWin and Wayland

HDR output with ICC profiles now renders more accurately. A series of commits in the OpenGL ICC shader and DRM backend (fixing bug KDE bug 524038) handle multiplier values, fall back from BToA1 to BToA0 when needed, and validate the color profile source before applying it. Users with HDR displays and custom ICC profiles should see correct colors where they previously did not.

KWin adds support for more than one wl_data_device (MR linked to bug KDE bug 521494). This improves drag-and-drop between Firefox and other Wayland clients that rely on multiple data devices. The change is in the Wayland backend and does not require application updates.

The Eye On Screen effect had a broken return animation (bug KDE bug 481100) and horizontal wheel scrolling in the offscreen Quick view — both fixed.

The Tabbox (Alt+Tab switcher) gained horizontal scrolling support and a corrected scroll direction (bug KDE bug 522229). It also closes when the activation modifier is released, matching the behavior users expect.

A DRM syncobj kernel version check was corrected, and the global removal timer timeout for Wayland clients was increased to one day, which helps with long-lived surfaces.

KWin now avoids using render devices without hardware acceleration (fixing a regression that impaired pointer movement in VMs with non-accelerated graphics drivers). It also checks supported blend modes more carefully before setting them.

EDID parsing now handles hexadecimal strings in output names correctly (bug KDE bug 523181), so monitor identification in display settings stays reliable on affected hardware.

Input handling iterates over a copy when dispatching to filters and spies, and a use-after-free in the DPMS input event filter’s touch handling was fixed (bug KDE bug 523770). Warps are no longer counted as user activity for the screen locker (bug KDE bug 523504).

The internal input method context initializes cursor and anchor positions, and surrounding-text offsets are clamped when clients set them (bugs KDE bug 516195, KDE bug 517620). The wl_fixes v2 protocol is now disabled by default.

A file descriptor leak when starting the input method was plugged, and wl_data_device support for multiple devices improves Firefox drag-and-drop.

Discover package manager

Updates no longer get stuck when fwupd is unavailable or masked via systemd (bug KDE bug 521682). A regression that mistook an update for needsReboot was reverted. The Snap backend now signals completion of update checks even when zero upgradeable snaps exist (bug KDE bug 524077). Concurrent KJobs during quit are handled safely (bugs KDE bug 497419, KDE bug 522245, KDE bug 522815, KDE bug 518264). The rpm-ostree notifier crash is fixed, and null-pointer queries in the notifier are guarded (bugs in the rpm-ostree backend). The updates KCM text now reflects the selected update type correctly. Discover also only offers to open and install .deb packages on Debian-based distributions.

Plasma Desktop and widgets

The Task Manager (taskmanager applet) fixes several right-to-left issues: task progress bars now follow RTL layout, and tasks move to the expected location when manually rearranged by dragging (bugs KDE bug 504898, KDE bug 524112). Window thumbnails no longer disappear unexpectedly. The applet also requests a thumbnail when a window is ready for painting, improving the first thumbnail appearance.

Kicker no longer launches favorites twice when pressing Space, and the Emojier returns focus to the search field on Arrow Up. The Emojier window is now large enough for its sidebar (bug KDE bug 523090). Kicker also disables category dragging and fixes the highlight while dragging. The desktop containment respects the type-ahead setting in widgets (bug KDE bug 523053). Panel tooltips strip mnemonics (bug KDE bug 488578). A scripting API reorderApplets() is exposed for panel applet reordering (bug KDE bug 523675). The wallpaper-provided accent color is no longer overwritten (bug KDE bug 514656). The landing page KCM fixes color bleed at corners (bug KDE bug 522042). Spell Checking no longer prompts to apply settings when no backend or dictionary exists (bug KDE bug 521712).

The Calendar widget no longer changes the displayed date when dragged between screens (bug KDE bug 472360). The digital clock fixes tooltip overflow, centers time zones, and compares agenda dates across time zones (bugs KDE bug 524390, KDE bug 501555, KDE bug 442100).

The Plasma Login Manager (SDDM KCM) now also syncs ~/.config/plasma-localerc, so the login screen respects your preferred language and time settings (improvement KDE bug 516964).

System Settings and KCMs

Multiple System Settings pages now correctly implement the “highlight changed settings” feature. The Spell Checking KCM no longer erroneously prompts to save unsaved changes when navigating away without making any (bug KDE bug 521712). The Night Light KCM adds the missing non-default highlight (bug KDE bug 521974). The System Settings module loader fixes a parent reset issue for modules without a submenu (bugs KDE bug 524340, KDE bug 514006).

Powerdevil clears stale battery warnings after charging, and the battery monitor applet omits the PPD message when there is no PPD. The Powerdevil KCM fixes a non-default highlight issue.

The KScreen KCM fixes the check for showing the calibration button (bug KDE bug 524507).

System daemons and background services

The KDE daemon (kded) no longer crashes while reading from or writing to the system password storage when network conditions change. A crash affecting non-KDE applications when closing a dialog is fixed. A common kded crash on Wi-Fi connection or hotspot creation is resolved.

DrKonqi stops processing crashes of its own binaries (bug KDE bug 524048) and ensures its launcher service does not participate in session management (bug KDE bug 524213), fixing a crash loop on some systems.

The activity manager (kactivitymanagerd) fixes a stats plugin crash with wrong D-Bus calls (bug KDE bug 524352) and uses contains instead of binary_search on unordered QSet.

KSystemStats fixes the i915 PMU path for discrete Intel GPUs (bug KDE bug 517334) and provides fallbacks for the OS version property (bug KDE bug 523727), improving the “OS Version” sensor in System Monitor widgets for KDE Linux and other non-traditional distributions.

Plasma Vault allows networking to be restored when an offline vault was not closed before shutdown (bug KDE bug 457680).

Plasma NetworkManager fixes duplicate delete/update jobs, missing secrets returned, and a crash with multiple secret requests (bugs KDE bug 521935 and related).

The xdg-desktop-portal-kde fixes a screencast stream leak when creation fails and releases all sessions when the portal frontend disappears (bug KDE bug 523515). It also guards against deleting an uninitialized DataControlManager.

Visual polish and theming

Breeze now uses font metrics to inset text only where it can spare the space (bug KDE bug 523118), improving text alignment in buttons and labels. The Breeze GTK theme detects dark GTK 2 themes better and applies a matching icon theme automatically.

The Union (Plasma style) adds styling for modal overlays behind dialogs (bug KDE bug 523141), makes NavigationTabBar and NavigationTabButton styling look more like upstream, sets default toolbar heights, disables Drawer animations when the animation speed multiplier is zero, uses the animation speed multiplier for StackView animations (bug KDE bug 522148), exposes the platform’s animationSpeedMultiplier on StyleHint, sets menu margins to zero (bug KDE bug 520831), and uses fill vertical alignment for delegate layouts.

Spectacle fixes the annotation options submenu overflowing off the top of the screen and a crash when the window under the pointer is destroyed during detection.

Bluedevil fixes the dialog translation for “Forget Device.”

Noteworthy bug fixes

Compositor and display: ICC profile handling for HDR (multiple commits, bug KDE bug 524038), EDID hex strings in output names (bug KDE bug 523181), DRM syncobj kernel check, render device hardware acceleration guard, blend mode validation, offscreen Quick view horizontal wheel scrolling, Eye On Screen return animation (bug KDE bug 481100).

Input and Wayland: Multiple wl_data_device support (bug KDE bug 521494), input method context initialization, surrounding-text offset clamping (bugs KDE bug 516195, KDE bug 517620), FD leak on input method start, filter/spy dispatch safety, DPMS touch use-after-free (bug KDE bug 523770), warp not counted as user activity for locker (bug KDE bug 523504), wl_fixes v2 disabled by default.

Window management: Tabbox horizontal scrolling and scroll direction (bug KDE bug 522229), Tabbox close on modifier release, window vertical pullback fix using width, custom tile null-pointer dereference, window placement for apps that resize immediately after launch (centered mode).

Task Manager and panels: RTL progress bars and drag reorder (bugs KDE bug 504898, KDE bug 524112), thumbnail disappearance, thumbnail request on window ready, Kicker double-launch on Space, Emojier Arrow Up focus and sidebar size (bug KDE bug 523090), category drag disabled, highlight while dragging fixed, desktop type-ahead (bug KDE bug 523053), panel tooltip mnemonics (bug KDE bug 488578), wallpaper accent color preservation (bug KDE bug 514656), landing page corner bleed (bug KDE bug 522042).

Calendar and clock: Calendar date change on cross-screen drag (bug KDE bug 472360), digital clock tooltip overflow and time zone centering (bug KDE bug 524390), agenda date comparison across time zones (bug KDE bug 442100), infinite list current day view, calendar view change on drag (bug KDE bug 472360).

System Settings: Highlight changed settings across multiple pages, Spell Checking false save prompt (bug KDE bug 521712), Night Light highlight (bug KDE bug 521974), module loader parent reset (bugs KDE bug 524340, KDE bug 514006).

Discover: fwupd unavailable/masked (bug KDE bug 521682), needsReboot regression, Snap zero-upgrade signal (bug KDE bug 524077), concurrent KJobs quit (bugs KDE bug 497419, KDE bug 522245, KDE bug 522815, KDE bug 518264), rpm-ostree notifier crash and null pointers, update type text, deb-only on deb distros.

Background daemons: kded password storage crash on network change, non-KDE app dialog close crash, kded Wi-Fi/hotspot crash, DrKonqi self-crash filtering (bug KDE bug 524048) and session management opt-out (bug KDE bug 524213), kactivitymanagerd stats plugin crash (bug KDE bug 524352).

Power and battery: Stale warning clear after charge, PPD message omission, KCM highlight.

Network: Plasma NM secret agent duplicate jobs, missing secrets, multi-request crash (bug KDE bug 521935).

Portals: xdg-desktop-portal-kde screencast stream leak, session release on frontend disappearance (bug KDE bug 523515), uninitialized DataControlManager guard.

Graphics and stats: i915 PMU for discrete Intel (bug KDE bug 517334), OS version fallback for KDE Linux (bug KDE bug 523727).

Vault: Network restore after unclean offline vault shutdown (bug KDE bug 457680).

Bluedevil: Forget Device dialog translation.

Spectacle: Annotation submenu overflow, window-under-pointer crash.

Known regressions and deferred work

None listed for this bugfix release. Plasma 6.7.6 is scheduled for November 3, 2026, but the project has signaled that the 6.7 series will be extended to cover the transition to the Wayland-only Plasma 6.8 release on October 14.
