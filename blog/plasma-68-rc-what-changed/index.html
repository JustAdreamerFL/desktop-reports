KDE Plasma 6.8 RC: what changed since the beta

KDE Plasma 6.8

The release candidate (Beta 2, versioned 6.7.91) is out, the feature freeze is in effect, and the final release lands October 14. Here is everything that changed since the beta, including the Union QtWidgets preview, a KWin memory leak fix, and dozens of polishing touches.

As of September 24, 2026, Plasma 6.8 Beta 2 (versioned 6.7.91) is out. KDE labels this the release candidate; the feature freeze and soft UI freeze have been in effect since Beta 1 on September 10. The final release is due October 14, coinciding with KDE’s 30th anniversary. Only fixes and translations should land between now and then.

Things worth your attention

Union theming enters its second phase

The Union theming system’s public tech preview enters its second half. Union now themes QtWidgets applications such as Dolphin and Kate (!270). To test it, install the union package, open System Settings → Colors & Themes → Application Style, and select “Breeze (Union)”. This applies Union styling to both QtQuick and QtWidgets apps. Visual glitches are expected and known; report them at bugs.kde.org with product=Union. The goal is for Union-styled apps to look as close as possible to their Breeze equivalents, with minor visual improvements considered intentional.

KWin memory leak fixed

KWin now depends on plasma-wayland-protocols 1.23.0 to fix a memory leak that could grow severe over time (!525314). The bug leaked one kde_output_device_mode_v2 resource per advertised mode on every client re-bind. After nearly two weeks of uptime, one reporter found kwin_wayland consuming around 2.2 GB of RAM versus a typical ~0.3 GB. Anyone running the beta for extended periods will notice a significant improvement.

Clipboard settings overhauled

The clipboard’s settings for handling copied image data and “MIME actions” are now more comprehensible (Tomáš Hnyk, #348932, #502274, #473882). The old interface was confusing enough that many users never touched it; the new one actually explains what the options do.

Lock screen polish

Clicking the “Show On-Screen Keyboard” button (renamed from “Virtual Keyboard”) on the lock and login screens now always shows the keyboard as expected, regardless of its typical visibility settings (Kristen McWilliam and Nate Graham, #467209, !7044). The lock screen also notifies you when the “Slow Keys” accessibility feature is enabled.

Input Method widget overhauled

The Input Method widget has been reworked. It now primarily switches between on-screen keyboard visibility modes and lets you manually show the keyboard while an XWayland app is focused, since these apps cannot trigger the keyboard automatically (Kristen McWilliam, !6876).

Kup backup notifications improved

Kup’s backup progress notifications now show elapsed time, and average speed calculations are more accurate (Méven Car, kup !62). Kup itself is new to Plasma in 6.8 — it is the backup scheduler that moved into the Plasma release cycle.

Portal dialogs polished

KDE’s desktop portal dialogs received another round of visual polish for better information density and consistency (David Edmundson and Oliver Beard, xdg-desktop-portal-kde !628, !630).

Smaller changes

Visual polish

  • Kickoff Application Launcher widget is now always big enough by default to fully accommodate all items in its sidebar rather than sometimes being scrollable by a few pixels (Christoph Wolk, #515175).
  • Notifications’ speed graphs have better axis label padding (Méven Car, plasma-workspace #151).
  • Spectacle no longer shows a misleading message about copying the image to the clipboard after you use the “Share…” feature to share it elsewhere (Tobias Fella, !586).
  • Digital Clock widget’s calendar view keyboard navigation improved (Christoph Wolk, !6900).
  • System Settings’ Quick Settings page now shows a default set of frequently-used pages until the app has learned your habits (Tobias Fella, #522711).
  • Power & Battery widget percentages use fixed-width tabular numerals so other UI elements don’t jump around as numbers change (Christoph Wolk, powerdevil !674).
  • Multi-panel setups: the “Show Notifications” button on the missed-notifications notification now opens the history widget on the first panel only (Ameen Al-Asady, !7028).
  • Clipboard widget inline buttons for the selected item appear only on hover or keyboard focus, so you can read the full text of the selected entry (Christoph Wolk, #520130).
  • Renamed audio devices is less awkward (Tomáš Hnyk, #508211).
  • KWin’s Overview effect: adjacent virtual desktop highlights no longer touch (Nate Graham, #523656).

Performance and internals

  • Plasma no longer writes to a cache file every time it displays a notification (ValdikSS, #523805).
  • System Tray ported away from the Animator system, fixing an old crash (#487699).
  • ShellCorona tracks uiReady more robustly (#525327).
  • KWin virtual backend honors buffer transform when rendering.
  • KWin DRM backend matches pageflip events to unique commit IDs (#524883).
  • KWin GBM buffer allocation destroyed as soon as possible (#525748).

Bug fixes

Compositor, display, and input

  • Fixed an issue that left Task Manager tasks’ “I’m playing audio right now” indicators stuck after entering and exiting full-screen mode (Christoph Wolk, #522471).
  • Fixed a KWin crash when interacting with titlebar buttons in very specific ways (Vlad Zahorodnii, kwin !9926).
  • Fixed lockscreen not properly showing when using the “Never require password” setting (#525349).
  • Fixed Wine window focus regression (#525590).
  • Fixed a crash returning to a game using Alt+Tab (#510116).
  • Fixed black wallpaper previews in the Activity Switcher sidebar (#378693).
  • Fixed XWayland not launching when an invalid config file existed in /etc/xdg/Xwayland-session.d/ (Ilya Katsnelson, kwin !9894).

Login and sessions

  • Fixed Plasma hanging on login when connected to a monitor with a non-standard VCP range, such as the Samsung Odyssey G60SF (Marco Martin, #525216).
  • Fixed Plasma crash on login when no screens were present early in boot (#520720).
  • Fixed occasional random Plasma crash on login (David Edmundson, !7042).
  • Fixed a crash when querying the wallpaper via D-Bus while switching wallpaper plugins (Alperen Yildiz, #525207).

Apps

  • Fixed a bug where copying text in LibreOffice apps added it to persistent clipboard history only every other time (Tomáš Hnyk, #519510).
  • Fixed middle-click-pasting text selected in a non-Qt app into a Qt app working only every other time (Tomáš Hnyk, #506325).
  • Fixed Spectacle’s full-screen annotation UI tool settings appearing off-screen (Mirko Laruina, #524499).
  • Fixed Menu Editor crashing when deleting three or more items at once (David Edmundson, #525598).
  • Fixed KRunner-powered unit conversions in French (Tobias Fella, #510873).
  • Fixed Emoji Selector showing incorrect buttons and placeholder when search returned no results.
  • Fixed sRGB color intensity info button in KScreen (#525540).

Libraries and build

  • Qt requirement bumped to 6.11.1 across all Plasma modules.
  • KDE Frameworks requirement bumped to 6.30.
  • Fixed a serious QML issue that could break QML-based UIs with nonsensical property errors (Fabian Kosmale, Qt #149607 and #146886).
  • Fixed “Frames and Outlines Contrast” theme setting not taking effect in some apps (#525364).
  • KScreen made XCB a required dependency; dropped obsolete libxcb-randr.

Known regressions and deferred work

Union theming for QtWidgets apps has known visual glitches (acknowledged in the official announcement). Location-based timezone setting remains deferred. Session restore and window position memory are still being improved. Some accessibility features from third-party apps may behave differently on the Wayland-only session.
