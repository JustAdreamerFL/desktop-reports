KDE Plasma 6.8.3: what actually changed since 6.8.2

KDE Plasma 6.8.3

The third stable 6.8 update repairs multi-GPU workarounds, screencast frame pacing, and a suspend delay. Desktop focus, panel cloning, screenshots, and everyday widgets also get fixes.

Plasma 6.8.3 is a stable bugfix release, published on November 10, 2026. It follows 6.8.2 with two weeks of fixes and translations, not another feature-development milestone. The broader changes from our 6.8 beta report are already part of the released series. KDE has published the announcement and source archives; distribution packages may follow later.

Things worth your attention

Graphics and the compositor

KWin repairs both NVIDIA and AMD workarounds in MultiGpuSwapchain. The NVIDIA condition was inverted, so the intended exclusion of a problematic Vulkan copy path was wrong (#527163, 9c944a4). On AMD, the selected linear buffer modifier was overwritten immediately afterward; that assignment is now kept (#521716, 7d296e8). These matter when rendering and display output involve different GPUs. They are repairs to existing workarounds, not a new rendering backend or a general performance claim.

Frame pacing gets a separate correction. KWin now advances Wayland FIFO and commit timing through one relevant scene view rather than every view for an output (b145d8b, #498628, #525619). Mirroring and screencasting can create multiple views of the same output; advancing through all of them could double the FIFO frame rate or cause commit-timing stutter. The render loop also fixes scheduling with triple buffering and commit timing (c7a6bdc). These are specific scheduling fixes, not measured frame-rate gains.

KWin corrects the linear segment of its inverse sRGB transfer function (#528375, 232eff1). The low-luminance branch now multiplies the normalized value by 12.92 instead of dividing it. This concerns color conversion near black, not newly added HDR support. The DRM backend also clears damage tracking for non-shadow-buffer swapchains and overrides a buffer modifier with INVALID where required, both linked to #527421.

Suspend, brightness, and display defaults

KWin ignores requests to wake displays once the system is committed to sleeping (#528221, 5b0a41d). Previously, input arriving while the screens were turning off could cancel that transition but leave the sleep-delay inhibitor active. The result was a visible lock screen and a wait for logind’s timeout before suspend. Input can wake the displays again after resume. This is particularly relevant if a last mouse movement made closing down for sleep feel unreliable.

Powerdevil fixes screens remaining dimmed after brightness control is lost (#523988). The Battery Monitor limits its charge-limit hint to the system battery (#448020, #497345), rather than applying the hint indiscriminately to other batteries.

Default scaling now distinguishes tablets and handhelds from phones (91857c5, !10345). KWin’s added test expects a 1.5 scale for the Legion Go S at 1920 × 1080. This changes automatic scale selection, not a promise to replace everyone’s saved settings. Automatic mode selection also avoids interlaced modes when the preferred mode is progressive (#527502).

Recording and remote desktop

KWin smooths the cursor image written into PipeWire screencast metadata (#528423, e553ba0). People sharing or recording their screen should no longer get the jagged cursor caused by that scaling path. The KDE desktop portal fixes duplicate virtual-output names (9516674).

Spectacle initializes final image data when the captured images have the same scale and calculates the combined image size more accurately (ad648f3, fa4b068). These are screenshot assembly fixes, especially relevant to combined captures. It also skips QR-code scanning in background mode.

KRDP explicitly disables RDSTLS, which it does not implement, instead of relying on FreeRDP’s default (8fe3696, !287). That is one RDP negotiation mode. The patch retains the existing TLS and NLA selection according to the authentication path; it does not turn off encrypted remote desktop generally.

Shell, panels, and desktop files

Plasma Desktop fixes a panel hang when layout spacing is zero (#528228). Plasma Workspace assigns a cloned panel to the screen it was cloned to (#527445). Those are useful corrections for people arranging panels across several displays.

Desktop clicks now give the desktop focus (#434090), and Show Desktop manually restores focus for minimized windows (#450137). Scrolling the Pager no longer triggers Show Desktop (#471241). Adding a launcher to the desktop targets the current Activity (#520511), while launching through shortcuts no longer hits the reported segmentation fault (#527810).

Folder View removes invalid or nonexistent files from its positioner (#469445), fixes press-position resets when its model resets (#526073), and handles drag images better during very fast drags (#527529). Widgets no longer offer unsupported manual sorting (#513880) and can shrink to a single cell (#515561). The desktop’s “Create New” menu now shows Ctrl+Shift+N beside “Folder…” (#473045, e8ddeed). The shortcut already worked; the menu finally tells you about it.

Smaller changes

Performance and internals

  • The image wallpaper loader stops launching overlapping loads during rapid screen-size changes. It lets the current request finish, then checks whether the latest options need another load (64fd6b7). This fixes a race that could replace the chosen wallpaper with the default during repeated rotations or resizes.
  • libksysguard cancels its ReadPids runnable if the corresponding cgroup is destroyed (#502879), relevant to process monitoring while groups disappear.
  • KWin deletes the forwarding input devices belonging to OffscreenQuickView (c2e5658).
  • Union raises its cache allowance and skips cache updates for pixel metrics, linked to #527409. This is internal widget-style work, not a published benchmark.

Visual polish

Oxygen restores a missing outline for borderless decorations, adjusts neutral and negative text colors (#528121), and fixes lines in menus under fractional scaling (#527745). Breeze’s Plasma desktop theme stops drawing a faint background on the active tab (881e157). Attached desktop tooltips inherit Plasma styling correctly with Qt 6.12 (#527730).

Volume percentages and on-screen progress labels use tabular digits without overriding the font’s other default features. The brightness applet gets the same preservation fix. Kicker keeps its current list index while scrolling, Kickoff scrolls to the correct position, and Window List elides long titles instead of growing without limit (#456148).

The Timer’s default notification stops forcing the English text “Timer finished” in every language (#413374, a4b2681). Existing translated text is used when no custom message is set. Its preset configuration also shows seconds. The Digital Clock zero-pads hours when 24-hour display is forced in a 12-hour locale (#517262), so an hour such as 9 appears as 09.

Developer tools and diagnostics

KWin adds an opt-in hang-detection thread (273d39d, !10248, #527622). A positive KWIN_HANG_DETECTION_TIMEOUT, in microseconds, enables periodic pings of the main thread. A missed response produces a warning and provides Application::onMainHang as a breakpoint target; recovery logs how long the thread was busy. This helps developers collect evidence about stalls. It is not an automatic recovery mechanism or an always-running watchdog.

KWin logs input devices during libinput setup and exposes left, top, right, and bottom properties on its internal Rect and RectF types. libkworkspace exposes session management to QML. Both libkscreen and plasma-workspace raise their plasma-wayland-protocols dependency to 1.23, which distribution builders need to account for.

Content and smaller apps

Plasma Addons updates the Astronomy Picture of the Day provider’s URL, corrects Picture of the Day context-menu icons, and fixes the tiled wallpaper’s default directory. Media Frame passes cached remote files as URLs (#508225), uses a hover handler, and updates its icon immediately when a new image is selected. These repair existing content providers and widgets; there is no new wallpaper collection announced here.

Info Center’s energy graph shows the correct date and value (798f13f). Plasma Welcome fixes its KDE Connect AppStream link and Mac detection on the Meta-key page. Bigscreen reconnects its CEC adapter after libcec reports a lost connection and allows switching settings modules while the settings app is open (#527030).

Bug fixes

Compositor, display, input

KWin ends an interactive move or resize without waiting for every mouse button to be released (6e1c799). Picture-in-picture windows preserve their resize anchors at screen edges (#527641). Maximize guides work with floating-point geometry, and a typo in window-size adjustment is corrected (#465124). The Zoom effect finds adjacent monitors correctly in Push mode.

The Screen Transform effect paints the entire snapshot instead of only a subset. Window-opacity changes emit the damage notification needed for repainting (#502748). KWin handles a missing render device (#527984), honors KWIN_DISABLE_UDMABUF_IMPORT even without a DRM device, and cancels touch sequences when displays turn off. Its Dim Screen effect recognizes pinentry-qt’s Wayland window class. Display Configuration avoids a zero preferred height for its panel view (#527131), and the Touchscreen settings device selector gets its missing text role.

Login and sessions

The SDDM theme restores the Qt Virtual Keyboard fallback on X11 (#527138). The lock-screen UI ignores empty authentication messages instead of bringing up its login interface (#527262). kscreenlocker uses the view as the context for its frameSwapped connection (#528438).

Plasma Workspace restores the Show Desktop state when leaving edit mode (#502272). Bigscreen’s on-screen-keyboard toggle now changes KWin’s virtual-keyboard mode correctly. These are separate from the suspend-delay fix above.

Apps and widgets

Discover corrects keyboard-shortcut handling and settings indentation in right-to-left layouts. KRunner and Milou repair pseudo-Vim keyboard navigation (#528257). Plasma Addons fixes keyboard use of the Calculator on the desktop, keyboard movement of Quicklaunch items between models, preset-timer keyboard navigation and reordering, the Color Picker’s circle border and middle-click preview, and Disk Quota hover highlighting.

The Audio Volume OSD appears only for the currently preferred output device (#517055). The Digital Clock passes its current font only after the dialog exists (#503333, #511164). The calendar moves its selected date along with today at midnight (#523827, #518640) and stops interpreting years 0–99 as 1900–1999 (#474972).

System Monitor closes its column-configuration dialog when pages change (#523194). The Colors settings grid recalculates its sample text and cell height (#528106), and the Wallpaper settings module guards against a null screen (#528380). The global application menu loses a stray black pixel (#524857). Desktop context menus open at the current item for keyboard menu requests (#526282).

Security

The announcement and changelog do not identify a CVE fix. KRDP’s explicit RDSTLS disablement is the security-protocol correction described above; it should not be read as a switch to unencrypted RDP.

Libraries and build

libplasma avoids a crash on an invalid tooltip component, uses the parent’s screen for nested-containment geometry (#525536), and reports shell-package load failures (12709e5). plasma-integration restores the color picker’s alpha channel (#528396).

Union fixes checkbox alignment (#528493), spinbox sizing and backgrounds (#528280), combo-box text (#527410), and mnemonic drawing (#528236). It reserves menu-icon columns, corrects font metrics, improves header and element fallbacks, and respects palette text and background overrides (#527260). Library-directory checks now require a directory rather than merely an existing path (#528147).

Known regressions and deferred work

None listed yet. KDE’s announcement does not publish a new regression or deferred-feature list for 6.8.3. The issues above are fixes included in this release, not a claim that all outstanding 6.8 bugs are resolved.

Sources
