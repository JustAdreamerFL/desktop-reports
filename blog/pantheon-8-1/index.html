Pantheon 8.1: what actually changed

Pantheon 8.1

Elementary OS 8.1 ships with the Secure Session as default, a blur-behind Dock, background-app management, new Monitor and Maps apps, and over 1,100 fixed issues.

Pantheon 8.1 is a stable release shipping as elementary OS 8.1, based on Ubuntu 24.04.3 LTS with Linux 6.14 and Mesa 25. This is the release that finally makes the Wayland-based Secure Session the default, adds the blur-behind visual effect to the Dock and notifications, brings system monitoring and mapping to the default app set, and closes over 1,100 issues from the community since the OS 8 launch in November 2025.

Things worth your attention

Desktop and window management

The Secure Session is now the default session type. In OS 8 it was an optional Wayland session; after a year of fixes from third-party app developers and hardware vendors including Nvidia, the team reports that it “provides a much better experience for most people and supports a broader range of modern hardware features.” Users who prefer the old session can still select the X11-based Classic Session at the login screen.

Authentication dialogs in the Secure Session now dim the rest of the screen and block other windows from stealing focus when opened, so you can be sure you are typing your password into a genuine system dialog and not a spoofed prompt.

The Dock gained background-app support through the Background Portal. You can see a list of apps running without a window, read their stated reason for running, and force them to quit. Workspace switching moved into the Dock itself: press the “+” tile to open a new workspace, click an existing one to switch, click one that is already open to jump straight into the Multitasking View, or drag apps into the Multitasking View from the Dock. The Dock also appears when you open the Multitasking View, and a new Pressure Reveal makes it easier to select app controls at the bottom of the screen without accidentally revealing the Dock. A shake animation fires when you middle-click an app that already has a single window open.

The window manager gained a new Gesture Controller that enables multi-touch features, including swiping up in the Multitasking View to close windows and a long-press gesture for context menus in more places like the Dock. Hotcorners now work even when an app is fullscreen, and the Applications Menu hotcorner is shown only in its corresponding panel corner: top-left for left-to-right readers, top-right for right-to-left.

Visual effects and design

OS 8.1 adds a blur-behind effect for translucent desktop elements including the Dock, Notifications, and the Alt+Tab window switcher, giving those panels visual separation from the applications behind them while keeping text legible. Notifications have rounder corners, and their close animation now matches the associated swipe gesture. Picture-in-Picture windows also have rounded corners.

Focus indicators now appear only when navigating with the keyboard and disappear when using a mouse or touch, removing a persistent visual artifact for pointer users while keeping accessibility intact. The new Reduce Motion setting covers a wider range of animations across the desktop and apps, with smooth multi-touch gestures preserved.

Folder icons were redesigned to be rounder and match the Files app icon more closely. Mouse icons gained a scroll wheel detail, and pointer icons were updated to match. The system falls back to Adwaita icons when an app uses a non-standard icon name.

New default apps: Monitor and Maps

Two new default apps shipped with OS 8.1. Monitor is a system-resource and process viewer with live graphs and an optional panel indicator for passive checking. Maps covers the basics — explore, transit maps, location search, and geo:// link support that integrates with Calendar for event locations.

Privacy and security

AppArmor profiles ship with this release that resolve Flatpak sandbox issues, notably for Steam and apps running in a Guest session. In System Settings → Applications you can now directly deny an app access to notification bubbles alongside other permissions. System Settings can configure its own notifications, and stale notifications from apps like Terminal are withdrawn when no longer relevant. Screenshot notifications open Image Viewer when clicked and offer to show the image in Files.

Apps

Music now saves and restores the play queue and last-played track across sessions, lets you remove individual tracks via context menus or clear the whole queue, searches the queue by track name, and shows album artwork in the panel media controls. Performance for large queues improved.

Files supports the admin:// URI protocol for administrator access, the New file submenu respects the Templates folder hierarchy, and Properties windows show more precise date and time with a new format setting in the main menu.

Code can clone repositories from the sidebar projects menu, switch to remote git branches with a warning about uncommitted changes, and the Symbols sidebar shows more detail for Vala and C symbols in tooltips. Edit marks can be placed in the source-view gutter and jumped between with Alt+←/→.

Terminal adopted the modern tab bar widget shared with Web, Files, and Code, with an option to hide the tab bar when there is only one tab. Paste protection expanded to cover authentication commands like doas, commands with skip-confirmation flags (-y, –interactive=never, –force), and multi-line command detection. A new option lets you disable paste protection entirely.

GNOME Web 48.3 ships with improved performance, web compatibility, and a redesigned bookmarks sidebar.

Accessibility

The installer and Onboarding were reworked for keyboard and screen reader use after feedback from Florian, a blind cybersecurity tester who returned for a second round of accessibility testing. The “Before Installing”, “Try or Install”, “Choose a Disk”, and Encryption views have improved accessible labels, password-quality feedback is read aloud, and text-style markup is no longer announced unexpectedly. OS 8.1 can now be installed and set up completely blind in most cases.

Notifications and the Shortcut Overlay both got screen-reader support. Calendar main menu, calendar source addition, and the event dialog have improved labels. Firmware updates navigation was rewritten with better screen reader support. The Lock Screen auto-selects the Classic session when accessibility features that do not yet work in the Secure Session are in use, and media keys work on the Lock Screen. Main menus are properly marked and can be opened with F10.

Smaller changes

Visual polish

Dark Mode schedule snoozing lets you manually toggle Dark Mode on or off while using a timed or sunset-to-sunrise schedule without canceling the schedule — it resumes on the next schedule change. Dark Mode screenshots and brand colors appear in AppCenter when available, and the Lock Screen follows your Dark Mode settings. The Bluetooth settings panel was redesigned to separate nearby and paired devices visually, with improved keyboard navigation and screen reader experience. Duplicate devices in the list were fixed, and pairing requests requiring passcodes now work more reliably.

In Network settings, you can now choose whether a network auto-connects when available and whether to reduce background data usage. Middle-clicking a networking toggle in the panel jumps to System Settings. The Power menu shows the device model when available and avoids an empty battery icon, and Power settings now warn about increased energy usage with certain options.

Settings pages with sidebars remember their adjusted width. “About this device” works as a search term in the System page. Panel transparency, orientation lock, and power settings now sync to the Lock Screen.

Performance and internals

The long-term support Hardware Enablement stack from Ubuntu brings Linux 6.14 and Mesa 25, with improved performance while gaming or moving files, reduced power consumption for some AMD and Intel chipsets and GPUs, and new security features. Support was added for Intel Lunar Lake processors and for more webcams, USB network devices, joysticks, gamepads, Wi-Fi devices, and microphones.

For the first time, ARM64 builds are offered for UEFI-booting devices, including Apple Silicon machines and devices that load UEFI-supporting firmware like the Raspberry Pi. The underlying Linux also supports certain Qualcomm and Rockchip processors.

Fractional display scaling now works in the Secure Session, addressing a common complaint about integer-only scaling in OS 8 that left HiDPI-non-pixel-dense displays awkwardly sized. Multi-monitor issues were resolved, including problems when monitor layouts changed or during drag-and-drop. The Installer is now always re-centered on screen, fixing issues when the layout changes while it loads, including in some virtual machines.

Buttons that previously appeared only on hover (in Calendar’s main menu and the Multitasking View) now show all the time, making them discoverable on touch. Wacom stylus detection was improved to prevent a crash when no stylus is found, and the middle-click paste option was fixed in Secure sessions.

The updates system was rewritten: it no longer runs in Demo Mode, checks once daily instead of on every login, and does not automatically download on metered connections, sending a notification instead. AppCenter updates are sorted by release date, the Releases dialog was redesigned, and the “Last checked” time updates every minute while the updates view is open. System updates show the download size beforehand and a progress bar, skip held-back phased packages, and can be reached directly from the Dock, Applications Menu, or search.

Developer tools and platform

Gala 8.6.0 and 8.6.1 shipped alongside OS 8.1 with improvements to the classic session, a new on-screen keyboard for the secure session, screenshotting that includes open menus, and touchscreen swiping up from the bottom to open the Multitasking View. The flatpak-platform repository bumped the GNOME runtime to 49 and then to 50, updated Granite to 7.8.1, and updated the stylesheet to 8.2.2. The icons repository released 9.0.0 with updated symbolic icons for GTK 4.22 across devices, apps, status, emblems, and categories, plus Inkscape-related icon additions.

Bug fixes

Compositor, display, input

The new Gesture Controller and Gesture Manager in Gala fixed several multi-touch and window-management edge cases. Stylus detection in Wacom settings no longer crashes when no stylus is found. Middle-click paste now works in Secure sessions. The Lock Screen no longer freezes when connecting Bluetooth devices, and Airplane Mode now correctly disables only networking radios rather than Bluetooth or wired networks.

Login and sessions

The session-switching issues between Classic and Secure sessions were resolved, so apps that failed to start correctly when switching sessions now launch properly. The Installer’s custom install mode no longer closes unexpectedly for users with complex partitioning schemes, and the corner cases were tracked down with new regression tests added. The Installer is always re-centered on screen, including when the layout changes during loading.

Apps

AppCenter now shows percentage-based ratings from ODRS for Flathub apps, displays elementary-specific screenshots when developers provide them for multiple platforms, indicates controller support for games, shows in-app purchase labels, and supports application add-ons. The action button for free apps now reads “Install” instead of “Free”, and search results show in two columns when space permits. App icons fall back to a nicer placeholder when loading is slow and cross-fade in once ready, and icons reload on the fly as their data is processed.

Calendar received improved screen reader labels and touch-screen support. Terminal’s paste protection now warns when a single paste contains multiple alarming elements and detects commands with newlines better. System Settings warns if a custom keyboard shortcut conflicts with a common system shortcut like Copy, Paste, or New Tab.

Security

New AppArmor profiles resolve Flatpak sandbox issues that affected Steam and Guest sessions. Screen filters are no longer captured in screenshots. The notification system properly denies app access and withdraws stale notifications.

Libraries and build

Gala 8.6.1 fixed a frequent crash when using the classic session. The flatpak-platform and icons repositories updated their translation templates, build tooling, and dependencies, with the platform moving to Docker build-action version 7 and Ubuntu 24.04 runners.

Known regressions and deferred work

The Secure Session does not yet support the onscreen keyboard, so System Settings shows a message when you try to turn it on and directs you to the Classic session instead. Some apps that have not yet updated to Wayland may still require the Classic session. The multi-monitor and fractional scaling improvements are specific to the Secure Session; behavior in the Classic Session remains unchanged from OS 8.0.
